# Plan 0.51 (discharge) — prove the three ResolverBridge postulates

status: ready-to-execute (2026-06-27). POC done; NOT blocked by 0.50.

## Goal
Replace the three postulates in `Once.Adequacy.ResolverBridge`
(`resolver-preserves-typing`, `resolver-reflects-typing`, `resolver-preserves-trace`)
with proofs, for the IMPORT-FREE fragment (the import case → residual `*-imports`
postulates, keeping the apex interface general).

## Key facts (verified)
- `resolveImports mm (mkModule ds)` = inline import sigs (per `DImport`) + map
  `canonDecl` over decls. **Import-free** (no `DImport`) ⇒ just `canonDecl` (=
  `canonExpr [] um am` on each `DFunDef` body; `um=[]`,`am=[]` when no imports).
- `canonExpr` only rewrites a FREE NON-BUILTIN `RVar x` → `RResolved (canonical [x])`
  (`canonVar`, Resolve.agda 198-211). Local/bound names and the 18 `isBuiltinName`
  names (id,fst,snd,inl,inr,unit,pair,terminal,initial,curry,apply,compose,arr,
  case,cata,ana,In,Out) stay `RVar`. **isBuiltinName ⊇ all 16 judgment-special
  heads** (verified), so every special rule's head is preserved.
- `bare x ≡ canonical [x]` and `showCanonical (canonical [x]) ≡ x` are DEFINITIONAL
  (Once.CanonicalName 40-53). `t-var-import`/`m-named` premise `lookupImport ctx x`
  and `t-var-resolved`/`m-named-resolved` premise `lookupImport ctx (showCanonical cn)`
  are then the SAME term ⇒ the var map is just `t-var-resolved <same proof>`.
- `ModuleTyped` = inductive `⊢ᶜ` (AcceptSound: "ONLY the judgment, no elaborator").

## Step 1 — foundational lemmas (standalone, commit green first)
New module e.g. `Once.Adequacy.CanonPreserve`.
- `BLA ctx bound` := `∀ x → elemStr x bound ≡ is-just (lookupLocal ctx x)` (or the
  two implications bla-local / bla-import). Needs `lookupLocal`/`extendNamedCtx`
  (Classify.agda 174-235) + `elemStr` (Resolve 167-171).
- `bla-nil`   : `BLA ctx []` when ctx has no locals (initial fun ctx) — verify
  `lookupLocal initialCtx x ≡ nothing`.
- `bla-extend`: `BLA ctx bound → BLA (extendNamedCtx ctx x A) (x ∷ bound)`.
- `classify-canon` : `classifyAppHead f ≡ nothing → classifyAppHead (canonExpr bound [] [] f) ≡ nothing`
  (canonExpr can't CREATE a builtin head; Classify 346-386).
- helper: for free non-builtin x, `canonExpr bound [] [] (RVar x) ≡ RResolved (canonical [x])`,
  and for builtin/bound x, `≡ RVar x` — by `elemStr`/`isBuiltinName` case (use BLA to
  align "x not local" ⇒ elemStr false).

## Step 2 — mutual preservation (ATOMIC ~48 cases; commit when green)
`canon-pres-ᵢ/ᵍ/ᵐ/ᶜ : BLA ctx bound → ctx ⊢_ e ∶ … → ctx ⊢_ (canonExpr bound [] [] e) ∶ …`
Case shapes:
- literals/unit (t-int,t-str,t-unit,g-int): canonExpr is id ⇒ refl / same rule.
- t-unit-var, g-terminal, m-id…m-inr: head is builtin ⇒ kept; lookup-fail premises
  unchanged (ctx fixed) ⇒ re-apply same rule.
- t-var-local: BLA ⇒ elemStr true ⇒ canonExpr keeps RVar x ⇒ same rule.
- t-var-resolved / m-named-resolved: RResolved unchanged ⇒ refl.
- t-var-import / m-named: x not local ⇒ (BLA) elemStr false; case isBuiltinName x:
  true → kept (same rule); false → `RResolved (canonical [x])`, apply t-var-resolved/
  m-named-resolved with the SAME `lookupImport` proof (showCanonical (canonical [x]) = x).
- t-var-qualified: import-free ⇒ am=[] ⇒ canonExpr's RQualified→(lookup nothing) branch;
  but a qualified ref can't be import-free-well-typed (no qualified import in table) ⇒
  rule out via the premise, or handle the am-nothing branch.
- congruence: t-annot,t-pair,t-neg,t-binop×2,t-id/fst/snd/terminal/arr/apply-app,
  g-pair,g-inl,g-inr,g-In,m-compose,m-case,m-pair,m-curry,m-cata,m-arr,m-const,
  t-morph-lift,t-embed — recurse (IH) on sub-derivations, re-apply rule. The *-app
  rules keep the builtin head; m-compose/case keep `RApp(RApp(RVar "compose")…)`.
- t-app/t-effApp: use `classify-canon` for the `classifyAppHead … ≡ nothing` premise;
  IH on f (⊢ᵢ) and x (⊢ᶜ).
- binders t-lam/t-let/t-case: canonExpr extends bound by the binder; use `bla-extend`
  for the IH on the body/branches; note canonExpr (RLam x b)=RLam x (canonExpr (x∷bound) b)
  etc. (Resolve 214-218).
- m-cata: alg checked in `ctxWithImportsAndPolys …` (locals reset) ⇒ BLA [] there;
  canonExpr recurses with the SAME bound (cata alg uses `canonExpr bound` — check it
  resets or not; if alg is closed, bound is irrelevant). Verify against Resolve's RAna/cata clause.

## Step 3 — reflection (reverse direction)
`canon-refl-ᵢ/…` : `ctx ⊢_ (canonExpr … e) ∶ … → ctx ⊢_ e ∶ …`. Mirror Step 2; the
var case maps t-var-resolved (canonical [x]) BACK to t-var-import (need: the RResolved
in the image came from a free RVar — true since canonExpr only produces canonical [x]
from RVar x). Cleanest: induct on e (not the derivation) and invert.

## Step 5 — trace, discharge (3)
`moduleToIR mod = moduleToIR-aux (compileResolvedModule Heap false mod)`. Need
`compileResolvedModule Heap false mR ≡ compileResolvedModule Heap false mU` (import-free),
then `cong (⟦_⟧IR ∘ moduleToIR-aux)` + per-n refl. compileResolvedModule elaborates
each body via the 3445-line elaborator (`checkElab`/`inferElabV`). Two routes:
  (a) prove `checkElab ctx (canonExpr…e) T ≡ checkElab ctx e T` by elaborator induction
      (heavy; bare=canonical makes the sigOp leaf definitionally equal — Builders.agda
      `value-info` depends only on `showCanonical`); OR
  (b) reuse compile-correctness: if the elaborated SURFACE term is determined by the
      ⊢ᶜ derivation (Step 2 gives corresponding derivations), the IR coincides.
Route (a) is the direct one; scope it after (1)&(2) land. THIS is the heavy third.
