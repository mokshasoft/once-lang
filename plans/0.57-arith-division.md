# Plan 0.57 — Arith Division & Remainder (D055-total)

Add `/` and `%` to the arith machine, mirroring the `add/sub/mul/neg`
pipeline. Per **D055**, `/` and `%` are TOTAL over `Word` (RISC-V
semantics, no trap):

- `a / 0 = -1` (all-ones); `a % 0 = a` (keeps `a = (a/b)*b + (a%b)`).
- `INT_MIN / -1 = INT_MIN`; `INT_MIN % -1 = 0` (quotient wraps like `*`).
- else: signed truncated division / remainder.

**Correctness = the same op↦instruction mapping as the other ops:**
`aadd ↦ add-rrr ↦ Xadd ↦ "add" ↦ ⊕`. For division the mapping is
`adiv ↦ div-rrr ↦ Xdiv ↦ "div"(riscv)/guarded-idiv(x86) ↦ ⊘`.

## Layers to add (mirror the existing ops)

1. **Word** (`Once/Word.agda`): `_⊘_ : Word → Word → Word` (div) and
   `_⊛%_`/`remW` (rem), TOTAL with the D055 sentinels above. Signed,
   truncated-toward-zero. Optionally prove the div identity
   `a ≡ (a ⊘ b) ⊗ b ⊕ (a remW b)` (useful, not required).
2. **MArithIR** (`Once/Arith/Machine/IR.agda`): constructors
   `adiv` / `amod : MArithIR sh → MArithIR sh → MArithIR sh`.
3. **eval-arith-W** (`Once/Arith/Machine/WordSem.agda`):
   `eval (adiv a b) = eval a ⊘ eval b`,
   `eval (amod a b) = eval a remW eval b`.
4. **AbstractInstr** (`Once/Arith/Machine/AbsInstr.agda`):
   `div-rrr` / `rem-rrr : ℕ → ℕ → ℕ → AbstractInstr` + `step` cases
   using `⊘` / `remW`.
5. **Machine Compile** (`Once/Arith/Machine/Compile.agda`): `adiv`/`amod`
   → `div-rrr`/`rem-rrr` (same register discipline as `amul`).
6. **XInstr** (`Once/Arith/Backend/XInstr/{Syntax,CodeGen}.agda`):
   neutral `Xdiv-rr` / `Xrem-rr`.
7. **Backend Emit**:
   - **RISC-V** (`Backend/RiscV64/Emit.agda`): `Xdiv-rr ↦ "div …"`,
     `Xrem-rr ↦ "rem …"` — native, total by spec. Clean 1-1 mapping.
   - **x86-64 / x86-32** (`Backend/X86-*/Emit.agda`): `idiv` needs
     `rax`/`rdx` (`cqo`/`cdq` sign-extend) + a **D055 guard**: test
     divisor `== 0` → produce `-1`(div)/dividend(mod); detect
     `INT_MIN / -1` → produce `INT_MIN`(div)/`0`(mod); else `idiv`.
     Emit as a short branch sequence. (Guard elision is a later
     optimization; emit it unconditionally first.)
8. **Correctness** (`Backend/*/Correct.agda` + `block-correct`):
   - RISC-V: extend the block-correct mapping with the `⊘`/`remW`
     cases — same shape as `⊗`.
   - x86: prove the guard sequence's net effect equals `⊘`/`remW`
     (case-split on `b = 0` / `INT_MIN,-1` / else). More work than the
     1-1 ops; this is the one place D055's guard shows up in the proof.
9. **Recognise** (`Once/Arith/Machine/Recognise.agda`): recognise
   `arith.div.int` / `arith.mod.int` → `adiv` / `amod`.
10. **cabal**: add any NEW MAlonzo modules to `compiler/once.cabal`
    (hand-maintained list). Re-extract (`make malonzo`).
