# Plan: Restructure Bootstrap Normalizer Proofs (v2)

## Core Insight

A normalizer is correct when **normal forms are fixpoints**:
```
N ∘ encode t ⟶* encode t   (for NoRedex t)
```

Since N = cata TermF alg, this follows from a single property of the algebra:

> **The algebra acts as In on normal forms**

## The Single Spec

```agda
record NormalizerSpec (N : Term TermCode' TermCode') : Set where
  field
    alg : Term (⟦ TermF ⟧F TermCode') TermCode'
    is-cata : N ≡ cata TermF alg

    preserves-nf : ∀ {A B} (t : Term A B) → NoRedex t →
                   (alg ∘ out ∘ encode t) ⟶* encode t
```

One property, not 15.
