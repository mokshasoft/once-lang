# Plan 0.46 — Denotational (monadic) trace semantics IS the source observable

> **One sentence.** Give Once a **compositional denotational meaning** `⟦_⟧ᴰ`
> (an effect-graded monadic trace semantics) and make **it** the source
> observable `⟦src⟧` — fuel-free, event-indexed, higher-order-correct — with the
> operational machine (`flat-events`) *refining* it and the independent
> `SS.eval` reference (D057) kept as the load-bearing cross-check. The
> step-fueled `otrace` is retired.

## THE RULE (inherited from Plan 0.44 — read first)

A principled top-level definition is correct by fiat; when it and the lower
levels (lemmas, existing machinery, codegen) disagree, **the top wins and the
mismatch is a work-item.** Never weaken the spec to fit a lemma; never rebuild
bottom-up (step-fuel / enough-fuel / monotonicity) what the top made
unnecessary. We are *applying* this rule to a decision this very plan reverses
(see below) — so it is the contract here too.

## Why this plan was inverted (the mistake we are correcting)

The 2026-06-14 draft made `⟦_⟧ᴰ` a *deferred reasoning layer*, with an
**operational** source observable (`obs`, then the step-fueled `otrace`) as
ground truth. That was backwards, for one concrete reason:

- **Higher-order effects.** The current `obs` denotes an arrow as a *pure*
  function `⟦A ⇒ B⟧ = ⟦A⟧ → ⟦B⟧`, which has no slot for a trace, so an effect
  inside an applied closure is lost (`obs … apply … = ([], …)`). To fix this I
  built `otrace`, an *operational* interpreter that *runs* the closure body —
  but running a closure body doesn't terminate structurally, so `otrace` carries
  a **step-fuel**, and that step-fuel became the apex's observable index
  (`⟦src⟧ n = proj₁ (otrace n …)`). **That is exactly how step-indexing snuck
  back into the apex**, in contradiction to D058 (event-indexed).

The fix is not operational. It is to give the **arrow** an effect-carrying
denotation: `⟦A ⇒ B⟧ᴰ = ⟦A⟧ᴰ → T ⟦B⟧ᴰ`. Then `⟦apply⟧ (clo, a) = clo a` is
**ordinary, total Agda function application that threads the trace** — no
running, no fuel, higher-order effects handled compositionally. The closure's
trace-function is built by **structural recursion on the body IR**. So the
denotational observable is fuel-free *and* higher-order-correct — the one thing
the operational route could not be without step-fuel.

**Layering, corrected:** *denotational spec, operational refinement.* Only the
**machine** is operational; the **source observable is denotational**. `otrace`
was the source observable made operational — the wrong layer — and is retired.

## The semantics (effect-graded, arrow-respecting, fuel-free)

The monad **never surfaces in Once**. Once stays a CCC + structured recursion on
arrows; effects are tracked at the **arrow kind** (`⇒[ k ]`). `⟦_⟧ᴰ` interprets
those kinds into a metatheoretic trace monad `T`:

- **The monad.** `T X = ℕ → List SigOpEvent × X` — a **budget-indexed Writer**.
  The `ℕ` is the **event-observation depth** (D058): it is consumed *only* by
  the productive `Ana` unfold (one F-layer per decrement), and threaded
  inertly everywhere else. It is **not** a step-fuel and **not** a termination
  device — `⟦_⟧ᴰ` terminates by structural recursion on the IR; `T`'s `ℕ` is a
  *parameter*. (Finite computations — every `Cata`, every total closure — ignore
  it; the trace is a finite `List`. Only the single top-level `Ana` event loop
  grows the trace with the budget, which is precisely the apex's `∀ n`.)
- **Value domain.** `⟦_⟧ᴰ : Type → Set`, recursive on type structure, with
  `⟦A ⇒[k] B⟧ᴰ = ⟦A⟧ᴰ → T ⟦B⟧ᴰ` (pure arrows get `T = Id`-collapsed: their
  Writer component is always `[]`). Base/product/sum/`μ` as usual. (Positive and
  total: `→` of two `Set`s is a `Set`; recursion is on the finite type.)
- **`⟦_⟧ᴰ : IR A B → ⟦A⟧ᴰ → T ⟦B⟧ᴰ`** (Kleisli), compositional:
  - `SigOp si` ↦ `tell` its event (`Emits`/`Halts`; `Pure` ↦ `tell []`, lockstep
    with the effect-aware `obs`/`flat-events`).
  - `_∘_` ↦ Kleisli composition (concatenate events, thread budget).
  - `⟨_,_⟩`, `fst`, `snd`, `inl`, `inr`, `case`, `terminal` ↦ standard monadic
    combinators.
  - `curry f` ↦ `λ γ → return (λ a → ⟦f⟧ᴰ (γ, a))` — a closure *is* a Kleisli
    arrow, built structurally from `f`. `apply` ↦ `λ (clo, a) → clo a` (fuel-free).
  - `Cata wf alg` ↦ structural fold whose algebra runs in `T` (`sem-cata` over
    the trace-Writer carrier — the existing `cata-ev-alg`/`sem-cata` machinery).
  - `Ana wf coalg` ↦ budget-bounded unfold: at budget `0` emit `[]`; at `suc n`
    run one coalgebra layer (telling its events) and recurse at `n`. **The sole
    consumer of `T`'s `ℕ`.**

Higher-order effects are handled **compositionally and fuel-free**; the budget
appears **only** at `Ana`, as the event-observation depth — i.e. exactly D058's
index, structurally, with no step-fuel anywhere.

## How it sits under the apex (Plan 0.44) and D057

- **`⟦src⟧ = ⟦_⟧ᴰ`** (projected to its trace): `⟦ src ⟧ n = proj₁ (⟦ mainIR ⟧ᴰ tt n)`.
  Fuel-free, event-indexed, higher-order-correct. Replaces `λ n → proj₁ (otrace n …)`.
- **Machine refines it.** `traces-agree` / `ir-flat-correct` become
  `flat-events … ≡ proj₁ (⟦ir⟧ᴰ … )` — the operational machine refines the
  denotational observable. (`MachineRefinesObsF`'s `enough-fuel`/`run-halts`
  completion fields go away: the budget is the event depth, not a halting fuel.)
- **`SS.eval` is the load-bearing cross-check (D057 preserved).** `SS.eval`
  (independent, untyped, step-fueled — its fuel stays *internal* to the
  reference) is tied to `⟦_⟧ᴰ` by a *required* theorem `SS.eval ≡ ⟦_⟧ᴰ`
  (today's `#10`/`elaborate-preserves-trace`, restated). A meaning-changing
  elaborator bug breaks *that* proof ⇒ the elaborator stays load-bearing. So we
  keep both: the clean denotational spec **and** the independent anchor.

## Why a denotational semantics is also the right reasoning layer (unchanged, still true)

Beyond being the cleanest observable, `⟦_⟧ᴰ` is **compositional**
(`⟦g ∘ f⟧ᴰ = ⟦g⟧ᴰ ∘ₖ ⟦f⟧ᴰ`), which the operational trace never was. That buys
two things for free, later:

1. **Certifying the optimizer (Plan 0.39):** `⟦optimize ir⟧ᴰ = ⟦ir⟧ᴰ` by the CCC
   + monad laws (equational), then trace-preservation falls out since `⟦_⟧ᴰ` *is*
   the observable — no separate adequacy step needed (it was its own ground truth).
2. **Reasoning about Once PROGRAMS** (the deeper reason, user 2026-06-14): a
   program logic / equational theory — observational equivalence, effect-freedom
   on a path, spec satisfaction — at the source/IR level, independent of any run.

## Dependent-types caveat (honest)

A monadic denotational model of a *dependently-typed effectful* language is
research-frontier (graded/indexed monads compatible with type dependency, or an
LCCC + monad model). For **today's** (non-dependent) Once, `⟦_⟧ᴰ` is a clean,
total, `--safe` semantics and the right observable. **If/when** Once gains
dependent types, revisit whether `⟦_⟧ᴰ` follows the graded-monad route or is
replaced/augmented by an operational program logic. The independent `SS.eval`
reference (D057) is the hedge: it remains a valid anchor regardless.
