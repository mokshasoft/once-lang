# Plan 0.46 / OCP-0006 — Clean semantics (a five-object target, reached top-down)

> **One sentence.** Once *is* CCC + structured recursion with an effect-carrying arrow, so
> its semantics should be **five objects and one theorem**; we are *not there* (the tree
> holds ~10 overlapping semantics joined by drift-prone bridges), so this plan **purges to
> the clean state layer by layer, top-down, deleting conflicts rather than bridging them,
> and closing every gap at a layer before descending to the next.**

---

## Why a PROCESS, not a milestone list (read first — it is the whole point)

Every wrong turn in this work — the general-recursion leak, `CompSim`/`ProdSim`, the phantom
"setup trace," option A, "bridge `obs`" — has **one cause**: we made a decision at a lower
layer (the machine, a proof) **while a higher layer (the meaning) still had gaps.** With an
unpinned meaning, every choice below it is a guess. The cure is not cleverness; it is
**order**: pin the meaning completely, *then* descend.

And the *mess itself* — the ~10 semantics — is the residue of one repeated move: **add a
better semantics, bridge it to the old one, intend to delete the old one later, never delete
it.** Coexistence is the disease; every bridge (`faithful`, `prod-bridge`, the missing
`obs↔evalᴰ` edge) is a fossil of a deletion that never happened. So the process forbids
coexistence: **delete first, break the build, rebuild against the clean meaning.**

## THE PROCESS — three rules, applied per layer, ①→②→③→④

**Rule 1 — the "conflicts with layer N" test (so deletion isn't subjective).**
A module conflicts with layer N **iff it is a *second definition* of the thing N uniquely
owns** (① owns *the value model*; ② owns *the meaning*). A module that merely *consumes* N,
or is a *derived view* of N, does **not** conflict — it gets re-pointed at the clean N.
Discriminator: *another way of saying what N says* (delete) vs *another thing that uses what N
says* (keep, re-point).

**Rule 2 — bounded red via scaffold-downstream-as-postulates (so `fix` never drags you down).**
Deleting an N-conflict breaks its consumers, which usually live *below* N. Do **not** prove
those green now — that is premature lower-layer work. Instead:

> delete the conflict → **scaffold each downstream break as an explicit `postulate` stated
> against the clean layer-N object** → commit (green-with-postulates) → fix only *layer N's
> own content* → commit.

The only red allowed is "a named postulate pointing strictly *downward* at a layer not yet
reached."

**Rule 3 — the descent gate (so we never decide on an unpinned meaning).**
Before descending from layer N, the **N-and-above subgraph must be postulate-free *among
itself*.** The only postulates permitted point strictly *downward*. A postulate pointing
sideways or up is a gap *within* the meaning — the gate is **not** passed, and we do **not**
descend. This makes "close the gaps" a yes/no check, not a feeling.

**Soft coupling (honour, do not reorder):** T's observation granularity (the `ℕ` depth) must
stay machine-realizable (depth = Ana unfold layers = machine loop iterations). That is a
design constraint on ②, *not* a reason to peek at ③ while fixing ②.

## MILESTONES (each = clean one layer; gate before the next)

- **L1 — Pin THE MODEL (①) at the machine Word.** *Footprint (measured 2026-06-17):* the
  ℤ model (`Semantics.IR`/`eval′`/`SigOpInfo.semI`) is **load-bearing for the entire
  algebraic proof layer** — `Surface/Correct` (83), `Category/Laws` (58), `Optimize/Correct`
  (39), `Fusion`/`Escape/Correct` (25 each), `TypeSystem/Soundness` (18), etc. — while the
  machine + meaning use ℕ, **with no bridge**. So this is a *migration*, not a delete, and it
  must land at the **real wrapping Word** (not the ℕ placeholder, which would misclassify
  truncation-breakage as bugs). Steps:
  1. **Reuse `Once.Word` (`module Width (bits)`)** — it already gives modular, signed
     (two's-complement) `⊕`/`⊖`/`⊗`/`⊝` + `fromℤ`, *total*, width-polymorphic via the `bits`
     module parameter (D054). Do **not** invent a Word and do **not** hard-code 64 — thread
     `bits` from the architecture instantiation. Fill the two gaps the decisions already name:
     **total division/remainder** (D055: `a/0=-1`, `a%0=a`, `INT_MIN/-1=INT_MIN`; per-arch
     guard) and **signed comparisons** (D054), defined *on `Word`*. (Caveat: D054 residue —
     width is not type-enforced; rely on the `bits` parameter, the typechecker won't police
     width-mixing.)
  2. **Instantiate the ONE value model at Word** (collapse `SigOpInfo`'s `semI`/`semM` to a
     single `sem`; `eval` is the one evaluator).
  3. **Migrate the ℤ proof layer to Word**, module by module (bounded red per module): a law
     that still holds (ring laws — most of them) is re-proven; a law that **fails under wrap**
     (overflow/order assumptions) becomes an **explicit `postulate` tagged UNSOUND + the
     precise wrap case** — the visible bug backlog.
  4. **Delete the ℤ subsystem** (`Semantics.IR`, `eval′`, the `*-semI` builders) once nothing
     imports it.
  **Gate:** `Semantics.Core` + the one `eval` (at Word) typecheck; the only postulates are
  the explicitly-tagged UNSOUND-on-hardware rules (documented), nothing else among ①.
- **L2 — Pin THE MEANING (②), fully linked to ①.**
  - Delete `obs`, `otrace` (second/third IR trace denotations); `⟦_⟧ᴰ` is the one.
  - Make `⟦_⟧ᴰ`/`⟦_⟧ˢ` values come *from the model* (`sem-cata`/`eval`), so `faithful`
    (incl. `cata`/`ana`) is **structural — no fusion lemma**.
  - Drive `emit` from `π`; delete `classify-name`'s name match.
  - Delete `SS.eval` and the `CompSim`/`ProdSim`/`prod-bridge`/`AnaTrace` islands.
  - **Gate (the critical one):** Model + Meaning + `faithful` typecheck with **zero
    postulates between ① and ②**; the only postulates left point down at ③/④.
- **L3 — Clean THE MACHINE (③).** Re-point the operational semantics / codegen at the clean
  `⟦_⟧ᴰ`; collapse machine-side trace duplicates. **Gate:** ①–③ postulate-free among
  themselves; only ④ postulated.
- **L4 — Prove ADEQUACY (④).** Discharge the one apex theorem
  `machine-trace ≡ projTrace ⟦src⟧ˢ` against the clean stack. **End state: zero postulates**
  (modulo the deliberate per-arch trust base: GNU `as`, asm printer).

## What survives untouched
The `T` monad machinery; the `erase` round-trip (now purely the *syntactic* typechecker-
faithfulness lemma, decoupled from the trace); the genuine transformation pipeline
(lexer → parser → checkElab → elaborate → ir-to-trace → target). None of these are
"second meanings"; they are the compiler and its syntactic checks.

## Working agreement on this branch
- **Delete-first, never bridge-first.** If tempted to "prove X ≡ Y to preserve X," stop —
  delete X, scaffold, rebuild from the meaning.
- **No "this is clear" until it typechecks.** (Five premature reversals this session; see
  `plans/0.46-HANDOFF.md` for the full list — keep it as the lessons file.)
- **Commit green-with-downward-postulates increments per layer**; revertible checkpoints.
- The apex is the only root; no free-standing relations; no fuel in the meaning.
