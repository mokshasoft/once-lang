# Plan: Prove All Cata Postulates for X86-64

## Executive Summary

Per OCP-0003, the **Implementation TCB must be PROVEN, not postulated**. This includes:
- `rec-scheme-semantic` - recursion scheme traces produce correct results
- `lambek-iso-semantic` - In/out-μ/Out/in-ν traces are identity

The Mathematical TCB (category theory facts like "Cata terminates") is safe to assume.

**Key Insight**: The architecture is already correct in `cata-dispatched-new`. The SMP.!! placeholders are mostly **compositional proofs** (combine sub-results) and **simple arithmetic** (capacity). This is NOT extremely hard - just needs methodical filling in.

## Implementation Plan (Most Impactful First)

### Phase 1: Fix Interface - Add Layer Validity to process-layer

**Why first**: This unblocks all the structural proofs. Currently `process-layer` doesn't receive validity for the layer, so it can't prove validity for results.

**The fix**:
```agda
process-layer : ∀ {F G A}
  (wfF : WellFormedF F) (wfG : WellFormedF G)
  (alg : IR (⟦ G ⟧T A) A)
  (dispatch : RecDispatcherWF (ir-size (Cata wfG alg)))
  (layer : ⟦ F ⟧F (⟦μ⟧ G))
  (mIn : AllocMode)
  (input-loc : ValueLocation FS)
  (s : LocState FS) (alloc : AllocState {FS})
  → ValidAtWF mIn alloc layer input-loc s  -- ADD THIS
  → BeforeFrontier alloc input-loc
  → ...
```

**Then the proofs become trivial**:
- K case: `processed-valid = layer-valid` (same value)
- Id case: `μ-val-valid = layer-valid` (Id layer IS the μ-value)
- Sum/Prod: compose from recursive calls

**Files**: `Once/CCC/Machine/IR/RecTrace.agda`

### Phase 2: Prove Lambek Validity (Representational Identity)

**Why**: Needed to pass validity from μ-value to layer in cata-dispatched-new.

**Key insight**: `sem-Out wf x` returns `coerce-functor⁻¹ F (μ-type F) (sem-Out' wf x)`. The coercion is representationally identity for well-formed functors.

**Files**: `Once/CCC/Machine/IR/LambekValidity.agda`

### Phase 3: Fill Compositional Proofs in cata-dispatched-new

**Why**: With interface fixed, these are just combining sub-results.

**Files**: `Once/CCC/Machine/IR/RecTrace.agda`

### Phase 4: Wire cata-dispatched-new into RecCoreWF

**Why**: Replace the stub trace in `run-cata-core` with actual `cata-dispatched-new` call.

**Files**: `Once/CCC/Machine/IR/RecCoreWF.agda`

### Phase 5: Remove rec-scheme-semantic Postulate

**Why**: With cata-dispatched-new proven, the postulate is no longer needed.

**Files**: `Once/CCC/Machine/IR/RecCoreWF.agda`
