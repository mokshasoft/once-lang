# Plan 0.49 — Relational correctness against the denotation (kill the corollaries)

## The flaw being fixed

Today `correct` relates `exec (compile src)` to `⟦ src ⟧⊥ = evalᴰ (moduleToIR src)`.
The front-end (`moduleToIR` = typecheck + elaborate) appears on **both sides**, so
it **cancels**: a front-end bug produces a wrong IR on both sides and `correct`
still holds. So `correct` forces only *codegen*; typecheck- and
elaborate-correctness are definitional, not forced. `accept-sound`/`⟦⟧⊥-sound`
patched this as **corollaries** — forgettable, not structural. (Symptom: `faithful`
sits as a standalone fact, used by nothing.)

The denotation (`Once.Denotation`: `evalᴰ`, `SD.⟦_⟧ˢ`) **is** the authored spec —
the one legitimate, reviewed trust point. The fix is purely structural: state
`correct` against that **independent** denotation, with the **declarative
judgment** (not `checkElab`) choosing the typed term, so nothing cancels.

## The genuine statement (relational; edits `Once.Adequacy`)

```
correct : ∀ arch doOpt src →
    -- SOUNDNESS + TRACE: accepted ⇒ src has a meaning AND the bytes run it
    ( ∀ bytes → compile arch doOpt src ≡ just bytes →
        Σ tp, (src ⊢ᵖ tp) × (∀ n → exec arch bytes n ≈ ⟦ tp ⟧ˢ n) )
  × -- COMPLETENESS: src has a meaning ⇒ it compiles
    ( ∀ tp → src ⊢ᵖ tp → Σ bytes, compile arch doOpt src ≡ just bytes )
```

- `src ⊢ᵖ tp` = the **program-level** declarative judgment: `src` parses to a
  module with a `main` whose body has a `_⊢ᶜ_` derivation `tp` (independent of
  `checkElab`/`elaborate`).
- `⟦ tp ⟧ˢ` = `SD.⟦_⟧ˢ`, the independent surface denotation (the spec).
- Two conjuncts in **one** statement (not separate record fields): proving
  `correct` requires BOTH; you cannot drop one without editing the reviewed spec.

Why it forces everything (nothing cancels):
- elaborate buggy ⇒ `exec(codegen(elaborate se)) ≉ ⟦se⟧ˢ` ⇒ fails (`faithful`
  becomes load-bearing here),
- typecheck unsound/incomplete ⇒ the `src ⊢ᵖ tp` ↔ accept mismatch fails,
- codegen buggy ⇒ fails (as today).

## Phase 1 — `Typed`/`_⊢_`/`⟦_⟧ˢ` via the intrinsic term (option ii, user-chosen)

`Typed` = the closed typed main term `Expr S∅ Ψ (Unit ⇒[ mk-kind Many eff ] Unit)`
(Eff Unit Unit, per `validateMain`). `⟦ tp ⟧ˢ` = `SD.⟦ tp ⟧ˢ tt` (its trace).
`src ⊢ tp` = `gmoduleToModule src ≡ just m` × the main's RawExpr `≡ erase tp` —
the intrinsically-typed `tp` IS its own well-typedness witness; `erase` (forget
types) is the declarative link to the source.

NEW pieces this needs (none exist today):
- `erase : Expr Γ Ψ A → RawExpr` — structural forgetful map (NEW).
- **erase round-trip for soundness**: from `checkElab src ≡ success … eE …`
  (the algorithm's term), need `erase eE ≡ main-raw` so `tp = eE` satisfies
  `src ⊢ tp`. UNCERTAIN — elaboration may insert nodes that don't erase back
  exactly; may need restriction or a NAMED postulate. **Verify before relying.**
- main-WRAPPING: `moduleToIR` wraps main (`maybeWrapMain`, Unit→Unit entry); the
  IR's `evalᴰ` is of the WRAPPED ir, but `⟦ tp ⟧ˢ` is the UNwrapped main. Connect
  `evalᴰ(wrapped) ` to `⟦ unwrapped-main ⟧ˢ` (wrap-denotation lemma).
