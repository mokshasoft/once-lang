The value fork was: compose sub-IR correctness for `∘`/`⟨,⟩`/`case`/`curry`/
`apply` via (1) flat-native composition, (2) a `SigOp`-free shadow dispatcher,
or (3) the canonical abstract `Dispatcher`. We chose 3 — **wrongly**. On trying
to instantiate it we found:

- **The `Dispatcher` is a superseded route-B fossil, red at HEAD, orphan.** The
  live apex track (`IRObsCorrectFlat`) imports neither the `Dispatcher` nor
  `ComposeWF`; `IRObsCorrectFlatness` takes **no** `sigOp-proof` (the live apex
  is provider-free). `ComposeWF`'s only importer is the `Dispatcher`; the
  `Dispatcher`'s importers are the WF producers + the orphan `IRTraceCorrect`.
  **0.36 explicitly lists this cluster for deletion** ("verified fossils, all to
  be deleted"; Phase 4 "deletes the whole rec-scheme cluster + the catchall").
- So Option 3 = "reuse the *proven* dispatcher" was false — it's route B, the
  thing `IRObsCorrectFlat` (route A) replaces. `ComposeWF`'s `at-reg`
  non-exhaustiveness (from this session's `ResultPlace` extension) is **moot** —
  it's a fossil being deleted, not machinery to repair.

Consequence: the SigOp-contract work from this session (total `Provider`,
`PureProvider`, `BuiltinProvider`) is **route-B/fossil-track** — it never harmed
the live (provider-free) apex, but it is not load-bearing and is retired here.
The live wins stand: `obs-correct-sigop`, the `id/fst/snd/terminal` carve,
`at-reg`, the `FlatSemanticLift` salvage, `ValidAtWFHalted` retire, all arith work.

Option 1 is the *only* live track: it never touches the fossil, works at the
`ValidAtWF` level (where `at-reg` is fine), and — since the abstract Dispatcher

## Phase 2 — `∘` and the other composites, flat-native (the core)

`obs-correct-compose` builds `MachineRefinesObsF (g ∘ f)` from the recursive IH
(`ir-obs-correct f`/`g`). Both fields decompose; ROADMAP (mapped 2026-07-04, all
infrastructure confirmed to exist — this is assembly, not discovery):

`ir-to-trace (g ∘ f) = trace(f) ++ mov-to-input ∷ trace(g)`;
`eval (g∘f) x = eval g (eval f x)`; `evalᴰ (g∘f) a = evalᴰ f a >>=T evalᴰ g`.

**`traces-agree`** (the hard half — trace-preservation over composition):
  * Denot side: `projTrace (m >>=T h) n = projTrace m n ++ projTrace (h (valueT m n)) n`
    (from `_>>=T_`, `TraceMonad.agda:55-59`). So RHS = `projTrace(evalᴰ f) ++
    projTrace(evalᴰ g (f-val))`.
  * Machine side: build `FlatSteps` for `trace(f)` (from `straight-ir-to-trace`),
    then `mov ∷ trace(g)`, compose with `FlatSteps-++`; then `flat-events-steps`
    (`FlatEvents.agda:168`) + `chain-events-++` (`:186`) split `flat-events` into
    `chain-events(f) ++ chain-events(g-from-post-f)`.
  * Combine the two `IH.traces-agree` through the `++`; handle the `take k` prefix
    of a concatenation (the fiddly bit: `take k (A ++ B)` splits on `k ≤ |A|`).

**`value-realized`** (rebuild the abstract sequential-composition value producer —
what deleted `ComposeWF.run-compose` did, cleanly at the `ValidAtWF` level so
`at-reg` register-resident intermediates work — no pointer hand-off):
  * `exec-trace-++` (`SMCore.agda:1856`) splits the run at `f`'s post-state.
  * Recurse for `f`/`g`'s value at the exec-trace level (leaves → `SimpleWF.run-*`;
    composites → this recursion), thread `Output→Input1` (mov-to-input) hand-off.
  * `lift-validAtWF-flat` once at the top → flat post-state.
