# Plan 0.58 — `Once.Spec`: one home for the language definition (OCP-0006)

Implements **OCP-0006** (`docs/proposals/OCP-0006-once-spec-language-definition.md`).
Purely **organizational**: gather the artifacts a reader must *trust and read* — the
type/syntax grammar, the typing rules, the meaning, and the correctness criterion —
under one namespaced, auditable `Once.Spec.*` door. **No proof or semantic change.**

Deferral prerequisite (D063 collapse + retiring the two false `*-eff-complete`
postulates) is **satisfied** (landed via plans 0.52–0.55; `⊢ᵐ` is in `Judgment`,
`Completeness:1606` replaced the false postulates). `Judgment` imports neither
`Denotation` nor `Elaborate`, so the layering is cycle-free.

## Approach: re-export first cut (OCP-recommended, low-risk)

Each `Once.Spec.X` is a thin module that `open import <source> public`. This creates
the namespaced door and the enumerable trust boundary **without moving files or
churning importers**. The heavier "make `Once.Spec` canonical" step (rewire
implementation importers onto `Once.Spec.*`) is explicitly **out of scope** here — see
M4 (a later plan).

## Boundary decisions (baked in — settle these, don't re-litigate)

- **`Once.IR` / `evalᴰ` stay OUTSIDE `Once.Spec`** (OCP option **a**): IR is a pure
  syntax vocabulary tier (no machine), shared by spec and impl like `Once.Type`.
  `Once.Spec.Meaning` re-exports `SourceDenote`/`Realize`/`DenotTrace` but **not** `Once.IR`.
- **`Once.Spec.Syntax` includes BOTH** `Once.TypeCheck.Raw` (what the programmer writes)
  and `Once.Surface.Syntax` (what the denotation reads).
- **`Once.Spec.Correct` = ONLY `Once.Adequacy`** (the `CorrectCompiler` record — the
  correctness *criterion*, proof-free). It is trusted because it is the *statement* of
  what we prove (a wrong/vacuous statement makes every machine-checked proof worthless);
  the proof and the `Once.Adequacy.*` sibling proof modules are checked, NOT trusted, so
  they are **not** re-exported. The instance (`Once.Compiler`) and its NAMED postulates
  (listed by `make postulates`) are trust-boundary but live in the instance — out of
  scope for the criterion module.

## Proposed layout

```
Once.Spec            -- umbrella; re-exports the whole language definition
Once.Spec.Type       -- ← Once.Type (+ Once.Functor.* type grammar, if present)
Once.Spec.Syntax     -- ← Once.Surface.Syntax + Once.TypeCheck.Raw
Once.Spec.Typing     -- ← Once.TypeCheck.Judgment        (⊢ᵢ/⊢ᶜ/⊢ᵍ/⊢ᵐ, Typed)
Once.Spec.Meaning    -- ← Once.Denotation.{SourceDenote, Realize, DenotTrace}
Once.Spec.Correct    -- ← Once.Adequacy                  (CorrectCompiler record only)
```

## Milestones

### M1 — the five leaf re-export modules
Create `Once/Spec/{Type,Syntax,Typing,Meaning,Correct}.agda`, each a header + the
`open import … public` lines above. Resolve any re-export name clashes with
`using`/`hiding`/`renaming` and DOCUMENT each in a comment (clashes are the only real
risk; e.g. overloaded `⟦_⟧` notations across `Type`/`Meaning`).
Verify each: `timeout 60 scripts/agda-safe.sh agda MODULE=Once/Spec/X.agda`.

### M2 — the umbrella
Create `Once/Spec.agda` = `open import Once.Spec.{Type,Syntax,Typing,Meaning,Correct}
public`. If cross-module clashes surface at the umbrella, prefer keeping the sub-module
as the canonical import point over aggressive renaming (note it in a comment).
Verify: `timeout 90 scripts/agda-safe.sh agda MODULE=Once/Spec.agda`.

### M3 — whole-tree check + trust-boundary sanity
- `make check-all` green (island-rot backstop; the new modules are now in the tree).
- `certified` unaffected (no apex change) — spot-check it still exits 0.
- Confirm the trust surface is enumerable: reading `Once/Spec.agda` + the five leaves'
  import lines names exactly the spec modules and nothing implementation.

### M4 — make `Once.Spec` canonical (OUT OF SCOPE — future plan)
Rewire implementation-package importers (`Elaborate`, `Soundness`, `Completeness`,
`Adequacy.*`, codegen…) to import from `Once.Spec.*`. High import churn; deferred so this
plan stays a clean, reversible organizational cut. Track as a separate plan.
