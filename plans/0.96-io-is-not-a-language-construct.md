# Plan 0.96 — `IO` is not a language construct

## 0. The correction that makes the case

`IO` is **already not an elaboration**. `Once/Type.agda:351-352`:

> Note: IO sugar removed for clarity in error messages.
> The parser desugars "IO A" to "Eff Unit A" at parse time.

There is no `IO` constructor in `Type`, nothing in the elaborator, nothing in
the denotation, nothing in codegen. D032 introduced it for one stated reason:

> **Why IO sugar:** Familiar to Haskell users (`IO ()` vs `Eff Unit Unit`).
> `IO A = Eff Unit A`. **No semantic difference, purely ergonomic.**

So the thing to remove is not a construct. It is **six hardcoded sites in the
parser**, three of which are in the VERIFIED parser's relations and therefore
carry a case through every soundness and completeness proof:

    Parser/Type.agda:219                  the ground parser
    Parser/Generic/Parser.agda:58         the generic parser
    Parser/Generic/Sound.agda:66          its soundness proof
    Parser/TypeRelation.agda:111          ParsesAtom  — the RELATION
    Parser/Generic/Relation.agda:103      extraMiss-IO
    Parser/Generic/Relation.agda:476      ParsesAtomG — the RELATION

That is the real cost, and it is why this is worth doing: the change DELETES
proof cases rather than adding them.

## 1. What the measurement says

    `IO` occurrences in .once sources   85, across 73 files
    Type constructors for IO            0
    Elaborator/denotation/codegen sites 0
    Parser sites                        6 (3 in relations + proofs)
    Type-alias mechanism                ALREADY EXISTS

The last line is the enabling fact. `Grammar.agda:179`:

    DTypeAlias : UpperIdent → List LowerIdent → GType → GDecl

parameterised aliases, with `Once/Parser/TypeAlias.agda`'s
`expandAliases : TypeAliasEnv → Type → Type`. So `type IO a = Eff Unit a` is
writable in the language TODAY. Nothing needs inventing.

## 2. The tension this must resolve: D027

**D027 — No Implicit Imports.** Once deliberately has no prelude. So a library
`IO` is not automatically in scope, and "move it to a library" means every
program that says `IO` must either import the module defining it or declare the
alias itself. 73 files.

This is the whole decision. The plan does not get to skip it.

## 3. THE OPTIONS — undecided, and the reason this is a plan

**A. Library alias, explicitly imported.**
A module (`Derived/Io.once`?) declaring `type IO a = Eff Unit a`; every user
imports it. Consistent with D027. Costs an import line in 73 files, and makes
the commonest signature in the language depend on an import.

**B. Delete `IO` outright; write `Eff Unit A`.**
No alias, no import, no prelude question, D027 untouched. 85 mechanical edits.
`main : Eff Unit Unit` instead of `main : IO Unit` — nine characters.

**C. Status quo.** Keep the sugar, accept the six parser sites.

**The plan's recommendation is B, and A is the trap.** A keeps the ergonomics by
spending exactly what D027 exists to prevent: a module every program must import
before it can write its own `main`. That is a prelude with extra steps. B costs
nine characters per signature and removes the special case at the root — the
parser stops knowing a type name, and three relation cases plus their proof
obligations disappear.

B also matches what D032 actually argued. Its justification for `IO` was
familiarity with Haskell, not a property of Once. `Eff Unit A` says what the
thing IS — an effectful arrow from nothing — and the language's own vocabulary
already covers it.

## 4. What NOT to do

Do not add a prelude to make `IO` free. That reverses D027 for an abbreviation,
and D027's own rationale is stronger than `IO`'s.

Do not leave `IO` in the parser and ALSO define the alias. Two spellings of one
type, one of them privileged by the grammar, is worse than either alone.

## 5. Gates

* the six parser sites gone, and the three relation cases with them;
* parser soundness/completeness still green with FEWER cases than before —
  if a proof gets longer, the change is wrong;
* 71/0/0 exit tests on three arches, `cabal test` green;
* `grep -w IO` over `compiler/test` and `Strata` returns nothing (option B) or
  only alias declarations and imports (option A).

## 6. Sizing

Mechanical and wide: 85 occurrences, 73 files, 6 parser sites. No new
machinery under either option. The risk is not difficulty, it is deciding §3
before editing 73 files — reversing it afterwards is another 73.
