# Plan 0.97 — The Spec must model termination

## 0. The one property

> **A program that calls a halting SigOp stops, and the Spec must say so.**

Today it does not. `T X = ℕ → List SigOpEvent × X` (TraceMonad:46) has no
channel for "this computation ended"; `_>>=T_` (:58) unconditionally runs the
continuation; and `emit-eff` (TraceDenote:63) / `emit-D` (ValueDomain:323)
treat `Halts` IDENTICALLY to `Emits` — one event, value `tt`, carry on. So the
denotation of `exit 0; print "x"` emits BOTH events. The machine, correctly,
emits one.

## 1. The measurement — verified 2026-09-22

`Once.Probe.HaltsRefute` (untracked) typechecks. It proves that for a `Halts`
SigOp NO `MachineRefinesObsF` witness exists at all:

  * `exec-sigop-halts-of (Halts _) ≡ true` — the instruction sets the flag;
  * `ValueRealized.live` demands `halted (floc settle) ≡ false`;
  * `at-end` demands `fpc settle ≡ 1 + base`, which only executing that
    instruction reaches.

Zero steps leaves the pc at `base`; one step sets the flag; two steps need the
flag clear to take the second. All three branches close.

`Halts` is not hypothetical: `Elaborate.agda:1953`/`:2006` build `haltsV refl`
from an `se-halts` declaration, which is how `exit` is declared.

### What this is and is not

It is NOT a compiler bug. For `main = exit 0` the EVENTS already agree. It is
an unsatisfiable side-condition: `live` was written to match a Spec that says
programs never stop, so no exiting program — i.e. no program — can satisfy it.

## 2. The encoding, and why this one

    T X = ℕ → List SigOpEvent × Stopped × X          (Stopped = Bool)

`Halts` already forces `B ≡ Unit`, so the VALUE after a halt is `tt`
regardless — nothing has to become optional. Only the EVENTS must stop.

Rejected: `T X = ℕ → List SigOpEvent × Maybe X`. It retypes `valueT`, and
`TM.valueT (evalᴰ ir x) k` appears in the `ResultPlace` of every discharged
clause. The flag leaves `valueT`'s TYPE alone, so those sites are untouched.

`projTrace` and `valueT` KEEP THEIR TYPES; only their definitions move. 50
modules import `TraceMonad`, and that is what keeps the ripple to the ~52
sites that destructure a `T` result directly rather than through an accessor.

## 3. The obligation gets STRONGER, not weaker

`ValueRealized.live : halted (floc settle) ≡ false` becomes

    halted (floc settle) ≡ stoppedT (evalᴰ n l ir x) k

— the machine halts EXACTLY when the Spec stops. The present field is the
`false` case of this one. `comp-obs-correct` then matches structurally: if `f`
stopped, `g` does not run, on either side.

## 5. The gate

Stage C's "each clause supplies `false ≡ false`" is the load-bearing guess.
PROBE IT FIRST: if `stoppedT (evalᴰ n l ir x) k` does not reduce to `false`
for a non-SigOp constructor, every discharged clause needs real work and the
cost estimate is wrong.

## 6. What NOT to do

Do not encode stoppedness as a synthetic event in the list. The event list is
the observable; a marker in it would be observable too, and `obs` would then
distinguish programs by how they ended rather than by what they did.
