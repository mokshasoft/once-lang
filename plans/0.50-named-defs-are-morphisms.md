# Plan 0.50 — Named definitions are morphisms (direct-call ABI)

Implements **decision-log D064** (read it first). Corrects the universal closure-returner ABI
(D019/D053): a top-level `f : A → B` is a **morphism**, compiled to a direct symbol / `IR.SigOp`
arrow (`once_f(a):B`, direct call); `curry`/closure is emitted **only** at genuine value-use sites.
Enabled by D063 (the `⊢ᵐ`/`t-lam` distinction lets a call site tell "call a morphism" from "apply a
closure value"). Subsumes Plan 0.40 residual-3 (first-order-lambda-as-morphism).

## Why deferred / separable

`realize-morph` already uses the principled `m-named ↦ IR.SigOp`; `realize-agrees` bridges the
current closure ABI via the β/uncurry iso (morphism ≡ uncurried-closure). So Plan 0.49 needs no ABI
change. This plan turns that bridge lemma trivial and pays down the conflation at codegen.

## Canonical naming (folded in 2026-06-25 — the `realize-agrees` unblocker)

At the module level there is **no SigOp/function distinction** — every definition is just a function,
named by its **resolved module path**; "compile to a SigOp" is a *leaf* codegen choice for
interpretation functions. The only hard constraint is the symbol/trace name must be **clash-free**.
Today this is broken: the parse-time canonical `path` (`DImport path alias`) is discarded; the
typecheck `Imports` table keys by the as-written `alias.name`; the elaborator's `ext-arrow-info`
names a `SigOp` by the **bare** op name (`once_foo` ⇒ `A.foo`/`B.foo` collide); and `realize` used
the (alias-unstable) `alias.name`. So `realize-agrees`'s qualified case is currently *false*.

**Scheme (locked in):** the canonical name is the resolved component list `[path…, name]`; the symbol
is `once_` + `_`-joined `<len><z-encoded-component>` segments, centralized in `Once.Target.Symbol`.
- **z-encoding** (escape letter `z`) makes each component asm-safe — the only unsafe identifier chars
  are `' + * ! ?` (lexer `isIdentContinue`): `z→zz`, `'→zq`, `+→zp`, `*→zt`, `!→zb`, `?→zh`; all else
  passes through. Injective on all strings (z self-escapes).
- **length-prefix + `_`** carries structure / clash-freedom (subsumes the `Cars.All_foo` vs
  `Cars.All.foo` ambiguity). Needs each component non-digit-leading = exactly lexer `isIdentStart`.
- **Injectivity** (`once-symbol-injective`) proved in `Once.Target.Symbol` under precondition
  `All ValidIdent components` (a SHARED predicate = lexer `isIdentStart`/`isIdentContinue`, single
  source of truth, no lexer import into codegen); discharged by a `lexer-produces-ValidIdent` lemma
  and composed only at the end-to-end no-clash theorem. Same "injective static encoding" discipline
  as the Label work (memory: injectivity-not-lockstep).

## Milestones (rough; flesh out when picked up)

0. **Canonical naming (NEW, prerequisite for `realize-agrees`):** `Once.Target.Symbol` = z-encode →
   length-prefix → `_`-join, over `[path…, name]`; `once-symbol-injective` under `ValidIdent`; thread
   **alias→canonical-path** through the import table (stop discarding `DImport`'s `path`). Update
   `ext-arrow-info` (and `realize`'s `t-var-qualified`/`t-var-import`) to name by the resolved path.
1. **Elaborator:** arrow-typed `sigOp`/`closure`/named-ref → direct `IR.SigOp` morphism (not
   `curry(SigOp ∘ snd)`); a first-order lambda whose body needs no exponential → a morphism. `curry`
   stays as the exponential introduction at genuine value-use sites only.
2. **Use sites:** `f arg` for a named morphism → direct call (not `apply (closure "f") arg`); the
   `⊢ᵐ` vs `t-lam` distinction selects direct-call vs apply.
3. **Calling convention / codegen (D053):** `once_f` ABI = the arrow itself (canonical-path symbol
   per milestone 0); backends (x86-64 first) emit direct calls; closures (value-use) keep the
   existing record/apply path.
4. **Verification:** update the closure/apply WF machinery (`Apply*`/`Curry*`, `valid-closure-wf`,
   DirectSimulation/Corresponds) — the expensive part; scope it like the original Apply/Curry work.
5. **MAlonzo bridge** NameIds sync; binary check (`arith-simple` still exits 13; a named-fn program
   compiles to direct calls).
6. **Collapse the now-trivial bridge:** once the ABI is morphism-direct, `realize-agrees`'s
   `m-named` clause is `refl`-level (no uncurry iso to launder).
