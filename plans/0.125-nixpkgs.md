## 0. Where this starts

- search.nixos.org/packages indexes the nixpkgs channels only. A flake in this repo is not listed; the
  package has to be merged into `NixOS/nixpkgs`.
- The flake builds with `callCabal2nix`, which is import-from-derivation; nixpkgs forbids it.
- An installed `once` cannot find `Strata/`: `findStrataDir` walks up from the input and from the CWD and
  falls back to `./Strata`. Outside a checkout every build fails.
- Building writes `.o` files INTO the Strata tree (`<impl>.<arch>.o`, `Host.<arch>.o`). In the read-only
  `/nix/store` that fails; it is also why the test suite runs with `NumThreads 1`.
- `once` shells out to `as`, `ld`, `objcopy` (or `$AS`/`$LD`/`$OBJCOPY`). The package must provide them.
- Hackage already has a package named `once` (memoization). `pkgs.once` is free but ambiguous.
- `once.cabal` still carries the stack template's `githubuser/compiler` URLs.
- `nix build` fails at install: `compiler/LICENSE` is a symlink to `../LICENSE`, which dangles in a
  source of `compiler/` alone (since `5889dbe0a`).

## 1. Decisions

- **Name.** The nixpkgs attribute and `pname` are `once-lang`; the executable stays `once`
  (`meta.mainProgram = "once"`). The cabal package keeps the name `once`; that only matters if it is
  ever published to Hackage, which this plan does not do.
- **Route.** `pkgs/by-name/on/once-lang/package.nix` with a cabal2nix-generated
  `haskellPackages.mkDerivation` and `fetchFromGitHub` on the release tag, wrapped with
  `justStaticExecutables`. Not Hackage (name clash, and the generated MAlonzo tree is a poor fit).
- **Strata lookup order.** `--strata DIR`; else a `Strata/` found walking up from the input, then from the
  CWD (a project's own Strata wins); else the installed copy at `<bindir>/../share/once/Strata`; else
  `./Strata`. No environment variable: `--strata` already is the explicit override.
- **Objects go beside the output.** Each impl/Host object is `<output>.<module path>.o`, removed with the
  program's own `.o` unless `--save-temps`. The Strata tree is only read.

## 2. Phases

### A. The compiler reads Strata only (this branch)
1. `assembleImplFiles`/`assembleHost` write their objects beside the output, not the source.
2. Update the `NumThreads 1` comment in `test/Spec.hs` (the shared-object race is gone; whether to drop
   the serialisation is a separate question, not this plan).

### B. An installed compiler finds its Strata (this branch)
1. `findStrataDir`: the installed fallback (§1).
2. The flake installs `Strata/` (without objects) to `$out/share/once/Strata` and wraps `once` with
   binutils on the PATH (`--suffix`, so a user's `AS`/`LD` or own toolchain wins).
3. Verify outside the checkout: `cd $(mktemp -d)`; build and run a hello world with `./result/bin/once`.
   Done 2026-10-27: `examples/hello.once` exits 42 on x86_64 and x86_32 under `env -i PATH=/nonexistent`
   (binutils from the wrapper only); no `.o` in the store or left beside the output.
4. The flake's source is `compiler/` plus the root `LICENSE` (a fileset, `sourceRoot` = `compiler`), the
   shape `fetchFromGitHub` + `sourceRoot` will have in nixpkgs.

## 3. The package

`packaging/nixpkgs/once-lang/package.nix` is the file the nixpkgs PR adds as
`pkgs/by-name/on/once-lang/package.nix`. The Haskell part is `cabal2nix ./compiler` inlined (base,
containers, directory, filepath, process, text); regenerate it when `once.cabal`'s dependencies change.
`packaging/nixpkgs/test.nix` builds it against the flake's pinned nixpkgs.
