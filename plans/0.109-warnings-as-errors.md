# Plan 0.109 — Warnings are errors

## 0. The incident

Plan 0.92 batch 1 removed a `public` re-export. One module had reached `Arch`'s constructors only
through it, so in

    arch-semantics x86-64 = …
    arch-semantics x86-32 = …

`x86-32` was no longer in scope, and in a PATTERN Agda reads an unbound name as a fresh
VARIABLE. The first clause became a catch-all, and every arch got x86-64's semantics. Agda
reported nothing but `UnreachableClauses`, a warning. The defect surfaced only as a type error
two modules downstream, by luck.

This is **meaning drift, not inconsistency**: nothing becomes inhabited that was not, and ⊥ is
no easier to prove. It is harmless in implementation code, because a drifted implementation stops
matching the Spec and the proof breaks. It is NOT harmless where the drifted definition is:

* **in the Spec** (`Once.Spec` closure): the theorem is still proved, about the wrong claim;
* **in the trusted model** (the `ArchSemantics` instances, `RunTraceCore`, the residual
  interfaces): the same, one level down;
* **shared by both sides of a correspondence**: both move together and the proof still checks.

The same pattern recurs: `RewritesNothing` hid an unsolved implicit (memory
`feedback_vacuous_rewrite_is_a_warning`), a retired constructor's leftover clause became a silent
catch-all (memory `feedback_retired_ctor_catchall_trap`), and a stale `using` entry
(`ModuleDoesntExport`) hides a moved name. In each case the warning was the only signal.

## 1. What Agda 2.8 offers

* `-W error` (also `--warning=error`) turns ALL warnings into errors. There is **no
  per-warning error switch**. `-W noX` silences warning X entirely, which is the opposite of what
  we want.
* `PatternShadowsConstructor` (default on) fires when a pattern variable has the name of a
  constructor of the variable's TYPE, whether or not that constructor is in scope
  (`TypeChecking/Rules/LHS.hs`). *Corrected 2026-10-05:* this section first said it does not fire
  for an out-of-scope constructor. Measured: with `open import ArchA using (Arch)`,
  `f x86-32 = …` warns `The pattern variable x86-32 has the same name as the constructor
  Arch.x86-32`. So the incident did produce this warning as well as `UnreachableClauses`. It went
  unseen among the rest, and under `-W error` it is now a build error at the definition.
* Already fatal: `NotStrictlyPositive`, `TerminationIssue`, `UnsolvedMetaVariables`.

So the end state is `-W error` in `Once.agda-lib`. The route is a ratchet, because the tree carries
pre-existing warnings (at least the `CoverageNoExactSplit` family, and deprecations such as
`<-transˡ`).

## 2. The warnings that matter (the classes to kill first)

| warning | why it is dangerous here |
|---|---|
| `UnreachableClauses` | the visible symptom of a captured constructor; also of a duplicated clause |
| `CoverageNoExactSplit` | a clause that is not a definitional equation; downstream `refl`s may silently stop holding where we assumed they did |
| `RewritesNothing` | a `rewrite` that does nothing usually means an unsolved implicit or a wrong equation |
| `ModuleDoesntExport` | a stale `using` name, often a moved identifier (plan 0.92) |
| `UselessPublic`, `DuplicateUsing` | import hygiene; the plan 0.92 lint already treats them as failures |
| `PatternShadowsConstructor`, `AsPatternShadowsConstructorOrPatternSynonym` | the incident itself: a pattern variable named like a constructor of its type |
| `DeprecationWarning`, `UserWarning` (stdlib deprecations) | cheap; keep the tree on current stdlib names |
| `UselessAbstract`, `UselessInline`, `InvalidCatchallPragma` | pragma noise that hides the real warnings |

## 3. Steps (top-down, ratchet-first)

### S0 — Census and ratchet  ✅ (2026-10-05)

Found while doing it: no cold build is needed. Agda REPLAYS a module's stored warnings when it
loads it from its interface, imports included, so a warm check of the roots reports the whole
closure.

A full, fresh typecheck of everything (`Once.Certified`, `Once.Compiler`, and the island backstop's
`EverythingFiltered`), keeping the complete warning log. Count per (module, warning name). Add
`scripts/warning-gate.sh` + `scripts/warning-gate.baseline` in the mould of `pragma-gate.sh` and
`public-gate.sh`: a module's count for a warning may only go DOWN; a warning not in the baseline
fails the gate. Add `make warning-gate`.

*Note:* Agda prints warnings only for modules it actually checks in that run. The gate must run on
a clean `_build` (or on the modules whose interfaces were rebuilt), or it reads an incomplete log.
The census is a cold build: schedule it when the machine is otherwise idle.

*Creates:* the ratchet. The number can only fall from here, and the incident's warning class can
never come back unnoticed.

### S1 — `UnreachableClauses` to zero

Each one is either a duplicate clause (delete it; two were found in `ArithSimCore` during plan
0.92) or a captured constructor (a real bug: restore the import, then check the definition's
meaning). Read every one; do not mass-delete.

### S2 — `RewritesNothing`, `ModuleDoesntExport`, the import-hygiene set

Mechanical, but each `RewritesNothing` is read first: per the memory, the cause is usually an
unsolved implicit, found with a `⊥-elim` probe.

### S3 — `CoverageNoExactSplit`

The largest class. For each site, either:
* make the clause split exactly (enumerate the constructors the catch-all covered), when downstream
  proofs rely on its equations; or
* mark the catch-all `{-# CATCHALL #-}`, when it is a deliberate fallback (the project already
  uses the pragma in about 31 places).

Do NOT enumerate blindly: memory `feedback_catchall_preserves_reductions` records that enumerating a
catch-all can BREAK downstream reductions. Measure (typecheck the cone) after each module.

### S4 — Deprecations and the rest

Stdlib deprecations (`<-transˡ` → `<-≤-trans` …) and pragma noise.

### S5 — Flip the switch

`flags: --exact-split --guardedness -W error` in `Once.agda-lib`. Delete the baseline and keep
the gate as a no-op check. Add a line to MERGE.md's gate list. From then on any warning, the
incident's included, is a build failure.

## 4. Gates

* Every step: the apex and the island backstop green, nothing newly skipped.
* No behaviour change: the plan touches no semantics, so the exit tests on all three arches and
  `cabal test` must not move. S1 is the exception: a captured constructor IS a behaviour change, and
  fixing it may legitimately move a test. If one does, that is the evidence, and it gets a
  decision-log entry.
* The baseline only shrinks.

## 5. Risks

* **Cold-build cost.** The census and each S3 measurement need fresh checks of large cones. Use
  `scripts/agda-safe.sh`, one run at a time.
* **Generated / extracted code.** MAlonzo extraction is unaffected (warnings are a typecheck
  concern), but the extraction gate must be rerun after S3, since exact-split rewrites can change
  compiled clause order.
* **Islands.** Modules already skipped by the backstop (red islands) are outside the gate. They are
  listed in its baseline as "unchecked", not as "clean".

## 6. Outcome (2026-10-05)

| class | count | fix (all behaviour-preserving) |
|---|---|---|
| `UserWarning` (stdlib deprecations) | 354 | renamed to the replacements (`≤-step`→`m≤n⇒m≤1+n`, `<-transˡ/ʳ`, `Data.List.any`) |
| `CoverageNoExactSplit` | 298 | `{-# CATCHALL #-}` on every listed clause (≈340); one pattern-lambda lifted to a named local, where the pragma is allowed |
| `ModuleDoesntExport` | 16 | stale `using` entries removed; three imports had a one-line import WEDGED before their continuation `using`, which then attached to the wrong module while the intended one was opened wholesale — restored |
| `UnreachableClauses` | 7 | deleted after reading each: duplicates, superseded fallbacks, and `fusion-once arr` — a retired constructor captured as a variable, shadowing identity clauses only |
| `RewritesNothing` | 7 | removed (same goal, same proof) |
| `UselessPrivate` | 1 | removed |
| `InversionDepthReached` | 1 | `--inversion-max-depth=100` on `SlotBudget` (with its reason) |

Two things the plan did not foresee:
* **Replay is incomplete.** Agda replays stored warnings for most classes, which made the warm
  census possible, but `InversionDepthReached` surfaced only in a fresh check. The S5 flip
  forced that cold check and is what found it — the census alone was not proof of zero.
* **Extraction** needed `--no-main` once warnings became errors (`Once.Compiler` is a library).

S0's ratchet (`warning-gate`) is deleted: with `-W error` there is nothing for it to count.
The rule is in MERGE.md §4d.

### 6a. Follow-up: which CATCHALLs to enumerate (2026-10-05)

`{-# CATCHALL #-}` is allowed under `--safe`, so the S3 markers are not a safety hole. The
hazard they leave is the plan's own: a NEW constructor silently falls into the fallback. A
classifier over the 395 marked clauses gives:

| class | sites | meaning |
|---|---|---|
| small | 19 | single-level fallback over a short constructor list |
| large | 71 | fallback covers many constructors (e.g. `Token`, `RawExpr`) |
| multi | 86 | fallback over several arguments at once (a diagonal / matrix) |
| with | 72 | inside a `with`-chain |
| shape | 92 | nested patterns / literal-indexed |
| otherpos | 14 | the fallback is not the last clause |
| type | 41 | a fallback over `Type` / `IRTy` |

Of the 19 small sites, **13 are now enumerated** (same right-hand sides, no proof changed):
`sv-nz`, `sv-succ`, `sv-pred`, `sv-tag-val`, `readTyped-int`, `readTyped-float`,
`exec-sigop-halts-of` (SMCore); `sv-is-zero` (Flat); `PtrB` (FlatPtrBounds); `StackPtrOK`
(FlatStackPtr); `pgProj`, `pgSchema` (Principal); `is-ptr` (ShapeTable). The `StoredValue` and
`EffectShape` helpers are the model's own dispatch, where a new constructor must be classified on
purpose.

**6 are kept**, each for a reason:
* `≟k-aux` (Type), `≟T-⇒-aux`, `≟T-ν-aux`, `≟T-rigid-aux` (DecEq): deliberately
  catch-all-FIRST "decided sooner" helpers (their design comments say so); enumerating would
  square the clause count.
* `load-snd` (ShapeTable): the fallback is `e-any`, the weakest claim, so it is sound for any
  future constructor; it covers about eleven shapes.
* `LabelScope.go`: an index-dependent diagonal over `CurryLoc` whose clause order carries the
  absurd-case proofs.

The other 376 stay marked. Enumerating them is a per-site judgement
(`feedback_catchall_preserves_reductions`), not a mechanical step.
