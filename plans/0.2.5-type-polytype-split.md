# Plan: Separate Type from PolyType to Remove Optimization Postulates

## Problem Statement

Tests are failing because postulates in `Once/Optimize.agda` are evaluated at runtime:
- `optimize-compose`
- `optimize-pair`
- `optimize-case`

Root cause: "type index unification issues" when pattern matching on IR constructors. The presence of `TVar` in `Type` complicates type equality and coverage checking.

## Goal

Separate ground types (`Type` without `TVar`) from polymorphic types (`PolyType` with `TVar`). This enables:
1. Clean decidable equality on `Type`
2. Simpler pattern matching in optimization functions
3. Removal of the optimization postulates

## Data Flow After Refactoring

```
RawExpr (untyped)
    | inferElabImpl (uses PolyType for unification)
PolyExpr (indexed by PolyType)  -- NEW intermediate representation
    | extract (fails if TVar remains)
SExpr (indexed by Type)         -- Ground types only
    | elaborate
IR A B (indexed by Type)        -- No TVar in type indices
    | optimize                  -- Pattern matching works cleanly
IR A B (optimized)
```

## Phase 5: Principled Extraction via Substitution (REVISED)

**Key insight**: Extraction cannot work by just checking `extract A = just A'` on the result type. Subexpression types may still contain TVars. The principled approach requires:

1. **Explicit substitution** from type inference
2. **Completeness proof** that all TVars are resolved
3. **Two-step extraction**: apply substitution → extract ground PolyExpr

### Standard Type Checking Phases

```
1. Constraint Generation  → PolyExpr with TVars + Constraints
2. Constraint Solving     → Substitution σ : TVar → Type
3. Substitution Application → Ground PolyExpr (no TVars)
4. Extraction             → Expr (total, cannot fail)
```

### Phase 5a: Ground Predicate and Total Extraction

**File**: `Once/Type.agda`

```agda
-- Predicate: PolyType has no TVars
Ground : PolyType → Set
Ground PUnit = ⊤
Ground (A P* B) = Ground A × Ground B
Ground (TVar _) = ⊥
...

-- Total extraction (no Maybe needed)
extractGround : (A : PolyType) → Ground A → Type
extractGround PUnit _ = Unit
extractGround (A P* B) (ga , gb) = extractGround A ga * extractGround B gb
extractGround (TVar _) ()  -- impossible
...
```

### Phase 5b: Substitution Infrastructure

**File**: `Once/Type.agda` or new `Once/Subst.agda`

```agda
Subst : Set
Subst = String → Maybe Type

applySubstType : Subst → PolyType → PolyType

-- Predicate: substitution covers all TVars in type
Complete : Subst → PolyType → Set

-- Key lemma: complete substitution produces ground type
complete→ground : (σ : Subst) (A : PolyType)
                → Complete σ A → Ground (applySubstType σ A)
```

### Phase 5c: Expression Substitution and Extraction

**File**: `Once/Surface/PolySyntax.agda`

```agda
-- Apply substitution to expression
applySubstExpr : (σ : Subst) → PolyExpr Γ A
               → PolyExpr (applySubstCtx σ Γ) (applySubstType σ A)

-- Ground predicate for expressions
GroundCtx : PolyCtx n → Set
GroundExpr : PolyExpr Γ A → Set

-- Total extraction (no Maybe!)
extractGroundExpr : (e : PolyExpr Γ A) → GroundCtx Γ → GroundExpr e
                  → Expr (extractGroundCtx Γ) (extractGround A)
```

### Phase 5d: Connect to Type Inference

**File**: `Once/TypeCheck/Elaborate.agda`

Type inference returns:
```agda
record InferResult (n : ℕ) : Set where
  field
    ctx      : PolyCtx n
    type     : PolyType
    expr     : PolyExpr ctx type
    subst    : Subst
    complete : CompleteExpr subst expr  -- proof all TVars resolved
```

The pipeline becomes:
```
inferElabImpl → InferResult
    ↓ applySubstExpr (using subst and complete proof)
PolyExpr Γ' A'  (guaranteed ground)
    ↓ extractGroundExpr
Expr Δ T        (total, cannot fail)
```

### Design Decision (2026-04-16)

**Problem**: Initial extraction approach tried to extract PolyExpr → Expr by checking
`extract A = just A'` on result types. This failed because subexpression types
(e.g., function domain in `papp`) may contain unresolved TVars even when the
result type is ground.

**Solution**: Principled two-step extraction:
1. Apply complete substitution from type inference
2. Extract ground PolyExpr to Expr (total function, cannot fail)

This follows standard type checking architecture where the substitution is a
first-class value produced by unification and explicitly applied.
