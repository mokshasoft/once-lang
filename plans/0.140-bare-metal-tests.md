# Plan 0.140 — The tests run on bare metal, not only under Linux

## Summary

Every test program today runs as a Linux process, either natively or through QEMU's Linux emulation.
So Linux is quietly part of every test: it starts the program, prints its output and reports how it
ended. Once is meant to run on bare metal with no operating system. This plan adds a second way to run
the same tests: on an emulated bare machine, with a minimal "host" layer that starts the program, writes
output to a serial port and reports the end to the emulator. When it is done, the test suite shows the
compiler's programs work without Linux, and the host layer it builds is the first step toward seL4 and
small boards.

## 1. Why

A Host (D320) is how a platform runs a program: `enter ; main ; leave`. The compiler knows no platform;
only the Host does (D349). But the only Host is `Strata/Hosts/Linux`, and every test observation goes
through Linux system calls:
- **exit tests** (`tests/run-exit-tests{,-x86_32,-riscv64}.sh`, 176 programs) run a static ELF natively or
  under `qemu-i386` / `qemu-riscv64` *user mode*, and read the process exit status;
- **trace tests** (`compiler/test`, `Backend.Common.buildAndRunTrace`, `traceCases`) import
  `I.Test.Emit`, whose `emit` is a Linux `write` (`Strata/Interpretations/Test/Emit.<arch>`), and read
  stdout;
- the end of a run is Linux's: `once_leave` is `exit_group(0)`, and on the heap branch `once_exhausted` is
  `SIGABRT`.

So the claim "Once runs without an OS" is untested, and the Host contract has exactly one implementation,
which makes it easy for Linux assumptions to leak into it unnoticed.

## 2. Where we are

- Hosts: `Strata/Hosts/Linux/Host.{x86_64,x86_32,riscv64}` (`once_leave`; on `origin/0.123-heap` also
  `_start` with the region set-up and `once_exhausted`).
- Interpretations used by tests: `Strata/Interpretations/Test/Emit.*` (trace bytes via `write`), and
  `Strata/Interpretations/Linux/*` (`exit@S`, files, argv).
- Runners: the three exit-test scripts; `compiler/test/Backend/Common.hs` (`archRunPrefix`: native,
  `qemu-i386`, `qemu-riscv64`; `archToolEnv` for the cross binutils).
- seL4 interpretations exist (`Strata/Interpretations/SeL4`) but no seL4 Host (plan 0.127).

## 3. Decisions

- **D1, the machines.** Recommended: QEMU system emulation with devices that let the guest end the
  emulator with a status: riscv64 `virt` (UART 16550 at 0x1000_0000; the SiFive test finisher at
  0x10_0000), x86_64 and x86_32 `pc` with `isa-debug-exit` (status `(v << 1) | 1`) and the COM1 UART;
  booted by Multiboot (`-kernel`) on x86, by `-bios none -kernel` on riscv64. Open.
- **D2, what is observed.** The run's end and its trace. Recommended: the bare-metal Host maps
  `returned` and `exhausted` to two distinct finisher codes, and the test Interpretation's `emit` writes
  the trace bytes to the UART, framed exactly as the Linux one writes them to stdout, so the same expected
  trace is compared. Exit codes from `exit@S` are Linux-specific: those tests either get a bare-metal
  `exit` (the finisher carries the code) or stay Linux-only. Open.
- **D3, which tests run where.** Recommended: a host is a test parameter (`ONCE_TEST_HOST=linux|bare`),
  the trace tests and the exit tests run under both, and a test that needs Linux (files, argv) says so
  and is skipped on `bare` with its reason. Open.

## 4. Steps

1. `Strata/Hosts/BareMetal/Host.riscv64`: `_start` (stack, the heap region as the heap branch defines it,
   then `once_main`), `once_leave` and `once_exhausted` (finisher codes, D2). A linker script for `virt`.
   Check: one hand-written program boots and ends with the `returned` code.
2. `Strata/Interpretations/Test/Emit.riscv64` for bare metal: the UART instead of `write` (selected by the
   host; how `once build` picks per-host Interpretations is part of this step).
3. `once build --host bare` (or the host as a Strata path; decide with step 2), linking the bare-metal
   Host instead of Linux's.
4. The runners: `archRunPrefix` and the exit-test scripts take the host (D3); `qemu-system-riscv64`
   with a wall-clock cap, the finisher code mapped back to the expected end.
5. x86_64 and x86_32: Multiboot header, long-mode / protected-mode entry, COM1, `isa-debug-exit`.
6. Docs: the Host contract section (D320/D349's statement) lists both Hosts; a decision entry.

## 5. Done when

The trace tests and the exit tests that do not need Linux pass under `ONCE_TEST_HOST=bare` on all three
arches, with the same expected outputs as under Linux, and the CI/test docs say how to run them.

## 6. Next step

Decide D1–D3 with the user. Then, after `origin/0.123-heap` has merged (its `_start`/region/
`once_exhausted` is the contract), step 1 on riscv64: it has the simplest bare machine.
