# Plan 0.117 — Once is total and productive, and a server is an ordinary function

## 0. Why

GOAL.md requires servers. Today no Once program can run forever: `Eff A B` means `A → T B` and
`T` is inductive, so every effectful function ends after finitely many events (D311 §Context).
And the Spec does not state the property the language is built on — that it is TOTAL (a pure
computation is a value) and PRODUCTIVE (each next event comes after finite work). D311 decides
both: a T+P part in `Spec.Metatheory`, the free completely iterative monad for effectful
computation that may run forever, guarded iteration as the server construct, `main` unchanged.

## 1. The mathematics (what a reader of the Spec should find)

* `T X` — the free monad on the call/halt signature `Σ`: the INITIAL algebra of
  `Y ↦ X + Σ Y`. Finite trees. Effectful computation that returns.
* `T∞ X` — the free completely iterative monad: the FINAL coalgebra of the same functor. Possibly
  infinite trees, no silent step. `T ↪ T∞`.
* Guarded iteration: for `f : A → T (B + A)` guarded (an event before every `inr`),
  `iter f : A → T∞ B` is the unique `x` with `x = f >=> [ret, x]` (up to bisimilarity).
* T+P: `M pure X = X`; `T X` is well-founded (`FiniteT`); every `T∞` tree is productive by the
  shape of its functor (no silent node); `Behavior n` of any program is computed by a total
  function of `n`.

  conclude at the product; the graded bind `bindᵍ π₁ π₂ : M π₁ X → (X → M π₂ Y) → M (π₁ ·p π₂) Y`
  and its law `toT-bindᵍ` (`Effects`); `⊢composeᶜ`/`⊢pairᶜ` take `π₂ ·p π₁ ⊑π π` (their arrow
