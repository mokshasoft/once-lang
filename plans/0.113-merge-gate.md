## B. Spec fixes (user: fix before the merge)

* **B1 — `cata`/`ana` scale their algebra's usage by ω.** QTT's eliminator rule: the fold applies its
  algebra once per node, so everything the algebra captures is used ω times (D232's own argument;
  D265/D273 let algebras capture). Today `t-cata-check`/`t-ana-check`/`d-cata`
  (`TypeCheck/Judgment.agda:697,719,945`) and the core's `⊢fold`/`⊢unfold`
  (`Spec/Core/Typing.agda:123,133`) conclude with the algebra's usage unscaled. Change: `Many *ᵘ Ψ`
  (core: `Many *ᵘ Ψa +ᵘ Ψt`). Blast radius ~19 files (elaborator, Completeness, ModeAgreement,
  meaning bridges, Translate); only AFFINE captures inside algebras become errors. Test: the
  matrix's row-20 probe (`f : Int^1 -> …; f k = cata (… k …)` rejected) + a `Many` capture accepted.
* **A3 — a `Zero`-quantity effectful op is not a constant.** `Spec/Contract.agda:91`
  `contractOf c (A ⇒[Zero π] B) = value …` ignores π (found by both categorical reviews):
  `now : 0 Unit ⇒[eff] Int` would read a fixed value with no event. Quantity decides the key's
  domain (`Zero ↦ Unit`), purity decides value vs answers/effect: `Zero, eff ↦ contract-eff c UnitT B …`.
  Follow `GradedOps.agda:208` (`sigOpRefᵛ`) and the codegen side.
* **B2 — halting and emitting are initial/terminal UP TO ISOMORPHISM.** Emit/halt is decided by
  syntactic `B ≡ Unit` / `B ≡ Void` (`Spec/Contract.agda:86`, `isVoid?`/`isUnit?`); `Void * Int` is
  classified "answers" with an EMPTY answer type ⇒ `Impl Σ` empty ⇒ correctness vacuous for such a
  program. Fix = a skeleton: decidable `Empty B` and `Singleton B` on `Type` with soundness
  (`⟦B⟧ → ⊥`, `⟦B⟧ ≅ ⊤`; note `μ` can be empty, e.g. `μ Id`; effectful arrows never are, they can
  halt), and honest FFI (`Type/Honest.agda`) requires an empty codomain to BE `Void` and a singleton
  one to BE `Unit`. The syntactic dispatch everywhere else then is correct, not accidentally so.
  General form → plan 0.112.
* **B4 — the Spec exports the meaning the apex uses.** `Spec/Meaning.agda:68` re-exports the
  purity-blind `⟦_⟧ᴰ`; the apex meaning is the graded one (`Spec.Core.Meaning`, `GradedDomain`,
  `GradedOps`, `T`/`run`/`Interp`). Export those; drop `⟦_⟧ᴰ` from the Spec surface. Split lemma
  parts out first so the closure stays proof-free (C/A1).
