# Plan 0.127 — Once runs on seL4

status: OPEN (written 2026-10-27, at the user's request: "park it, and write a plan for seL4 fixing").
Not started. Phase A needs a decision entry (the Host supplies the entry point) before code.

relates: D320 (the Host is linked beside the program: `enter ; main ; leave`), D317 (a loop is `ana` into

## 0. Where this starts

- **No Once code has ever run on seL4.** `examples/seL4/flake.nix`'s default package (`seL4-once-echo`)
  builds hand-written C (`once-echo/src/main.c`, `echo_server.c`, `echo_client.c`); "All tests passed" is
  printed by that C. The flake's `once build` steps used the C backend (removed, D341) and end in
  `|| true`, so their failures never showed. `make -C examples seL4` runs that C test.
- **The five `.once` programs do not type-check** (`Eff` signatures, uppercase type variables, loops by
  general recursion: D241 forbids it, D317 makes a loop an `ana`).
- **The rootserver design cannot work as written.** `Rootserver*.once` retype TCBs for the server and the
  client but never set their instruction pointer or stack (`seL4_TCB_WriteRegisters`), and Once has no
  value that names a definition's code address.
- **No seL4 Host.** `Strata/Hosts/` has only `Linux`. The compiler emits `_start`, which sets the heap base
  (`once_heap_base`, in `.bss`) and calls `main` on the stack the OS gave it; seL4 gives the root task no
  stack (seL4's own `sel4runtime` crt0 sets one). The Host provides only `once_leave` today.
- **What exists:** `Strata/Interpretations/SeL4/{IPC,CNode,TCB,Untyped,Notification,BootInfo,Types}.once`
  with `signature … : Act …` declarations (updated in plan 0.119 D6), and per-arch impl files
  (`.x86_64`, `.riscv64`, `.arm64`, plus stale `.c`). Their symbols are bare (`seL4_Yield`) and aliased at
  build time (`fe9580060`); their tuple ABI (pointer to nested pairs in `rdi`, result pointer in `rax`) has
  not been checked against what the compiler emits now.
- **A server that runs forever crashes** once the bump heap fills (plan 0.123), so any loop here runs a
  bounded number of rounds until 0.123 lands.

## 1. The goal

`nix build` in `examples/seL4` boots seL4 under QEMU with a Once program as the root task, and the test
reads what that Once program printed. No hand-written C in the path that is tested.

## 2. Phases

### A. A Once root task on seL4 x86_64 (the first run)
1. **Decide** (decision entry): the Host supplies the entry. Either the Host defines the ELF entry
   (`_once_enter`, which sets the stack and jumps to the compiler's `_start`) and the link passes
   `-e` for it, or the compiler's `_start` calls a Host `once_enter` first. Recommended: the Host's entry,
   so the compiler stays the same for every Host (D320's "the compiler never knows which Host").
2. `Strata/Hosts/SeL4/Host.x86_64`: a stack in `.bss`, the entry, and `once_leave`, which prints a fixed
   line with `seL4_DebugPutChar` (debug kernel) and suspends the root TCB (`seL4_CapInitThreadTCB`).
   `--host SeL4` selects it.
3. A debug-output signature (`I.SeL4.Debug.putChar : Act Int Unit`) and its x86_64 impl.
4. Check the IPC impl files' tuple ABI against the compiler's current SigOp calling convention; fix
   what disagrees, with a library-mode build of each signature as the test.
5. `examples/seL4/Hello/Hello.once`: the root task prints a few characters (an `ana` over a counter),
   calls `seL4_Yield`, and returns.
6. The flake: the seL4 kernel (x86_64, pc99, debug) plus the Once ELF as the multiboot module; a
   `simulate` that runs QEMU and checks the printed line. Drop the hand-written C and the `|| true` steps
   from the default package. `make -C examples seL4` runs it.

### B. Rootserver, echo server and client
1. Decide how a Once program starts another thread with code: separate ELFs loaded by the rootserver (an
   ELF loader in Once, or the seL4 tools' CapDL loader), or one image whose threads enter at Host-known
   symbols. This is a design question for the user.
2. Rewrite `Rootserver`, `EchoServer`, `echo-client` on the current surface (`Act`, `ana` with a bounded
   number of rounds, lowercase type variables, qualified imports), with the TCBs given their entry and stack.
3. The echo test passes under QEMU from Once code alone.

### C. Other architectures
1. riscv64 (qemu-riscv-virt) and arm64 (once an ARM64 backend exists) Hosts and kernels.

### D. Close
1. Delete the stale `.c` impl files under `Strata/Interpretations/SeL4` (no C backend, D341) and
   `examples/seL4/once-echo` once nothing uses them; rewrite `examples/seL4/README.md` from what runs.
2. Decision entries for A.1 and B.1; delete this plan.
