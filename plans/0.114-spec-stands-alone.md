# Plan 0.114 — The Spec stands on its own

## Why

Where the Spec calls a compiler function, a bug in that function moves BOTH sides of the
correspondence together, and no proof can see it ("self-validating definitions"). The theorem is
not empty — accepted programs exist and soundness ties them to the Spec — but the Spec is weaker
than it reads exactly at those points, and completeness ("every Spec-typed program is accepted")
becomes partly a tautology there.

## The four borrowings (2026-10-09, branch plan-0.91-program-facts)

1. **Monomorphic definitions** — `Spec/Module.agda:100` `mono` takes the definition's type from
   `C.resolveFunType … ≡ inj₂ ty` (incl. inferring a type for a signature-less definition);
   `ModuleTyped` still ranges over `Parser.extractFunctions (extractAliases m)` (the module's header
   names this defect; plan 0.59 owned it).
   Target: with a signature, a `⊢ᶜ` derivation at it; without one, any `ty` with an `⊢ᵢ`
   derivation — the Spec's own judgment, no resolver.
2. **Module → program translation** — `Spec/Core/Translate.agda:43–45,103–165` builds on
   `Compile.FunCtx`/`buildPolyCtx`, `Parser.FunInfo`, `Classify.lookupImport`, and picks "the first
   `main`, exactly as the compiler's `findMain`" (:15,185).
   Target: state `ImpSig`/`TeleSig` over `Spec.Module`'s own `Scope`/`ModTele`; `main` by its
   unique name (D249).
3. **The meaning's laws** — `Adequacy/Compile.agda:515`: `⟦_⟧ˢ` becomes a `Behavior` via
   `behavior-by (⟦ moduleToProgram … ⟧IR …) (core-run …) (ir-core …)`, i.e. through the compiler IR
   and `moduleToIR-complete`. (`≈` compares `at`, the core run, so correctness is not weakened —
   the trust architecture is inverted.)
   Target: the three `Behavior` laws from `runProgram` directly (`take n ∘ eventsT`;
   `take-pf`/`projTrace-pf` in `TraceMonad` already give them).
4. **`t-var-own`'s negative premise** — `TypeCheck/Judgment.agda:164` requires
   `lookupImport sig x ≡ nothing` only to stay disjoint from `t-var-resolved`.
   Target: `t-var-resolved` ranges over FFI-tagged canonical names, so Σ (generators) and Γ
   (definitions) are disjoint by construction (D274's own argument).

## Steps

Top-down, one borrowing at a time, Spec first and follow the red; each with a decision entry and
the merge-gate checks (Spec closure proof-free, apex + backstop green). 3 is small, 4 small–medium,
2 medium, 1 is the large one (it changes what "well-typed module" means; coordinate with 0.59's
oracle work).
