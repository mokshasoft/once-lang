# Plan: Implement is-id-pos-N Proofs

## Summary
Implement the 13 `is-id-pos-N` postulates in `DispatchLemmas.agda` that prove `is-id` returns `inr` for non-identity terms.

## Key Files
- **Main file**: `Implementation/Normalize/Fixpoint/DispatchLemmas.agda` (lines 429-449)
- **Supporting**: `Implementation/Normalize/Rebuild.agda` (rebuild-N definitions)
- **Supporting**: `Implementation/Normalize/Chain.agda` (proof combinators)
- **Supporting**: `Foundations/Encoding.agda` (encode function)

## Proof Pattern (same for all 13 postulates)

Each proof follows 5 steps:
1. **Unfold**: `is-id ∘ encode t = (is-id-dispatch ∘ Out) ∘ (In ∘ inj-chain ∘ payload)`
2. **Eliminate Out∘In**: Use existing `out-in-compose` lemma
3. **Navigate cases**: Use `assoc-l` + `is-id-tail-N-inl/inr` lemmas
4. **Reach ret-no-N**: After navigation, arrive at `ret-no-N ∘ payload`
5. **Restructure**: Use `assoc-r` to get `inr ∘ encode t`

## Example Implementation: is-id-pos-2 (fst)

```agda
is-id-pos-2 : ∀ {A B} → (is-id ∘ encode (fst {A} {B})) ⟶* (inr ∘ encode (fst {A} {B}))
is-id-pos-2 {A} {B} =
  let payload = ⟨ ⌜ A ⌝Ty , ⌜ B ⌝Ty ⟩ in
  -- Step 1-2: Eliminate Out ∘ In
  out-in-compose is-id-dispatch (inr ∘ inr ∘ inl ∘ payload) >>
  -- Step 3: Navigate case structure (2 inrs, then inl)
  ⟶1 assoc-l >> ⟶1 (⟶-∘-l is-id-dispatch-inr) >>
  ⟶1 assoc-l >> ⟶1 (⟶-∘-l is-id-tail-1-inr) >>
  ⟶1 assoc-l >> ⟶1 (⟶-∘-l is-id-tail-2-inl) >>
  -- Step 4-5: Restructure to inr ∘ encode fst
  ⟶1 assoc-r >>
  ∘-cong-right' inr (assoc-r3 In inr (inr ∘ inl) payload)
```
