# Plan 0.106 — Remove `Str` and `Buffer` (for now)

## 0. The property

> **Every value the Spec can pass to a SigOp is one the machine holds.**

## 1. The measurement (verified 2026-10-03)

Plan 0.105 §g decoded a SigOp's argument from memory (`SMCore.decode-at`, `readTyped`). It is proved
at every base type except `Str`/`Buffer`, and what remains for them, `IRObsCorrect/SigOp.decode-boxed`,
is REFUTABLE:

* `valid-str-wf` / `valid-buffer-wf` carry no content: any `x : ⟦ Str ⟧` is valid at any location
  below the frontier, so two different strings share one state and `decode-boxed` proves
  `"a" ≡ "b"`.
* A string literal is the `Pure` SigOp `lit.str.<s>` (`Builders.str-lit-info`), whose machine output
  is `structured-pure-sigop-output`, also content-free.
* No rewording is consistent. Deleting `valid-str-wf` makes `decode-boxed` provable but makes the
  literal's result placement (`obs-correct-sigop-rest`) refutable; giving `valid-str-wf` content
  makes the literal's placement refutable the same way. The abstract machine holds no strings.

No exit test uses either type: of the 82 programs in `compiler/test`, the 7 that match `"`/`String`
do so only in comments; every observable is an `Int`/`Float` emit. The footprint is 93 formal files
(918 mentions), mostly one clause per enumeration (`IsBaseType`, `⌊_⌋`, `cohᴰ`, `forgetᵇ`, the
`valid-*-wf` transports, `DecEq`, `Sub`, `Match`, `Instance`, the type parser and its relation).

## 2. Decision (D258)

`Str` and `Buffer` are removed from `Type`, `PolyType`, `IRTy`, the value domains, the machine and
the type parser. A string literal has no typing rule (`t-str` is deleted), so a program using one is
rejected by the type checker. The LEXER keeps its string-literal token and the surface AST keeps its
literal node: the verified lexer/parser relations are untouched, and the later plan reuses them.

Rejected: a Spec premise "no SigOp argument contains `Str`/`Buffer`" (keeps a type the theorem then
excludes, and the restriction must be remembered); keeping the refutable postulate as a documented gap
(the apex stays inconsistent).

## 3. Phases (top-down: change the definition, follow the red)

a. `Once.Type`: delete the `Str` and `Buffer` constructors (and `PStr`/`PBuffer`). Follow the red
   through `Type/*`, `IRTy` (and `⌊_⌋`), `Functor.Translate` (`base-Str`/`base-Buffer`), value domains,
   `Semantics`, `Denotation`, `Spec.Core`.
b. Surface: `t-str` and the literal's elaboration (`Surface.Elaborate.strLit`, `str-lit-info`,
   `str-lit-semM`); the type parser's `"String"`/`"Buffer"` words become ordinary names; its relation
   and tests.
c. Machine and codegen: `valid-str-wf`/`valid-buffer-wf` and every transport clause; `ShapeTable`;
   `ShapeAt`.
d. `IRObsCorrect/SigOp`: `decode-boxed` DELETED: every base type is `Readable` or uninhabited, so
   `arg-loc` takes the readable branch only (`readable?` total on base types).
e. `obs-correct-sigop-rest`: re-measure what still routes to it and probe it for `⊥`.
f. Haskell (`compiler/src/Once/Type.hs` `TBuffer`), examples using strings (`examples/hello.once`, …):
   delete or move.
g. Gate = plan 0.105 §5 (Certified green, extraction + `cabal test`, exit tests, island backstop).

## Progress

* *2026-10-03 (1/n):* phases a–d and f landed; `Once.Certified` GREEN. `Str`/`Buffer`/`PStr`/`PBuffer`
  and every per-constructor clause are gone; `t-str`/`⊢lit-str`/`lit-str`/`Surface.str`/`strLit`/
  `str-lit-info` are deleted; the elaborator rejects `RStringLit` with `StringLiteralUnsupported`
  (the `FloatLiteralUnsupported` precedent); the type parsers no longer know `"String"`/`"Buffer"`.
  `Readable` is total on base types (`readable-base`, with vacuous `r-void`/`r-rigid`), so
  `decode-boxed` is DELETED. Strata: the 66 String/Buffer-typed signatures are removed from the
  interpretation modules (their implementations stay; nothing declares them). Haskell: the legacy
  `TBuffer`/`TString`/`StringLit`/`VString` are removed. `examples/` programs that use strings are
  left as they are: they no longer typecheck and are the later plan's targets.
  Trap met: a deleted constructor left in a pattern (`coh-ii ii-str`) silently became a catch-all.
* *Phase e (measured 2026-10-03):* with every input readable, `pure-route` takes `Readable A`
  (no `Maybe`), and what reaches `obs-correct-sigop-rest` is exactly a NON-REGISTER CODOMAIN: a
  pure/prim/FFI-value SigOp returning `Unit`, `Void`, a product or a sum (the comparisons'
  `Unit + Unit`), and an answering call returning one. The machine writes no structured result
  (`structured-pure-sigop-output`, memory untouched by `instr-sigop`), so the postulate's result
  placement is not something the model makes true: it is a MODEL GAP (structured SigOp results),
  owned by plan 0.88's row and the Bool-encoding follow-on of 0.105 §6, not by strings. It is
  stated `∀ si`, so it also over-claims for routed-away cases; narrowing its statement to the
  non-register codomain is part of that row.

## 4. Out of scope, recorded

The later plan that brings strings back owns: the representation (byte cells + length versus a
content cell), a static-data region for literals in the abstract machine, the concrete
correspondence for it, and `Buffer`'s mutability story.
