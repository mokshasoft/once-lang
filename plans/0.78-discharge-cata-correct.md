## -1. FINDING 2026-09-01: `cata-correct` is not merely UNPROVED — it is FALSE
##     as the emitter stands, and the binaries segfault

Found by running the extraction gate on the plan-0.76 branch: every `cata`
test (`layer5-cata-*`, `layer5-iseven`) SEGFAULTS on all three arches — 27
`cabal test` failures, exit `-11`. On `master` they pass.

**The postulate is what keeps the build green over a half-landed model
change.** D131 gave `IR.Cata` an environment slot,

    Cata : ∀ {F} → WellFormedFI F → ∀ {E A}
         → IR (E * ⟦ F ⟧TI A) A → IR (E * μ-type F) A

and `Surface.Elaborate` now emits `cataM wfF m ∘ (elaborate m alg ∘ terminal)`
where `cataM` is `curry (Cata wf (… apply ∘ ⟨ fst , snd ⟩))` — the per-layer
step takes the pair `(algebra-closure, layer)`, projects the closure with
`fst`, and APPLIES it.

`Once.CCC.Codegen.IRToTrace`'s emitter was never updated:

    ir-to-trace' n l (Cata {F} _ alg) =
      let (bb , l1 , at , ab) = ir-to-trace' 0 l alg
          (next , l2 , trace) = cata-dispatch (cata-strategy ⌈ F ⌉F) bb n l1 at
      in next , l2 , trace , ab

`F`, the algebra's trace, and two counters — there is no term for `E` anywhere
in `cata-dispatch`, `cata-trace-{const,nat,linear,branching}`, `cata-br-I₁/I₂`,
`visit-walk` or `rebuild-walk`. All of them still assume the OLD contract
(Input1 = the μ-value). So the loop hands the algebra a bare layer, `fst` of it
is garbage, and the apply dereferences null.

Confirmed in the binary (`layer5-cata-nat`, x86-64):

    0x40187c  mov 0x8(%rdi),%rax   ; snd → the layer
    0x401884  mov (%rdi),%rax      ; fst → the algebra closure
    0x40188d  mov (%rdi),%rax      ; SIGSEGV, %rdi = 0

which is `apply ∘ ⟨ fst , snd ⟩` reading an environment nobody built.

**What this changes for this plan.** Closing `cata-correct` is not only a proof
task. The emitter must FIRST implement the parameterized contract — D131's own
"Consequences" section lists it, and the decision entry's claim that "the
COMPILER does not do this yet: `Surface.Elaborate` emits `Cata wfF (apply ∘
⟨ elaborate alg ∘ terminal , id ⟩)`" is now STALE: the elaborator moved, the
emitter did not. Every strategy needs the same two additions —

  * on entry, split Input1 into `env := fst` (stashed in a slot) and the
    μ-value `:= snd`, which is what the descend walks;
  * per layer, build the pair `(env, layer)` before the algebra call site
    (`cata-call`), instead of passing the layer alone.

and the slot budgets (`CataNextSlot`, `CataIRSlotStable`) move with them.

Until that lands, `cata-correct` should be classified **model-gap (refutable)**
rather than deferred-proof: there are reachable states of emitted programs at
which it is false.

## 1. Why the previous attempt could not finish

**A per-shape witness is not a theorem.** `cata-correct` is ∀-F; a proof for
`NatF = K Unit ⊕ Id` discharges the `NatF` instance and says nothing about
`F ⊗ G`. Wiring it would have meant narrowing the obligation to NatF, which is
the D114 failure mode (shrink the claim until it can be discharged).

So the plan is a proof that CASE-SPLITS THE FUNCTOR, with the Nat modules as
the worked example of what each case needs — not as a component.

## 2. The one finding that will bite immediately

**μ-values are NOT universally Heap.** `In-valid-bf` is mode-polymorphic — a
μ-value's mode is its layer's mode — so a descend needs a Heap-UNIFORMITY
precondition on the cata input, not an assumption. `CataNatProducer` called it
`AllHeap`: a mode-polymorphic recursive predicate over the validity derivation
asserting `mB ≡ Heap` at each cons. Without it the cons recursion gets stuck,
and that is exactly where it will get stuck again.

The decomposition itself was right: **descend to the base, then `build-layer`
on the way up.** What was wrong was fixing the functor while doing it.

## 3. What D131 changed under it

`Cata` now carries an environment (`IR (E * ⟦F⟧TI A) A`), so the algebra is
obtained ONCE and applied per layer. The recovered modules predate this and
will need the environment threaded — mechanically, the same edit the D131
migration made everywhere: project the environment once, outside the fold,
close over it per layer.
