# Plan 0.24: Effect-trace semantics — define `⟦_⟧` so "correct" means something

> Revised 2026-05-29: switched the trace representation from a
> **coinductive** `Eff` to a **step/fuel-indexed** denotation. A
> coinductive free monad needs a productive monadic bind, which is not
> definable under plain `--guardedness` and would otherwise force
> `--sized-types` (rejected — has bitten this project before). Step
> indexing represents a (possibly infinite) trace as **the family of
> its finite prefixes** and proves productive programs correct by
> ordinary induction on the bound (the take-lemma). See "Design".

## The gap (why this plan exists)

`Once.Verified.Compile.correct` claims `exec arch bytes ≡ ⟦ src ⟧`. But
`⟦_⟧ : Source → Behavior` is a **postulate** (`Once/Verified/Behavior.agda:113`),
so the grand theorem is a *well-shaped shell*: it compares the compiled
program against an **undefined** specification. The compiler *runs* and
emits correct binaries, but it is **not yet a *verified* compiler** —
"verified against what?" has no answer. This plan defines that answer.

### Why exit-code is the wrong observable

`Behavior` is presently `Maybe ℕ` (the argument of the final
`linux.exit`). As a *general* definition of correctness it fails:

- It collapses **every** program that exits `0` to "the same" — no
  distinction between wildly different effects.
- A **productive non-terminating** program (a webserver) never calls
  `linux.exit`, so its behaviour is `nothing` — **no correctness
  statement exists for it at all.**

The real observable is the **SigOp effect trace** — the sequence of
SigOp calls and their arguments (`Behavior.agda:7–70`, memory
`feedback_programs_dont_return`). Exit code is a finite projection of
it.

### The representation problem, and why step-indexing

Once targets **CCC + structured recursion**, which *includes* `ν`/`Ana`
— genuinely **productive, non-terminating** programs. We must be able
to prove *those* correct from the start ("we can't write them yet" is
not a reason to design them out).

A productive trace is **semantically** well-defined (structured
recursion: `Cata` over finite `μ` terminates, `Ana` is guarded, so
effects are well-spaced). But Agda's productivity checker is
*syntactic* and cannot see this through a monadic `bind`: the
`ret a >>= f` case collapses in zero steps, so a coinductive `Eff` with
`bind` is rejected. To make productivity visible you must supply an
**index**:

- **implicit, type-level** = sized types — rejected;
- **explicit, external** = **step/fuel-indexing** (`∀ n`) — chosen.

This is *not* a weakening. By the **take-lemma**, two traces are
bisimilar **iff** all their finite prefixes agree:

> `(∀ n → obs n compiled ≡ obs n source)`  **is**  "the (possibly
> infinite) compiled trace equals the source trace."

proved by **induction on `n`** — no coinduction in the definition *or*
the proof — and it covers reactive programs exactly. Structured
recursion is what makes it *sufficient*: pure reduction terminates
between events, so each bound captures a genuine prefix.

## What already exists (build on)

- **The CCC IR is mathematically defined and self-describing**:
  `SigOp : SigOpInfo A B → IR A B` (`CCC/IR.agda:277`); `eval`
  (`CCC/Eval.agda`) is a structural value evaluator that *discards* the
  SigOp event — the trace keeps it.
- **Side-2 machinery already exists.** `instr-sigop : SigOpInfo A B →
  AbstractInstr` (`SMCore.agda:876`) — the abstract instruction that
  carries a SigOp's full `SigOpInfo`; it is **not** a nop, it has
  structured `exec-abstract` semantics (`SMCore.agda:1323`). The codegen
  already emits it: `ir-to-trace' … (SigOp si) = instr-sigop si ∷ []`
  (`IRToTrace.agda:317`). So Side 2 only needs a *trace-recording* run
  of the abstract trace, not new labels.
- **Phase A′ (landed):** `Once/Verified/Trace.agda` has `SigOpEvent` +
  `mkEvent` (name + ℕ arg via `isInt?`) + `exitCodeOf`. **Phase B
  (landed):** `Once/Verified/TraceDenote.agda` has `obs`. (The earlier
  coinductive `Eff` was dropped.)
- **`sourceToIR`** route (front end, option (a)): `gmoduleToModule` →
  `compileResolvedModule` → find `main` → `cfIR : IR Unit Unit`. This is
  the compiler's own elaborator; `⟦_⟧` reuses it (IR pivot).

## Goal

Replace the `⟦_⟧` postulate with a **step-indexed SigOp-trace
denotation** of the source program, making `correct` a genuine
trace-preservation statement meaningful for terminating *and* reactive
programs. Exit-code becomes a projection.

User-observable signals:

1. `Behavior.agda` has **no `postulate ⟦_⟧`**: `⟦_⟧` is a real
   step-indexed definition. Fully `--safe`; no sized types, no
   coinduction.
2. `Behavior` is the family of finite trace prefixes; `exitCode` is the
   Layer-0 projection.
3. `correct` is re-stated as `obs(IR) ≈ concreteTrace(IR)` (`∀ n`-prefix
   preservation, take-lemma bisimilarity), via two bridges: codegen
   (`obs ≈ absTrace`) and the abstract↔concrete simulation
   (`absTrace ≈ concreteTrace`, extending `compile-correct`).
4. Layer-0 programs (only SigOp = `linux.exit`) get a finite trace and
   a discharged `⟦_⟧` end-to-end.

Non-goals: discharging `module-to-asm-correct` (the grand theorem,
gated by the open T0 obstacle); the in-Agda assembler (assembler stays
in the TCB per decision); the *interpretation* of each SigOp (what
`linux.exit` *does* — separate per `Behavior.agda`'s compiler/
interpretation split).

## Design

### D-trace-1: events and prefixes (inductive, finite)

`SigOpEvent` (name + observable arg) — already in `Trace.agda`. A trace
prefix is a `List SigOpEvent`. No coinductive type anywhere.

### D-trace-2: the step-indexed denotation `obs`

```agda
-- fuel = number of effect-steps allowed; structural recursion on it.
obs : ∀ {A B} → (fuel : ℕ) → IR A B → M.⟦ A ⟧
    → ℕ × List SigOpEvent × Maybe (M.⟦ B ⟧)
--    ^remaining  ^events emitted   ^just result if completed within fuel
```

- `obs (suc n) (SigOp si) x = (n , mkEvent si x ∷ [] , just (semM si x))`
  — emit the event, deliver `semM` so the continuation proceeds.
- `obs (suc n) (g ∘ f) x` — run `f`; thread remaining fuel + events
  into `g` iff `f` completed; otherwise return `f`'s prefix.
- `⟨_,_⟩` sequences `f` then `g`; `case` dispatches; pure constructors
  return `(n , [] , just (eval c x))`.
- `Cata`/`Para`: a fold over finite `μ` — emits finitely many events
  (recurse through the algebra, fuel-bounded).
- `Ana`/`Hylo`: the productive case — `obs n` yields the `n`-bounded
  prefix; *this* is where step-indexing earns its keep.
- `obs zero _ _ = (0 , [] , nothing)` — out of fuel.

Structural recursion on `fuel` ⇒ total, `--safe`, no sizes.

### D-trace-3: `Behavior`, `⟦_⟧`, equivalence

```agda
Behavior : Set
Behavior = ℕ → List SigOpEvent          -- the prefix family (monotone in n)

⟦_⟧ : Source → Behavior
⟦ src ⟧ = λ n → proj₁₂ (obs n (elaborate src) tt)   -- events at bound n

_≈_ : Behavior → Behavior → Set
b₁ ≈ b₂ = ∀ n → b₁ n ≡ b₂ n             -- take-lemma bisimilarity

exitCode : Behavior → Maybe ℕ           -- scan a sufficient prefix for linux.exit
```

### D-trace-4: monotonicity

`obs` is **monotone in fuel** (more fuel ⇒ the prefix extends:
`obs n` is a prefix of `obs (suc n)`). Prove it as a lemma; it is what
makes "family of prefixes" a faithful representation and the take-lemma
sound.

### D-trace-5: `correct` = `obs ≈ concreteTrace`, via two trace bridges

`correct` relates the source's **meaning** to what the **concrete
target actually does** — *three* IR-level traces connected by **two**
proven correspondences (the two bridges already in the per-target
proofs, each extended from *state* to the recorded *SigOp sequence*):

- **`obs(IR)`** — Side 1, the denotational meaning (D-trace-2).
- **`absTrace(IR)`** — run the codegen's abstract instruction trace
  (`ir-to-trace` → `exec-abstract`), recording each `instr-sigop`.
- **`concreteTrace(IR)`** — the same, on the concrete target machine.

```agda
absTrace      : ∀ {A B} → ℕ → IR A B → M.⟦ A ⟧ → List SigOpEvent
concreteTrace : ∀ {A B} → ℕ → IR A B → M.⟦ A ⟧ → List SigOpEvent

-- bridge 1 (codegen, abstract level):  IR meaning ↔ abstract trace
obs≈abs  : ∀ ir x → ∀ n → obs-events n ir x ≡ absTrace n ir x
-- bridge 2 (abstract ↔ concrete):      extend Corresponds / compile-correct
abs≈conc : ∀ ir x → ∀ n → absTrace n ir x ≡ concreteTrace n ir x
-- the theorem, by composition:
correct  : ∀ ir x → ∀ n → concreteTrace n ir x ≡ obs-events n ir x
```

**Bridge 1** — codegen correctness at the abstract level: extend
`IRTraceCorrect` (the IR-vs-abstract part of `compile-correct`) to
carry the recorded SigOp sequence. The pieces exist: `ir-to-trace`
emits `instr-sigop si` (`IRToTrace.agda:317`); `exec-abstract
(instr-sigop si)` has real semantics (`SMCore.agda:1323` — not a nop).

**Bridge 2** — the abstract↔concrete simulation. `compile-correct`
(`X86-64/CompileCorrect.agda:124`) already proves the concrete run
(`exec-prog (compile-trace trace)`) `Corresponds` to the abstract run,
**operation-aligned** (`DirectSimulation.agda:55`). Extend that
`Corresponds` from *state* to the *SigOp sequence* — **mechanical**,
because the simulation already aligns the operations (state-equality
doesn't *contain* the trace, but operation-alignment *produces* it).

This reaches concrete **target instructions**; only `programToText`
+ the assembler (`as`) — *instructions → text → bytes* — is trusted
(see TCB). State correspondence is the *means* (right event args + step
alignment); the trace is the *observable end*.

## Correctness statement & TCB — read this to know what "correct" means

A bare `absTrace ≈ obs` is **not** self-evidently "the compiler is
correct"; it only is *given the framing below*. State this prominently
next to the theorem (extend the `Behavior.agda` preamble box).

**What `correct` claims:** for every program, the compiler emits and
arranges SigOps so that *running the generated (abstract) code performs
exactly the SigOp calls — same names, arguments, order — that the
source program means* (`obs`). Up to `∀ n` prefixes, i.e. for
terminating **and** productive/reactive programs (take-lemma).

Distinguish **proof obligations** (provable in Agda — some currently
open, but NOT trust) from the **irreducible TCB** (external, cannot be
proved in Agda). Conflating them is the mistake to avoid.

**Proof obligations (provable; not TCB):**
- `obs(IR) ≈ absTrace(IR)` — IR meaning ↔ abstract trace (IRTraceCorrect
  territory).
- `absTrace(IR) ≈ concreteTrace(IR)` — abstract ↔ concrete-target trace,
  by **extending `compile-correct`/`Corresponds` from state to the SigOp
  sequence** (the state-bridge already exists and is proven).
- per-SigOp **compiler** realization — that the compiler *emits* code
  computing each SigOp (e.g. `arith.block` — plans 0.20/0.23).
- front-end `source → IR` (currently shared/trusted as the IR pivot and
  blocked by the open T0 obstacle, but a proof obligation, not a
  fundamental axiom).

**Irreducible TCB (CompCert-sized — external, review-trusted):**
1. `programToText` + the assembler `as` (concrete instructions → text →
   bytes). [Removable later by an in-Agda assembler.]
2. The **ISA model** (`exec-prog`/`execInstr` clauses vs real silicon —
   the CompCert `Asm.v` convention).
3. The **OS/external effect** of *external* SigOps (the kernel actually
   performing `linux.exit`, `linux.write` — genuinely outside the
   program; `Behavior.agda`'s "interpretation proves protocol" side).

**Honest comparison to CompCert/CakeML:** **the same floor** —
assembler + ISA semantics + external world. The earlier "we trust more"
claim was wrong: `compile-correct` already proves the abstract↔concrete
correspondence (it just needs extending from state to the SigOp trace),
so the abstract→target step is a *proof obligation*, not trust. What
remains genuinely external is exactly what CompCert also trusts.

## Phases

### Phase A′ — rework `Trace.agda` to events/prefixes only
Drop the coinductive `Eff` + `retE`/`effCall`/(`>>=E`). Keep
`SigOpEvent`/`mkEvent`; keep/adjust `events`/`exitCode` to operate on
prefixes. Fully `--safe`.

### Phase B — `obs` over the IR (the substantive piece)
Define the fuel-indexed `obs` structurally over `IR` (D-trace-2),
threading remaining fuel through `∘`/`⟨_,_⟩`/folds. Reuse `eval` for the
pure value parts; recurse through effectful folds; `Ana` gives bounded
prefixes.

### Phase C — `Behavior` + discharge `⟦_⟧` (Side 1)
Re-anchor `Behavior` as the prefix family; `⟦ src ⟧ := λ n →
obs-events n (sourceToIR src) tt` where `sourceToIR : Source → Maybe
(IR Unit Unit)` reuses the compiler's own elaborator (option (a):
`gmoduleToModule` → `compileResolvedModule` → find `main` →
`cfIR : IR Unit Unit`). Remove the postulate in `Behavior.agda`;
provide `exitCode` so Layer-0 specs read as exit codes.

### Phase D — Side 2 abstract + bridge 1 + monotonicity
Define `absTrace` by running `ir-to-trace IR` through `exec-abstract`,
recording each `instr-sigop`. Prove **bridge 1** (`obs ≈ absTrace`) by
extending `IRTraceCorrect` to carry the SigOp sequence; discharge the
`SigOp`/`∘`/`⟨_,_⟩`/`case` cases (recursion-scheme cases the honest
remainder). Prove `obs`/`absTrace` monotone in fuel.

### Phase E — bridge 2 + end-to-end `correct` + the TCB box
Define `concreteTrace` and prove **bridge 2** (`absTrace ≈
concreteTrace`) by extending `compile-correct`/`Corresponds` from state
to the SigOp sequence (mechanical — the simulation is operation-
aligned). Compose to the headline `correct : obs ≈ concreteTrace`
(take-lemma bisimilarity, reaching concrete target instructions). Write
the **"Correctness statement & TCB"** box next to the theorem so
reviewers see what is proved (both bridges) vs trusted (assembler, ISA
model, OS external effects).

### Phase F — Layer-0 end-to-end
For `exit (3 + 5*2)`: `⟦ src ⟧` computes the finite event prefix and
`exitCode ⟦ src ⟧ = just 13`; `absTrace` agrees. Confirms the discharge
is non-vacuous and `correct` holds for a real program.

## Risks / open questions

1. **Fuel threading.** `∘`/folds must thread remaining fuel + events
   correctly (return `(remaining , events , result?)`). Bookkeeping is
   the main fiddliness.
2. **Monotonicity proof.** Needed for faithfulness; should be a
   straightforward induction but must actually go through.
3. **Effectful `Cata`.** A fold's algebra may contain SigOps; `obs`
   recurses through it (finite, since `μ` is finite). Get the fuel
   accounting right.
4. **`Ana` accounting.** The productive case: ensure `obs n` extends
   with `n` (no premature `nothing`). This is the case that validates
   the whole approach.
5. **`elaborate` reuse.** `⟦_⟧` routes through existing elaboration
   (`GModule → IR`); avoid an import cycle with `Verified.Compile`.

## Why this is the right next step

- It makes `correct` **non-vacuous** — without a defined `⟦_⟧` every
  downstream proof compares against nothing.
- It is **`--safe`, no sized types, no coinduction** — robust against
  Agda's productivity limitations.
- It **proves productive/reactive programs correct** (the full CCC +
  structured-recursion target) via induction on the bound — not just
  terminating ones.
- It is **independent of the hard T0 blocker** (defines the spec; does
  not prove the grand theorem).
