# Plan 0.98 — a halting SigOp DOES NOT RETURN

Follow-on to 0.97. 0.97 made the Spec *model* stopping (`stops-D`, `>>=T`
short-circuit, `halts-obs-correct-sigop` proved). This plan removes the reason
0.97 needed four conditioned fields to say it.

## 0. The property

A SigOp declared `halts` ends the program. It therefore has **no result**.
Today its codomain is `Unit`, i.e. "returns a trivial value", and a boolean
flag beside it says "do not look at the value". The flag is a patch over a
type that lies.

## 1. The finding (audit, 2026-09-23)

`EffectShape`'s two effectful constructors carry the **same index**:

```agda
Emits : B ≡ Unit → EffectShape B
Halts : B ≡ Unit → EffectShape B
```

so a halting SigOp is **indistinguishable in the type** from an emitting one.
That is why the distinction could be dropped on the surface path and why it
had to be stashed in a name-keyed side table (`NamedCtx.sigEffects`), and it
is the root cause of `RealizeAgrees.masq`'s `true != false`: the elaborator
reads the table, `⟦_⟧ˢ` cannot, so D060's "ONE meaning, two presentations"
is currently FALSE.

The `B ≡ Unit` proof has exactly **one load-bearing consumer** —

```agda
semM : SigOpInfo A B → TargetNum → M.⟦ A ⟧ → M.⟦ B ⟧
  go (haltsV refl) = λ _ _ → tt        -- the PROOF is the value
```

— stated outright in `SigOp/Info.agda`: *"For an effect contract there is NO
value field: the machine output is `tt` by the `B ≡ Unit` coherence."*
Every other consumer discards it (`exec-sigop-output-of`, `exec-sigop-halts-of`,
`FlatStoreWF`/`FlatPtrBounds`/`FlatStackPtr`, `EmittedWF.sigop-owed`, and
0.97's own `halts-obs-correct-sigop`, whose `place` is already `absurd`).

So `semM`'s totality and `T.vlT`'s totality are **the same design decision in
two layers**: *a computation always has a value*. They are not two problems.

## 2. Why the change is ENTAILED, not chosen

Any design in which a halting SigOp's codomain is not inhabited-by-fiat forces
`semM` partial; any design in which it IS inhabited-by-fiat is the present lie.
There is no third option. So:

```agda
haltsV : B ≡ Void → SigOpSem A B
```

and `semM`/`T` must admit "no value".

## 3. The encoding

A leaf module `Once.Res` (no dependencies), used by both `SigOp.Info` and
`TraceMonad`:

```agda
data Res (X : Set) : Set where
  stopped : Res X          -- the program ended; there is no result
  returns : X → Res X
```

* `semM : SigOpInfo A B → TargetNum → M.⟦ A ⟧ → Res M.⟦ B ⟧` — TOTAL again
  (`pureV f ↦ returns ∘ f`, `emitsV refl ↦ returns tt`, `haltsV refl ↦ stopped`).
* `T` carries `resT : Res X` in place of `stT`+`vlT`.
* `_>>=T_` **case-splits** instead of computing and discarding:
  a stopped head never builds the sequel.

### What this DELETES

* `join-es`, `join-st` and their identity/associativity laws — they exist only
  to discard a sequel that is now never constructed.
* `stops-D` / `stops-D-of` and 0.97's `sigop-stops-*` / `no-stop-*` helpers —
  stoppedness is read off `semM`'s own result.
* `Once.SigEffect`, `SigEffectCtx`, `lookupSigEffect` (12 sites) and the
  `! halts` surface annotation — the codomain says it.
* `masq` / `masq-unit` / `masq-arrow`'s three-way `lookupSigEffect` split.
* `ValueRealized.place`'s hand-added premise: `resT … ≡ returns v` SUPPLIES the
  value, so the obligation cannot be mis-stated. (`live`/`at-end`/`stops` stay
  conditioned — they are about the machine, not the value.)

## 4. Cleared risks

* `IsConcrete Void` = `con-base base-Void` — `ffi-concrete` builds. ✓
* The parser already accepts `Void` as a type word (`parseType-Void` passes),
  so `signature exit : Eff Int Void` is writable today. ✓
* The machine is UNAFFECTED: `exec-sigop-output-of (Halts _) = unit-storedvalue`
  stays — writing the Output register is an ABI fact, not a semantic claim.
* Surface sources: exactly ONE `.once` file, two lines. ✓

## 8. STAGE C GREW: the pure evaluator was REFUTED (D224)

Not in the plan as written, and forced by it. `evalᴰ`'s SigOp clause was the
target; enumerating `evalᴰ` to reach it exposed that the catch-all beneath it
routed six constructors to the PURE `Once.CCC.Eval.eval` — and that function is
**refuted** by this plan's own §2, for exactly the reason `semM` was:

    ⌊ Void ⌋ = Void     ⟦ Void ⟧ = ⊥

so `eval fmt (SigOp si)` at a halting `si` must produce `⊥` from an inhabited
domain. §1's finding — "`semM`'s totality and `T.vlT`'s totality are the same
design decision in two layers" — turns out to have a THIRD layer, and `eval` is
it.

`eval` is DELETED rather than repaired. Repair forces
`Val.⟦ A ⇒ B ⟧ = ⟦A⟧ → Res ⟦B⟧`, i.e. a second Kleisli model beside `⟦_⟧ᴰ`,
which already has `T`-valued exponentials — the duplication this plan exists to
remove. Plan 0.79 §1 puts the IR-level laws over `evalᴰ`; plan 0.64 Group O's
`opt-trace` is a TRACE statement, so laws over `eval` could never discharge it.

`appNatTr-F`'s `ntK` leaf is `eval` on an arbitrary IR, and `NatTr` exists only
for `Hylo`/`Fuse`, so the cluster went together: **`Para`, `Hylo`, `Fuse`,
`NatTr`, `appNatTr-F`, `eval`**. 34 files. IR: 23 constructors -> 20, and the
recursion layer became symmetric (3 per side: intro / Lambek inverse / scheme).

What it bought beyond unblocking stage C:

  * **six postulates deleted** — `obs-correct-{Para,Hylo,Fuse}` (plan 0.68's
    class G, taking its own "restrict the IR so they cannot be built" option)

  * **D214's named dead-module cleanup discharged** — `ValidityDef` was `eval`'s
