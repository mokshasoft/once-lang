# Plan 0.98 — a halting SigOp DOES NOT RETURN

Follow-on to 0.97. 0.97 made the Spec *model* stopping (`stops-D`, `>>=T`
short-circuit, `halts-obs-correct-sigop` proved). This plan removes the reason
0.97 needed four conditioned fields to say it.

## 0. The property

A SigOp declared `halts` ends the program. It therefore has **no result**.
Today its codomain is `Unit`, i.e. "returns a trivial value", and a boolean
flag beside it says "do not look at the value". The flag is a patch over a
type that lies.

## 1. The finding (audit, 2026-09-23)

`EffectShape`'s two effectful constructors carry the **same index**:

```agda
Emits : B ≡ Unit → EffectShape B
Halts : B ≡ Unit → EffectShape B
```

so a halting SigOp is **indistinguishable in the type** from an emitting one.
That is why the distinction could be dropped on the surface path and why it
had to be stashed in a name-keyed side table (`NamedCtx.sigEffects`), and it
is the root cause of `RealizeAgrees.masq`'s `true != false`: the elaborator
reads the table, `⟦_⟧ˢ` cannot, so D060's "ONE meaning, two presentations"
is currently FALSE.

The `B ≡ Unit` proof has exactly **one load-bearing consumer** —

```agda
semM : SigOpInfo A B → TargetNum → M.⟦ A ⟧ → M.⟦ B ⟧
  go (haltsV refl) = λ _ _ → tt        -- the PROOF is the value
```

— stated outright in `SigOp/Info.agda`: *"For an effect contract there is NO
value field: the machine output is `tt` by the `B ≡ Unit` coherence."*
Every other consumer discards it (`exec-sigop-output-of`, `exec-sigop-halts-of`,
`FlatStoreWF`/`FlatPtrBounds`/`FlatStackPtr`, `EmittedWF.sigop-owed`, and
0.97's own `halts-obs-correct-sigop`, whose `place` is already `absurd`).

So `semM`'s totality and `T.vlT`'s totality are **the same design decision in
two layers**: *a computation always has a value*. They are not two problems.

## 2. Why the change is ENTAILED, not chosen

Any design in which a halting SigOp's codomain is not inhabited-by-fiat forces
`semM` partial; any design in which it IS inhabited-by-fiat is the present lie.
There is no third option. So:

```agda
haltsV : B ≡ Void → SigOpSem A B
```

and `semM`/`T` must admit "no value".

## 3. The encoding

A leaf module `Once.Res` (no dependencies), used by both `SigOp.Info` and
`TraceMonad`:

```agda
data Res (X : Set) : Set where
  stopped : Res X          -- the program ended; there is no result
  returns : X → Res X
```

* `semM : SigOpInfo A B → TargetNum → M.⟦ A ⟧ → Res M.⟦ B ⟧` — TOTAL again
  (`pureV f ↦ returns ∘ f`, `emitsV refl ↦ returns tt`, `haltsV refl ↦ stopped`).
* `T` carries `resT : Res X` in place of `stT`+`vlT`.
* `_>>=T_` **case-splits** instead of computing and discarding:
  a stopped head never builds the sequel.

### What this DELETES

* `join-es`, `join-st` and their identity/associativity laws — they exist only
  to discard a sequel that is now never constructed.
* `stops-D` / `stops-D-of` and 0.97's `sigop-stops-*` / `no-stop-*` helpers —
  stoppedness is read off `semM`'s own result.
* `Once.SigEffect`, `SigEffectCtx`, `lookupSigEffect` (12 sites) and the
  `! halts` surface annotation — the codomain says it.
* `masq` / `masq-unit` / `masq-arrow`'s three-way `lookupSigEffect` split.
* `ValueRealized.place`'s hand-added premise: `resT … ≡ returns v` SUPPLIES the
  value, so the obligation cannot be mis-stated. (`live`/`at-end`/`stops` stay
  conditioned — they are about the machine, not the value.)

### 9.1 The shape that repeats

Three distinct moves, and which one applies is decided by WHAT THE LEMMA IS
ABOUT — not by where the `join-*` happened to sit:

* **The value is the subject** (`ValueRealized.place`, `CalleeRuns.place`,
  `IRResultBase.result-place`) → the premise becomes `T.resT … ≡ returns v`,
  which SUPPLIES the value. The obligation can no longer be stated with the
  condition and the value out of step.
* **The trace is the subject** (`Pair`'s `denot-split`, `pair-traces*`) → the
  premise stays BOOLEAN. The trace does not depend on the value, and
  re-stating it with a value parameter would say less about more.
  `Once.Res.res-returns` / `res-stopped` invert the flag inside the proof,
  where `bindRes` has to be reduced. They are proofs: the flag and the result
  carry the same information about stopping.
* **The dispatch itself** (`Comp.go`, `PairAssemble.dispatch`) → splits on
  `Res`, not on `Stopped`. `returns v` BINDS the value the continuation
  consumes, and `bindRes` reduces on the very constructor being matched.

### 9.2 `IRObsCorrect/SigOp` — the one piece that is NOT mechanical

0.97's `stops-D si` was DEFINED as `stops-D-of (effect si)`, so a consumer
that matched on `effect si` could `cong` its way to stoppedness. There is no
such definition now: stoppedness is `is-stopped (semM si fmt a)`, and `semM`
and `effect` are two independent-looking readings of `sem si`.

The fix is to make the coincidence a LEMMA. `semM`/`effect` are hoisted out of
their `where`s into `semM-of`/`effect-of` on `SigOpSem` — a `where`-bound
dispatch cannot carry a proof, because neither reduces on `sem si` for a
variable `si`, so there is nothing to case-split — and then

    semM-stops : is-stopped (semM si tn a) ≡ stops-shape (effect si)

is proved by three `refl`s. `stops-shape` is 0.97's `stops-D-of`, moved to sit
beside the contract it reads.

### 9.3 `Adequacy/MeaningRelation` — the triple collapses

    RelT A t₁ t₂ = ∀ n → (projTrace t₁ n ≡ projTrace t₂ n)
                       × (stoppedT t₁ n ≡ stoppedT t₂ n)
                       × RelV A (valueT t₁ n) (valueT t₂ n)

becomes

    RelT A t₁ t₂ = ∀ n → (projTrace t₁ n ≡ projTrace t₂ n)
                       × Res-rel (RelV A) (T.resT t₁) (T.resT t₂)

— the stop channel and the value channel were always one fact. `Res-rel` is
already in `Once.Res` (it was added for the ν bisimulation, which needed the
same thing one layer down).


### 9.4 `Adequacy/SourceFaithful`'s arith lemmas — where `noStop` DIES

`arith-body-II`/`-IF`/`-FF` are stated as

    liftFn (SigOp info ∘ ⟨ ea , eb ⟩) dγ ⟨$⟩ n
      ≡ (sa >>=T λ va → sb >>=T λ vb → returnT (semM info fmt (va , vb))) ⟨$⟩ n

with `noEmit` AND `noStop` as premises, and the proof `rewrite`s by `noEmit`
applied to `(valueT sa n , valueT sb …)`.

After 0.98 that `valueT` cannot even be WRITTEN: `sa` is an abstract
computation, so its `Returns?` witness is an unsolvable meta. That is the
design working — the old statement quietly assumed both operands produced
values, on a branch where one may not have.

The replacement is a two-level split on `T.resT sa` and `T.resT sb`:

  * `sa` stopped — both sides are `(projTrace sa n , stopped)`; `eb` never ran.
  * `sa` returns, `sb` stopped — both sides are the two traces concatenated,
    still `stopped`; the SigOp never fired.
  * both return — `va`/`vb` are BOUND by the constructors, so `noEmit` applies
    to a pair that exists, and the trace residual is `bindRes-trʳ` rather than
    `join-es-idʳ`.

`noStop` is DELETED, not migrated: an arith SigOp's `Pure` contract is already
what makes `semM` return, and the third case is the only one that reaches it.
This is §3's prediction ("these COLLAPSE rather than migrate") landing on the
one place where the old shape was actually saying something false.

Also in this module: `_⟨$⟩_`'s type (`List SigOpEvent × Res X`, a pair again),
`subst-T-apply` (transport moves the trace not at all and the result by
`mapRes`), and `sigop-value` (the SigOp's result is ALREADY a `mapRes` —
`semM` says whether there is a value, the denotation only re-types it).
