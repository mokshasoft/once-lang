# Plan 0.101 — `cata`/`ana` algebras may capture locals

## 0. The property

> **`let x = e in b` and a top-level `x = e` used in `b` must be interderivable.**
> (plan 0.94 §0)

Plan 0.94 proved let ⇒ def (`Once.TypeCheck.LetIsDef`) and name ⇔ definiens
(`Once.TypeCheck.Unfold`). The converse, def ⇒ let, is FALSE today, for exactly one reason:
a `cata`/`ana` algebra is typed in the CLEARED context — imports and definitions, no locals
(`t-cata-check`, `t-ana-check`, `d-cata`, `d-cata-void`). So

```once
x = 5
f = cata (\l -> x)                -- accepted: the algebra sees the definition

f = let x = 5 in cata (\l -> x)   -- rejected: the algebra cannot see the local
```

That is the last place where a definition and its definiens are not interchangeable.

## 1. Why the context is cleared

Not for a mathematical reason. Plan 0.76 held capture back for its own decision, and D131
names the obstacle: the emitter elaborates a cata as

    Cata wfF (apply ∘ ⟨ elaborate alg ∘ terminal , id ⟩)

and `IR.Cata`'s algebra has domain `⟦F⟧TI C` with NO environment slot. A capturing algebra
needs its environment at every layer; today there is nowhere to put it. The meaning already
treats the algebra uniformly — obtained once, applied per layer (D131):

    ⟦ cata alg ⟧ᶜ dγ = ⟦alg⟧ᶜ dγ >>=T λ f → returnT (cata-sem f)

so capture costs nothing semantically; it is a codegen and adequacy question.

## 2. The change

1. **Judgment.** The algebra/coalgebra premises of `t-cata-check`, `t-ana-check`, `d-cata`,
   `d-cata-void` are typed in `ctx` (with its locals) instead of
   `ctxWithImportsAndPolys …`, and their usage enters the conclusion (today `zeroUsage`).
2. **IR.** The parameterized catamorphism D131 names: a closed
   `CataM : IR (F C ⇛ C) (μF ⇛ C)`, elaborated as `CataM wf ∘ elaborate alg` — the same
   shape as `compIR ∘ ⟨ ef , eg ⟩`. Dually for `ana`. This also removes the per-layer
   closure allocation of today's `elaborate alg ∘ terminal`.
3. **Surface.** `Surface.cata`/`ana` carry an algebra in context (`Expr Γ Ψ …`), not a
   closed one.
4. **Adequacy.** `cata-fold-eq`'s hypothesis `⟦ algE ⟧ˢ tt ≡ liftD m` becomes the algebra's
   own meaning in the environment; the named D131 premise is discharged, not moved.
5. **Metatheory.** Extend `LetIsDef` to the converse (def ⇒ let) — with capture there is no
   cleared context left to break it — and restate plan 0.94 §0 as an equivalence.
