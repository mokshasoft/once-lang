# Plan 0.85 — Split the deciders out of `Once.Type`

## The finding

`Once/Type.agda` is 1,082 lines and carries **5 decision procedures** alongside
the type/functor grammar. `Once.Type` is in the `Once.Spec` re-export closure,
so `make spec-closure` reports all 1,082 lines as audit surface.

This is the same module-granularity false positive that plan 0.84 fixes for the
grammar bridges, in a milder form:

* `Once/Spec/Type.agda` already `using`-restricts the deciders OUT. The
  **exported** surface is the usage algebra, the type/functor grammar, the
  schemas, `Ground`/`GroundF`, and `FitsInReg` — no decider among them.
* The `using` list is even annotated with the intent
  (`-- schemas, and groundness as a PROPERTY (D134)`).

So unlike 0.84, **nothing is actually leaking into the trust surface.** The
reviewer who follows `Once/Spec/Type.agda`'s `using` list reads the right
names. Only the closure *report* over-counts.

## Why this is not 0.84

Blast radius. `Once.Type` is imported by essentially every module in the tree;
`Once.Spec.Type` is imported by three. Splitting the deciders into
`Once.Type.Decide` means touching every importer that uses one, for **no change
in the actual trust surface** — which is the opposite of 0.84's trade, where
five files move and the trust surface genuinely shrinks.

Do it when something else already forces a sweep of `Once.Type`'s importers.

## The work

1. Identify the 5 deciders (`grep -E '^[a-zA-Z][A-Za-z0-9-]*\? :|^_≟|≟' Once/Type.agda`)
   and confirm none is mentioned by `Once/TypeCheck/Judgment.agda`. D134 is the
   governing rule: **the spec names PROPERTIES, the elaborator names DECIDERS.**
   If the judgment *does* mention one, that is a D134 violation and a finding in
   its own right — record it rather than moving the decider.
2. Create `Once.Type.Decide`, move them, re-export nothing from `Once.Type`.
3. Follow the red: fix importers. Expect a wide but shallow diff.
4. `make spec-closure` — `Once/Type.agda` should now be genuinely
   proof-free AND decider-free.
5. Gate: judgment sweep + 7 gate roots. **No extraction gate needed** — deciders
   are executable, so if any is in the extracted cone this becomes an
   extraction-gated change; check before assuming.

## Exit

`Once/Type.agda` contains the type language and nothing else. The closure's
1,082-line entry stops being the largest thing a spec reviewer is told to read.
