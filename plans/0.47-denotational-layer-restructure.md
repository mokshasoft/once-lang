# Plan 0.47 — Denotational-layer restructuring (architecture correctness)

## Goal

Make the denotational **meaning** a self-contained layer whose dependency arrows
point only *up* toward a minimal kernel — never *down* into the operational
compiler. Concretely: a module under the denotational layer may import **only**
the object language (`Type`, `IR`) and the semantic kernel (`Functor.Base`,
`Semantics.Core` *definitions* + the trace domain), and **nothing** operational
(no `Machine`, `Codegen`, `Target`, elaborator, arith backend) and **no axioms**
(`funext`, `bisimS-to-eq`). The remaining honesty (SigOp/arith value contracts)
stays visible and is the only thing blocking real `agda --safe`.

Four conceptual tiers (dependency: top imports nothing operational; each lower
tier references up):

```
  object language + kernel   Type · Functor · IR · Semantics.{Functor,Value} defs · Trace monad
        ├──────────────────────────────┐
  DENOTATION (spec)             OPERATIONAL (impl)
  Once.Denotation.*              Machine · Codegen · x86 · optimizer
        └───────────────┬──────────────┘
                  ADEQUACY (join)   machine-trace ≡ projTrace ⟦src⟧
```

## Module classification (from the import graph)

DENOTATIONAL (move to `Once.Denotation.*`): `Trace`, `TraceMonad`, `TraceDenote`,
`DenotTrace`, `SourceDenote`, `FaithfulLemmas`, `SourceFaithful`, `Behavior`.

ADEQUACY/OPERATIONAL (stay `Once.Verified.*`; rename to `Once.Adequacy.*` later):
`Compile`, `ArchCorrectness`, `CPU`, `FlatEvents`, `SourceTrace`.

## Steps (each independently green; commit per step)

### Step 1 — `Once.Verified.* → Once.Denotation.*` for the meaning group
- `git mv` the 8 denotational modules to `Once/Denotation/`.
- Fix each module header `module Once.Verified.X` → `module Once.Denotation.X`.
- Rewrite every importer (`import Once.Verified.{moved}` → `Once.Denotation.{moved}`)
  across the whole tree — incl. the remaining `Verified.*` adequacy modules and
  the `CCC/Codegen/*` trace-correctness proofs.
- Update `compiler/once.cabal` MAlonzo module list.
- Re-extract (malonzo + SourceFaithful root) + Bridge/cabal sync. Green.

### Step 2 — relocate `⟦_⟧ᶜ` out of the elaborator
- `⟦_⟧ᶜ : Ctx n → Type` lives in `Surface.Elaborate` (the heavy elaborator);
  `SourceDenote` imports it only for that. Move it to a lightweight module
  (`Once.Surface.Context` or fold into `Surface.Syntax`). Repoint `SourceDenote`.
- Effect: drops `Surface.Elaborate` + transitively `Memory.*` + `FrameSemantics`
  from the denotational closure. (Arith.SigOp.Builders stays — `⟦div⟧ˢ = semM
  div-info` is a genuine dep; its `div-semM` postulate is the deferred contract.)

### Step 3 — extract `Core.Laws` / `Base.Laws` (evict the axioms)
- `Functor.Base` → keep definitions; new `Once.Functor.Base.Laws` gets `_∼S_`,
  `⟦_⟧SF-rel`, `bisimS-to-eq`, `sfmap-rel`/`sfmap-f-rel`, `anaS-unfoldS-bisim`,
  `anaS-Out-id` (the bisim machinery + the axiom).
- `Semantics.Core` → keep definitions; new `Once.Semantics.Core.Laws` gets
  `funext`, `sem-cata-In-id`, `sem-ana-Out-id` (+ `∼S-refl-at`, `CoIn-CoOut-bisim`,
  `sem-ana-Out-bisim`/`-rel`). (Axiom-free structural laws stay in the defs module.)
- Repoint the law consumers (only `Category.Laws` + `Semantics.Coherence`, plus
  any indirect `_∼S_`/`bisimS-to-eq` users found at edit time).
- Effect: `funext` + `bisimS-to-eq` leave the denotational closure entirely.
  `make denot-safe-strict` then blocked ONLY by the SigOp/arith contracts.
