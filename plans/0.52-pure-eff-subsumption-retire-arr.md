## One-line

The grade (purity, later capabilities) is a **checked, runtime-erased typing
refinement**. The pure→eff direction is **subsumption** (`pure ⊑ eff`, a check),
never a **coercion term**. `arr` — the last pure→eff coercion — is retired.

## Why (the principle, see D068)

- `evalᴰ apply` is kind-polymorphic; `evalᴰ arr f = returnT f` (identity). The
  grade is a **phantom IR index**: present in the *type*, ignored by codegen
  (the IR is grade-erased, D046; `realize-morph` ignores `π`, D066).
- D065 already dropped **bare** `arr` (type error) and made bare morphisms
  grade-free. The only `arr` left is **applied `arr f`** (the closure lift,
  `t-arr-app-check`): a pure function *value* used at an eff arrow.
- That last `arr f` is a **no-op coercion** (`⟦arr f⟧ = ⟦f⟧`). OCP-0007's rule is
  "annotation is a **check, never a coercion**"; the QTT discipline (the
  `Zero/One/Many` quantity is already QTT's `{0,1,ω}` semiring) is that grade
  annotations are **tracked, checked, erased** — adjusted by subsumption, not
  coercion terms. `arr` is the pure/eff analogue of an explicit `0→ω` coercion,
  exactly what QTT avoids.

## Monotone, not free (the D066 guardrail)

Subsumption is **one-directional**: `pure ⊑ eff` (use a pure thing where eff is
allowed) is sound; `eff ⊑ pure` is **UNSOUND** (D066 — the optimizer drops pure
SigOps, so tagging an effectful SigOp pure drops effects). So this is *monotone*
subsumption up the grade lattice — which is precisely OCP-0007's **attenuation**
(authority only ever relaxes downward; you never fabricate it). The grade stays
load-bearing in the surface type for the effect/capability analysis; only the
*adjustment mechanism* changes (check, not term).

### M2 SCOPING (2026-07-14 audit) — findings + architecture verdict

**Core facts established:**
- IR objects ARE surface `Type`s (`IR : Type → Type → Set`, IR.agda:114). `arr`
  (IR.agda:146) bridges `A ⇒[mk-kind q pure] B` → `A ⇒[mk-kind Many eff] B` — two
  Types differing ONLY in the `Kind` index.
- The denotation ALREADY ignores the grade: `⟦ A ⇒[ _ ] B ⟧ᴰ = ⟦A⟧ᴰ → T⟦B⟧ᴰ`
  (ValueDomain.agda:42; Value.agda:124). The grade is a pure phantom index ⇒ any
  erasure map is denotationally invisible (coherence lemma is trivial).
- **Optimizer purity rides on SigOp CONTRACTS (D061), not arrow grades** — VERIFIED.
  `has-effect?` (Optimize.agda:1096–1138) branches on IR constructors; `has-effect?
  arr = false` (1117) ignores the `eff` codomain grade. Drop-gate at 1296–1302 uses
  `has-effect?`, and `Optimize/Correct.agda` proofs gate on the same. M2 is SAFE for
  the optimizer — its only `arr` uses are constructor matches (IRReducible/Depth) that
  just delete. NO optimizer rework needed (the plan's Normal/IRReducible/PairCaseNormal
  worry is unfounded — those are categorical-law rewrites, not grade-gated).

**Two removals in M2** (both enabled by "pure/eff = same IR object"):
1. `IR.arr` (IR.agda:146) — the IR object coercion.
2. `Surface.arr'` (Syntax.agda:140) — the surface Expr node the elaborator emits for
   `t-subsume`. Removing it deletes ~11 Elaborate clauses (453/1424/1461/1507/1545/
   1624/1790/2290 + resolveExprWF:3166 + resolveExpr-arr':3465 + extract-morph-eff-aux:628)
   and the RealizeAgrees arr'/subsume agree cases. `t-subsume` STAYS — its realize just
   becomes identity (`realize (t-subsume d) = realize d`).

**Architecture (a) grade-irrelevant field — VERDICT: a trap as literally stated.**
The surface checker DECIDES purity (`≟k`/`≟p`, Type.agda:216; 169 `mk-kind` splits in
Elaborate, 61 in Completeness). An irrelevant field is not decidable, so making the
arrow `Kind` irrelevant BREAKS the frontend. Since IR objects = surface `Type`, you
cannot have the grade relevant (surface) and irrelevant (IR object) on the SAME
constructor field. (a) only works if you first move the surface grade OFF the `Type`
object into a separate judgment — which is strictly more work than (b). Do NOT pursue
(a) as "irrelevant Kind field."

**Architecture (b) separate IR-object layer — VERDICT: the real path.**
Add ungraded `IRTy` (base/product/sum/μ + ungraded arrow `_⇛_`), erasure
`⌊_⌋ : Type → IRTy` dropping Kinds, re-index `IR : IRTy → IRTy → Set`. Then
`⌊A ⇒[k] B⌋ = ⌊A⌋ ⇛ ⌊B⌋` for ALL k ⇒ `arr : IR X X` ≡ `id` ⇒ removable; the
`arr`/`valid-eff` codegen coercion case deletes (SimpleWF.agda:456–516,
ClosureWellFormed.agda:267–274/838, Validity.agda:134/161/229–230/301). Clean, and
IRTy is the honest computational-object language for the QTT/DTT future (grade becomes
a separate modality, not baked into the object).

**Blast radius (option b), rough:**
- `IR.agda` — remove `arr`, re-index over IRTy (~20 constructors). CORE.
- CCC codegen (SimpleWF, ClosureWellFormed, Validity, ApplyWF + WF modules) — re-type
  over IRTy (mostly signature churn; codegen is already grade-blind: 5–6 `mk-kind` each)
  and DELETE the arr/valid-eff coercion case. Medium.
- Denotation (Realize, ValueDomain, DenotTrace, Meaning) — compose with `⌊_⌋`; trivial
  since already grade-blind. Small.
- Frontend (Elaborate, RealizeAgrees, Completeness, Soundness, Canon*) — drop `arr'`,
  re-thread the surface→IR boundary through `⌊_⌋`. RealizeAgrees is the hot spot
  (211 `mk-kind`), but only the OBJECT-grade splits collapse — the RVar mirror's
  ~48 `mk-kind Many π` + 17 `mk-kind Many eff` pure/eff-object cases; the SURFACE grade
  enumeration STAYS (do not overclaim "all 211 collapse"). Medium-large.
- Optimizer — no logic change; `arr` constructor matches delete. Trivial.
- Re-extract MAlonzo.

**Net:** M2 is a wide-but-mechanical re-indexing (multi-day), de-risked: optimizer safe,
denotation coherence trivial, codegen grade-blind. The proof win is real but concentrated
(the codegen arr-coercion case + the RVar-mirror object dimension), NOT a wholesale
collapse of every grade split. Architecture = **(b) separate IRTy**; (a) is a dead end.
- **M3 — generalize to the lattice (OCP-0007).** Once `pure ⊑ eff` subsumption is
  in, swap the two-point `{pure,eff}` for the capability lattice; subsumption
  becomes attenuation (`S ⊑ S'`), inferred bottom-up by union, checked top-down.
