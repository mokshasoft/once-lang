## Architecture (discovered 2026-06-02 — grounds Milestone 1)
The type front-end has three layers that must stay in lock-step:

1. **Parsing relations** `Once/Parser/TypeRelation.agda` — mutual inductive
   `ParsesAtom → ParsesProd → ParsesSum → ParsesType` (+ `*Tail` variants),
   producing `Once.Type.Type` **directly** from tokens. `ParsesX-shrinks`
   lemmas give the residual-strictly-smaller facts the WF parser needs.
2. **WF parser** `Once/Parser/Type.agda` — `parseTypeAtomWF`/… return
   `Maybe (Σ Type rest (ParsesX toks T rest))`; soundness/completeness are
   intrinsic (the relation IS the spec).
3. **Grammar spec + bridge** `Once.Grammar.GType` (the user-facing grammar
   datatype) ↔ `Type` via `Once/Grammar/Convert.agda`
   (`gtypeToType`/`typeToGType`, both partial; round-trips both ways).
   `NoMuNu` (in Convert) is the structural predicate characterising
   grammar-expressible types; `Once/Grammar/ParserInvariant.agda`
   (`ParsesX-NoMuNu`) proves every parser output satisfies it, and
   `Printer.agda` relies on it for total printing.

`Once.Type.Functor = K Type | Id | _⊕_ | _⊗_`; `μ-type : Functor → Type`;
`NatF = K Unit ⊕ Id`. `Mu (K Unit + Id)` therefore reads as a **type-atom**
whose body is a **functor expression** in which `+`/`*` are functor
sum/product (`⊕`/`⊗`), distinct from the type-level `+`/`*`.

## Milestone 1 — Functor + μ type syntax (verified grammar extension)
Decision (user, 2026-06-02): **extend the verified grammar** — add the
productions + their round-trip proofs; no shortcuts, leave zero obligations.

**Key reframe — NoMuNu dissolves, it is not "relaxed".** Its sole purpose
is to exclude the two grammar-*inexpressible* `Type` constructors (μ/ν).
Once we make μ expressible (`GMu`), the parser legitimately produces μ and
`ParsesAtom-NoMuNu` (which asserts the opposite) becomes false. So we
*narrow* the predicate to `NoNu` (μ allowed, ν still has no surface syntax)
— or drop it and prove conformance directly. ν stays inexpressible.

Concrete work:
- **`Once.Grammar`**: add `GMu : GFunctor → GType` and
  `data GFunctor = GK GType | GId | _G⊕_ | _G⊗_` (mirror `Functor`).
- **Functor sub-grammar** (parallel mutual block, mirrors the type levels):
  `funcAtom ::= 'Id' | 'K' typeAtom | '(' functor ')'`,
  `funcProd ::= funcAtom ('*' funcAtom)*`,
  `funcSum ::= funcProd ('+' funcProd)*`, `functor ::= funcSum`.
  New `ParsesFunctor*` relations + `*-shrinks` + WF parser clauses.
- **New type-atom production** `pa-mu : ParsesFunctor toks F rest →
  ParsesAtom (TWord "Mu" ∷ toks) (μ-type F) rest`, with its WF parser clause
  and shrink case.
- **`Convert`**: `gtypeToType (GMu gf)`/`typeToGType (μ-type F)` via mutual
  `gFunctorToFunctor`/`functorToGFunctor`; extend both round-trips
  (`typeToGType-gtypeToType`, `gtypeToType-typeToGType`) with μ/functor cases.
- **`ParserInvariant` + `Printer`**: replace `NoMuNu` with `NoNu` (+ functor
  variant `NoNuF`); re-prove `ParsesX-NoNu`, `typeToGType-NoNu`, total print.
- Discharge **every** obligation the above introduces (no postulates).
