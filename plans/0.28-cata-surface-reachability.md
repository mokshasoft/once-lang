# Plan 0.28 — Cata surface-reachability (end-to-end recursion schemes)

## Goal
Make a real `.once` program that uses a catamorphism compile (`once build
--target x86_64`) to an executable and run with the expected exit code, as a
`cabal test` case (Layer 5). No builtins — expose the structured-recursion IRs
(`In`/`Cata`/`out-μ`) as **generators**, and define `Nat` as a `Strata/Derived`
module. Leave **zero** new proof obligations.

## Background (see [[project-cata-surface-reachability]])
- For x86_64 the whole pipeline is MAlonzo-extracted Agda; the proven
  `compile-ir (Cata …)` codegen is already in the `once` binary.
- The gap is the frontend: surface `Expr` / `SurfaceIR` have no In/Cata nodes,
  and the parser enforces a `NoMuNu` invariant (μ/functor types unparseable).
- `Nat = μ NatF`, `NatF = K Unit ⊕ Id` (`wf-NatF = wf-Sum (wf-K base-Unit)
  wf-Id`). `cata-isEven-full` is a model-level example, NOT a per-IR proof.
- General Cata correctness = the CataLayer machinery (separate; not blocking
  "does it run").

## Milestone 1 — Functor + μ type syntax (parser)
- Lift `NoMuNu` for the recursion-scheme path: parse functor exprs
  (`K T` / `Id` / `F ⊕ G` / `F ⊗ G`) and `μ F` types.
- The parser is intrinsically-typed/verified — keep its correctness proofs
  green; discharge any `NoMuNu`-derived obligations rather than postulating.

## Milestone 2 — In / Cata / out-μ as generators
- Surface `Expr` + `SurfaceIR` nodes (or `isPolyBuiltin` entries) for `In`,
  `cata`, `out-μ`, parametrized by the functor (+ algebra for `cata`).
- Elaborate to CCC.IR `In` / `Cata` / `out-μ`. Type + usage rules.
- Keep the surface↔IR correctness proofs (Surface/Correct, Desugar/Correct)
  green; close every obligation introduced.

## Milestone 3 — Strata/Derived/Nat.once
- `Nat = μ NatF`; `zero = In (inl unit)`; `suc = In ∘ inr`;
  `isEven : Nat → (Unit + Unit) = cata (case (inl unit) (case (inr unit) (inl unit)))`.
- Built purely from generators; no SigOps.

## Milestone 4 — green end-to-end + extraction
- Re-extract MAlonzo; `test/layer5-iseven.once` builds + runs to the right exit.
- `cabal test` fully green; no leftover `!!` / postulates from this work.
