# Plan 0.112 — Name the structures the formalization already has

## 0. Why

Plan 0.92 kept hitting name clashes (`_+_` from ℕ vs the type coproduct, `_≟_` under seven local
names). Each clash was "solved" by a suffix or a renaming: `_+ᵀ_`, `_≟str_`, `⟦_⟧ᴰᴵ`, `_>>=T_`. A
survey of the tree shows the suffixes hide one fact each time: **the same mathematical structure
on different carriers.** About 70 suffixed names come down to about six structures.

Naming the structure, as a lawful Agda record per carrier, is a bonus for **Once in Agda** whatever
**Once in Once** later gets as surface syntax (the two are separate decisions, §2.3):

* **proofs shrink**: one law set per structure, reused; the stdlib semiring solver can discharge
  usage arithmetic that is today written as `trans`/`cong` chains;
* **duplicates collapse**: the Quantity/Usage laws are proven twice (§1.B), `fmap`/cata/ana exist
  in parallel copies (§1.D);
* **it forces the right question about each type**: is this law true on the nose, only up to
  isomorphism, or only after `⟦_⟧`? Asking it about `_+_` on types already exposed that its
  associativity is NOT a syntactic equality (§1.E);
* the clashes disappear as a side effect (one symbol per structure, §2.2).

## 1. What the survey found

Nothing is declared as a structure today: no `Algebra.*` import, no `RawMonad`/`Effect.*`, no
`IsPreorder`/`IsEquivalence`/`Setoid`. The only `instance` declarations are stdlib's `NonZero`
(`Word.agda:81`, `⦃ NonZero slot-size ⦄` in `Adequacy/ArchCorrectness/FlatCore/*`).

Every law below is labelled **≡** (on the nose, syntactic equality), **≅** (only up to
isomorphism), or **⟦⟧** (only semantically: after interpretation, or up to bisimulation/`≈`).

### 1.E Up to isomorphism

* **Type-level `+`/`*` associativity, unit and symmetry are stated nowhere.** Witnesses exist one
  way only: `swapIR` (`Surface/Elaborate.agda:281`), `distribIR`/`distribute` (`:240,284`, no
  inverse). `In` ⇄ `out-μ` and `Out` ⇄ `in-ν` (`IR.agda:196–228`) exist both ways, with no round
  trip at IR level.
* **No notion of isomorphism exists**: no `Iso`, `Inverse`, `↔`, `≃` is defined or imported; the
  only `≅` is stdlib `HeterogeneousEquality` (term transport).
* Isomorphisms that ARE proven (Set level, ≡): `coerce-functor`/`coerce-struct` round trips
  (`Semantics/Value.agda:241–301`), Lambek (`fold-unfoldS`/`unfold-foldS`), `Type ↔ GType`
  (`Grammar/Convert.agda:172–229`).
* Equivalences: `≈ˢ` (`Adequacy/CoherenceLaws.agda:61`) is a full congruence (`*-cong`,
  `CoherenceLawsWrap.agda:48–168`), so the term model is a quotient, but it is not declared a
  setoid; `Behavior`'s `_≈_` (`Adequacy.agda:124`) is an abstract field with no `IsEquivalence`;
  the bisimulations reach `≡` only through postulates (`bisim-to-eq`, `bisimS-to-eq`).

## 2. Principles

### 2.1 Lawful by default

An instance is a CLAIM about the type. Use the law-carrying records (`IsCommutativeSemiring`,
`IsPreorder`, a lawful-monad record), not only the raw operations. A raw-only instance is allowed
where a law is genuinely false, with the reason written next to it. Where laws hold only **≅** or
**⟦⟧**, say so in the structure's type: a setoid-based structure over the right equivalence, or a
categorical structure where the isomorphism is data — never a `≡` law that is false.

### 2.2 One symbol per structure

Inside a structure the operation has ONE name (`_+_`/`_*_` of a semiring, `_>>=_` of a monad,
`_≟_` of decidable equality). Across structures, a fixed symbol each, so rows never clash:

| Structure | Symbols |
|---|---|
| semirings (ℕ, Quantity, Usage scalars) | `+`, `*` (stdlib) |
| type coproduct / product (Type, IRTy) | constructors `+`/`*` today — they clash with ℕ's function `_+_`; candidates `⊕`/`⊗` or stdlib-style `⊎`/`×` (decision §3 F0) |
| monoids (concatenation) | `++` |
| orders | `≤`/`⊑` per carrier family, `≟` for decidability |

Constructor overloading needs no instances: `Type._+_` and `IRTy._+_` already coexist, Agda picks
by type. The clash is only function-vs-constructor (ℕ).

### 2.3 Once in Agda vs Once in Once

This plan is about the **Agda formalization**. It does not decide what Once-the-language offers
(type classes, structures); OCP-0010 R7 ("no instance search") is a rule for Once. For the Agda
code the open choice is resolution style (§3 decision X): coherent instances (one per structure ×
carrier, declared with the structure or the carrier, never locally — resolution depends on the
type, not on scope) vs explicit naming at the use site (`T.bind`, `Q.+`). Either keeps the lawful
records; only the call-site spelling differs.

### 2.4 Measure

Instance search costs check time, and check time is already the bottleneck (memories: two-minute
module rule, apex perf sweep). Every phase records the apex check time before and after; a
regression above ~5% on a module stops the phase for a decision.

## 3. Phases

Ordered by payoff against risk. Each phase: change, gate (apex `Once/Certified.agda` +
`EverythingFiltered.agda` green under `-W error`), commit. Run tools in the tree; land output and
hand-fix (memory `feedback_bank_tool_output`).

**Decision X (before A):** instance style in the Agda code — coherent instances or explicit naming
(§2.3). Recommended: coherent instances, declared in the module that defines the structure or the
carrier.

### A. Decidable equality — mechanical, low risk
* A1. Every decider typed as `DecidableEquality X`; one name `_≟_` per carrier via the chosen
  style; the tag+diagonal pattern (`irtyTag`/`≟IRTy-diag`, `headTag`) as the shared recipe for
  the big enumerations.
* A2. Stop renaming stdlib deciders (`_≟str_` & co.): qualified use or the instance.
* A3. Delete Bool duplicates in favour of `does`/`⌊_⌋`; delete the 5 `≡ᵇ-refl` + 3 `≡ᵇ⇒≡`
  copies for stdlib's; one String-list membership (stdlib `_∈?_`/`any`).
* A4. The per-arch `Frame ≟` triplet becomes one generic definition over the arch parameters.

### B. The grade algebra — highest payoff (~2000 use lines)
* B1. One law set: merge `Surface/Properties` + `GradeMatrix` with `TypeCheck/Identities`; the
  `id-*` fields of `Verified` point at the merged lemmas.
* B2. `Quantity` as `IsCommutativeSemiring` (add `*q-comm`); ONE order (the relation; the Bool
  `≤q` becomes its decider `≤q?`), antisymmetry + totality ⇒ `IsDecTotalOrder`; `⊔q` with least
  upper bound ⇒ `IsSemilattice`/join; state it as an ORDERED semiring (monotonicity already proven).
* B3. `Usage n` as a semimodule over Quantity (stdlib `Algebra.Module` left semimodule), with the
  preorder and semilattice; thinning as a structure homomorphism (the `thin-usage-*` lemmas are
  its fields).
* B4. `Purity` as a bounded lattice; prove the `⊔p` laws and `⊔p`/`⊑π` agreement (feeds E).
* B5. Try the stdlib commutative-semiring solver on a sample of usage-arithmetic proofs; adopt it
  where it shortens proofs without costing check time (§2.4).
* B6. Antisymmetry for `⊑ᵘ` and `<:` where true (partial orders); where not (`<:` may be a proper
  preorder), say so.

### C. Monads, and the arrow
* C1. `T` as a lawful monad (raw ops + a laws record carrying the existing lemmas); delete the
  re-proven copies in `CoherenceLaws`/`CoerceFaithful`. `_>>=ᵖ_` likewise (respecting `opaque`).
* C2. `Res` gets its bind, or is replaced by `Maybe`; `Result`/`>>=R` and `maybe-bind` become
  Maybe's monad.
* C3. Delete the dead Parser monad (`Parser/Core.agda`); the parsers use explicit `with`
  (Acc-indexed), and stay that way.
* C4. Name `run` as a monad morphism `T → Run` (`run-bind` is its law); name `seqF` as the
  traversal / distributive law of polynomial functors over `T`.
* C4′. The observation is NOT part of `T`. Since plan 0.105 `T` is an interaction tree (its
  monad laws are ≡); the "traces up to n" of the old budget-indexed Writer (plans 0.46–0.98)
  moved to the observation: `projTrace`/`atT ι m n` (D058, `TraceMonad.agda:~286–298`) with
  `take-coh`/`Bounded`/`Saturating`. Name it as what it is: for each `n` an equivalence
  `m ≈ₙ m′ ⇔ atT ι m n ≡ atT ι m′ n`, a chain refining with `n` (prefix-coherent), and
  observational equivalence = `≈ₙ` for every `n` (and every `ι`). A ⟦⟧-kind structure on top
  of the monad, stated once instead of re-derived per proof.
* C5. Name the arrow: `Eff` = Kleisli(T) as a Freyd category over the pure category, `arr`
  the embedding (D032). Probably a record stating what already holds, no refactor.

### G. Findings of the 2026-10-09 merge analysis (categorical reviews of the Spec)
Not fixed on plan-0.91-program-facts; they belong here.
* G1. **Initial/terminal up to isomorphism, generally.** Plan 0.113 B2 introduces `Empty`/`Singleton`
  and the FFI skeleton (an empty codomain must BE `Void`, a singleton one `Unit`). Extend to the
  rest: `sub-void` only for syntactic `Void` (`Void * A` is initial too); the monoidal isos of §1.E.
* G2. **`T` over the program's signature.** `T` is free over a GLOBAL op universe; `run` fabricates
  an `unlinked` observable for undeclared ops and answers undeclared Unit-codomain calls with `tt`
  (inconsistent). Principled: `T Σ X` = the free monad on Σ's ops, `halt` = the ops of arity ⊥;

* G3. **Effectful `unfold` evaluates its coalgebra once.** `GradedOps.agda:160` re-runs the
  coalgebra TERM per forced layer (CBN in one position of a CBV meaning; D247 reasoned from the
  compiled artifact). Principled: bind the coalgebra once; its FUNCTION's effects run per layer
  (the final T∘F-coalgebra anamorphism) — or require a pure coalgebra position.
* G4. **Quantity variance in subtyping.** `sub-arr` (`Type/Sub.agda:84`) keeps the arrow quantity
  fixed; under affine `One` (D276) `A ⇒[1] B <: A ⇒[ω] B` is identity on meaning. Also `sub-μ`
  invariant: functor-pointwise variance `F ≤ G ⇒ μF <: μG` (and ν's functor).
* G5. **`k-base` inherits a codegen limit** (`WellFormedF` restricts `K A` to base types; `K A` is
  strictly positive for any closed `A`).
* G6. **One graded result former** `⟨π⟩B` (`⟨pure⟩B = B`, `⟨eff⟩B = Unit ⇒[eff] B`) instead of the
  pure/eff rule pairs (app/effApp, apply, Out).
* G7. **`⟨f,g⟩` is premonoidal** in Kleisli(T) with non-commutative T: product β/η only for central
  (pure) arms — state it where the BCC laws are restated (F1).
* G8. `⟦ rigid _ _ ⟧ = ⊥` is junk — restrict `⟦_⟧ᵛ` to `RigidFree` types. Monad laws of `T` via
  `RelT′` instead of the `extensionality` postulate (as D201 did for ν). Codata is call-by-name
  (no memoisation): state it in the Spec. `in-νᵈ`: the comment says `Out ∘ in-ν ≡ id`, it is `≡ η`.
