# Plan 0.131 — every CLI tool beside the compiler, as `once fmt` is

status: NOT STARTED (written 2026-10-30, at the user's request). Next step: §3 A.

relates: plan 0.124 (`once fmt`, the model), plan 0.39 (`elaborate`/`optimize` dumps), plan 0.130 / MERGE.md §1
(`once stats`), D320/D342.

## 1. Why

`once fmt` is orthogonal to the compiler: its own Agda tree (`Once.Format`), one pure function
(`formatSource : String → String ⊎ String`) over the Spec syntax and the parser, its theorem a separate field of
`Certified`, one bridge function, and a CLI handler that only does I/O. Nothing in the compiler knows it exists.

The other commands are not built that way. `Once.Compile` carries a dispatcher written for the CLI —
`data Stage = Parse | Check | Build`, `CompileResult = Parsed | Checked | Built | Error`, the legacy one-shot
`compile` — and three commands are cases of it:

| Command | Today | Defect |
|---|---|---|
| `parse`, `preprocess` | `compileFromModule … Parse` | the same call twice (`parse` adds "Parse OK"); an arch and alloc mode parsing ignores |
| `check` | `compileFromModule … Check` | arch fixed to x86-64, and with it the warnings |
| `elaborate`, `optimize` | `Compile.Dump.dumpIR` | own module, but `Heap` only (`build` takes `--alloc`); "the IR the build compiles" is a comment |
| `stats` | `Once.Measure.statsOf` | orthogonal; `Heap` only |
| `escape`, `codegen` | `runNotWired` | advertised in `--help`, do nothing |
| `build` | `compileFromModule … Build` | the compiler goes through the CLI's stage switch |
| — | `Compile.compile`, `compileModule`, `Bridge.compile` | no caller |

## 2. Target

1. **The compiler exposes functions, not stages.** `build` calls `compileFileFromModule` and `printFile` (both
   exist). `Stage`, `CompileResult`, `built-of`, `compile`, `compileModule` and their show helpers are deleted.
2. **One tree and one pure function per tool**, none imported by the compiler:
   - `Once.Inspect` — `parse` (signatures), `check` (accepted, or the error, plus warnings), `elaborate`/`optimize`
     (absorbs `Compile.Dump`);
   - `Once.Measure` — `stats` (done: `Once.Measure`, `Measure.Image`);
   - `Once.Format` — `fmt` (unchanged).
3. **A tool describes what `build` compiles**: the inspection and measure tools take `--alloc` (and `check` takes
   `--target` for its warnings) with `build`'s defaults. "The IR shown is the IR the build compiles" becomes a
   theorem (it is definitional today: both call `compileResolvedModule`), carried beside fmt's in `Certified`.
4. **The surface**: `parse` and `preprocess` become one command; `escape` and `codegen` are deleted from the CLI
   and the usage text.
5. **Haskell**: one bridge module per tool (`Once.Compile.Bridge`, `Once.Inspect.Bridge`, `Once.Measure.Bridge`,
   `Once.Format.Bridge`), so a re-extraction changes the bridge of the tool whose names moved; each handler in
   `Once.CLI` is I/O plus one bridge call. The tests drive the `once` binary and do not change.

## 3. Steps

**A. Retire the stage switch.** Restate the apex-side facts over `compileFileFromModule`: `Adequacy/MainBuilds`
(`compileFromModule … Build ≡ Built asm`), `Adequacy/Compile` (already proves `compileFromModule … Build ≡
built-of arch (compileFileFromModule …)`, which then goes), `AcceptSound`, and the comments that name
`compileFromModule` (`ShapeTable`, `Contract`, `NameClash`, `SMPrimitives`, `Surface/Elaborate`). Delete `Stage`,
`CompileResult`, `compile`, `compileModule`. `build` calls `compileFileFromModule` + `printFile` through the bridge.

**B. `Once.Inspect`.** `parse`, `check`, `elaborate`, `optimize` as pure functions over `Resolved` (with `AllocMode`
and `Arch` where they matter); `Compile.Dump` folds in. The "same IR as the build" theorem.

**C. CLI and bridges.** Per-tool bridge modules; `parse`/`preprocess` merged; `escape`/`codegen` deleted; usage
text; `--alloc` on the inspection tools and `stats`.

**D. Closing.** Decision entry (the rule: a CLI tool is a function beside the compiler, never a mode of it) and its
`internal.md` line; the extraction root lists the tools; exit tests ×3, `cabal test`.

## 4. Done when

`Once.Compile` has no CLI-shaped type; every command other than `build` is one function in its own tree, imported by
no compiler module; each bridge module serves one tool.
