# Plan 0.34 — Conditional branch as one portable unit (retire the flags-register x86-ism)

## Diagnosis

The flat machine models a conditional branch as **two** abstract
instructions: `c-test-scratch` / `c-test-tag` (set `fzf`) then `c-je
target` (read `fzf`). That split mirrors **x86's microarchitecture** (a
flags register: test sets it, branch reads it). It is the control-flow
analogue of the 1-to-1 lockstep mistake — the abstract machine invented
structure matching *one* target.

**The symptom** is a flag-liveness hole: x86 `add`/`sub` (`input2-inc`,
`scratch-dec`) clobber `zf` as a side effect, but the flat reg-ops don't
touch `fzf`, so `CompiledCorr`'s `zf-eq` (x86 `zf ≡ fzf`) breaks at the
intermediate state after such an op (where `zf` is dead but the invariant
still must hold to be a real proof, not a hole). This only exists because
the branch is modeled at x86's granularity.

## Design — branch as one unit, lowered per target (plus-simulation)

Model a conditional branch as a SINGLE abstract instruction carrying its
condition + target, and let each backend lower it to whatever block it
needs (the same plus-simulation discipline as `alloc-heap`: 1 abstract op
→ a target-specific instruction count):

- `c-branch-scratch-zero target` — "if `Scratch == 0`, jump to `target`."
- `c-branch-tag-zero target`     — "if `*Input1`'s tag `== 0`, jump."
- keep `c-label` / `c-jmp` (every target has labels + unconditional jump).
- DROP `c-test-scratch` / `c-test-tag` / `c-je`.

Per-target lowering:
- x86-64:  `cmp rbx,0 ; je target`  /  `cmp [rdi],0 ; je target`  (2 instrs)
- RISC-V:  `beqz rbx, target`  (1 instr — compare-and-branch)
- ARM:     `cmp ; b.eq`  (2 instrs)

### Why this DISSOLVES the flag problem (not just solves it)

With the branch as one unit, the condition is computed AND consumed inside
the single step:
- **No `fzf`** field in `FlatState` — no intermediate flag state.
- **No `zf-eq`** field in `CompiledCorr` — nothing for `add`/`sub` to break.
  The x86 `zf` clobber is invisible because `zf` is never a shared invariant.
- The **flags register (an x86/ARM-ism) leaves the SHARED abstract machine.**
  RISC-V wiring later needs no rework — `c-branch-*` already lowers to `beqz`.

This is the right-abstraction-makes-the-problem-vanish move, the control
analogue of [[feedback-injectivity-not-lockstep]].

## Blast radius

- **`SMCore.FlatCtrl`**: drop `c-test-scratch`/`c-test-tag`/`c-je`; add
  `c-branch-scratch-zero`/`c-branch-tag-zero : Label → FlatCtrl`. (FlatCtrl
  now uses `Label`? — abstract targets are ℕ today; keep ℕ for the abstract
  side, x86 wraps in `once` at compile-abstract, as established in 0.33.)
- **`Flat.FlatState`**: remove `fzf`; **`flat-exec-instr`**: `c-branch-*`
  computes the condition (`sv-is-zero (Scratch)` / `tag-zf (*Input1)`) and
  `do-jump (find-label prog target)` or falls through; remove the
  `c-test-*`/`c-je` clauses + the `fzf`/`do-je` machinery.
- **`AbstractToX86.compile-abstract`**: `c-branch-scratch-zero t →
  cmp rbx,0 ∷ je (once t) ∷ []`; `c-branch-tag-zero t →
  cmp [rdi],0 ∷ je (once t) ∷ []`. (x86-len = 2.)
- **`ir-to-trace`** cata: emit `c-branch-scratch-zero ld-end` etc. in place
  of `c-test-scratch ∷ c-je ld-end`. Shrinks the trace.
- **SMPrimitives**: the per-instr invariant clauses for the dropped/added
  FlatCtrl constructors (case-on-tag-style treatment, mirror existing).
- **Proofs**: `sim-test-scratch`/`sim-test-tag` (FlatCorrespondence) fold
  into a `sim-branch-*` (block of 2 x86 instrs); `FlatComposition`
  `HeadView`/`headView` swap `c-je`/`c-test-*` for `c-branch-*` (a
  `c-branch` block `cmp;je` has no `label`, so it's a plain head — the
  `find-label-pres` core survives); `CompiledCorr` loses `zf-eq`.
- 3 backends mirror; re-extract + re-test layer5 exit 42.

## Staging

- **M1 — `FlatCtrl` change** (`SMCore`): swap the constructors. Cascade the
  abstract machine (`Flat`, `flat-exec-instr`, remove `fzf`) + `SMPrimitives`
  per-instr invariants + the 3 backends' `compile-abstract`/`DirectSimulation`
  stubs until the frontend typechecks.
- **M2 — codegen**: `ir-to-trace` cata emits `c-branch-*`; re-extract;
  layer5 exit 42.
- **M3 — proofs**: fold `sim-test-*` → `sim-branch-*`; update
  `FlatComposition` `HeadView`; drop `CompiledCorr.zf-eq`; resume Stage 2
  block-step with no flag-liveness obligation.

## Relationship to 0.32 Stage 2

This is a prerequisite refinement: it removes the `zf-eq` obligation that
was blocking `block-step`. After M3, Stage 2's block-step has only DATA +
pc-offset to preserve — no flags.
