# Plan: Reorganize Axioms as CCTower + BCCR.Theory

## Goal

Reorganize the Axioms folder to reflect the **CCTower** - a layered categorical structure where each level extends the previous. Properties proven at lower levels lift to higher levels, giving compositional proofs.

## The CCTower (5 Levels)

```
┌─────────────────────────────────────────────────────────────┐
│  CCT4: + νF, Out, ana (final coalgebras / coinductive)      │
│    Properties: DERIVED from CCT3 + Coalgebra theorems       │
│    = Full BCCR                                              │
├─────────────────────────────────────────────────────────────┤
│  CCT3: + μF, In, cata (initial algebras / inductive)        │
│    Properties: DERIVED from CCT2 + Lambek's Lemma           │
├─────────────────────────────────────────────────────────────┤
│  CCT2: + initial, inl, inr, [_,_] (coproducts)              │
│    Properties: DERIVED from CCT1 + coproduct preservation   │
│    = BCC (Bicartesian Closed Category)                      │
├─────────────────────────────────────────────────────────────┤
│  CCT1: + curry, apply (exponentials)                        │
│    Properties: ESTABLISHED (Lambek & Scott 1986)            │
│    = CCC (Cartesian Closed Category)                        │
├─────────────────────────────────────────────────────────────┤
│  CCTB: terminal, fst, snd, ⟨_,_⟩, id, ∘                     │
│    Properties: BASE CASE (trivial/definitional)             │
│    = CC (Cartesian Category)                                │
└─────────────────────────────────────────────────────────────┘
```

Each level EXTENDS the previous. Proofs at higher levels REDUCE to lower levels.

## Why Extension Makes Proofs Simpler

### Monolithic Approach (Hard)
Prove confluence for full BCCR all at once:
- Handle ALL rules simultaneously (~15+ rules)
- Prove ALL pairs are orthogonal
- One massive proof with O(n²) cases

### Tower Approach (Simple)

```
CCTB confluence:
  - Just: id, ∘, fst, snd, ⟨_,_⟩, terminal
  - Base case, ~6 rules, trivial

CCT1 confluence:
  - ASSUME: CCTB confluence ✓
  - PROVE: curry/apply preserve it
  - Only ~2 new rules + orthogonality to products

CCT2 confluence:
  - ASSUME: CCT1 confluence ✓
  - PROVE: inl/inr/[_,_] preserve it
  - Only ~3 new rules + orthogonality to exponentials

CCT3 confluence:
  - ASSUME: CCT2 confluence ✓
  - PROVE: μ/In/cata preserve it
  - Uses Lambek's Lemma (imported, not re-proven)

CCT4 confluence:
  - ASSUME: CCT3 confluence ✓
  - PROVE: ν/Out/ana preserve it
  - Uses coalgebra theorems (imported, not re-proven)
```

**Each proof is small** because:
1. It ASSUMES the previous level's result
2. It only proves NEW constructs preserve the property
3. Established math is IMPORTED, not re-proven

**Same for normalization, fixpoint uniqueness, etc.**

## The Beauty of This Structure

```
CCT4 (Full BCCR)
    ↓ reduces to
CCT3 + Coalgebra theorems
    ↓ reduces to
CCT2 + Lambek's Lemma
    ↓ reduces to
CCT1 + coproduct preservation
    ↓ reduces to
CCTB + exponential preservation
    ↓ reduces to
Base case (trivial/definitional)
```

Each proof is SMALL because it only handles ONE extension at a time.

## Summary

This reorganization:
1. **Clarifies the structure**: 5 levels, each extending the previous
2. **Simplifies proofs**: Each extension proof is small and focused
3. **Separates concerns**: Established math in Established/, tower in CCTower, unified theory in BCCR/Theory
4. **Enables future work**: Proving BCCR Theory = proving each tower extension
