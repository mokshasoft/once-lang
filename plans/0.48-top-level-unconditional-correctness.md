# Plan 0.48 — One unconditional top-level correctness; wire every proof under it

## The single claim

There is **one** top-level theorem. Everything else (judgment, faithful,
adequacy, soundness, completeness, optimizer/escape/fusion, flat-sim) is a
**link that discharges a named obligation inside its proof** — never a sibling.

The claim is **unconditional meaning-preservation** over a **total** denotation:

```
correct : ∀ arch src →  maybe (exec arch) rejected (compile arch src)  ≈  ⟦ src ⟧
```

with a **distinguished `rejected : Behavior`** (no real execution is `≈ rejected`)
and `⟦_⟧ : Source → Behavior` **total** — an *invalid* source denotes `rejected`.
This single line is:

- **soundness** — `⟦src⟧ = rejected` ⇒ `compile = nothing` (can't accept the
  meaningless, since `exec _ ≉ rejected`);
- **completeness** — `⟦src⟧ ≠ rejected` ⇒ `compile = just _` (can't reject the
  meaningful);
- **trace-correctness** — accepted ⇒ `exec bytes ≈ ⟦src⟧`.

`valid`/soundness/completeness are **corollaries**, not record fields.

## Non-negotiables (the shape, fixed first)

1. `⟦_⟧` is the **independent** source meaning (the surface denotation `⟦_⟧ˢ`
   on the typed term + `rejected` off-domain), **NOT** defined via `compile`/
   `moduleToIR` (else soundness is circular / true-by-construction). This is the
   one real content change from today's `⟦ moduleToIR src ⟧`.
2. Correctness is pinned at **`doOpt = false`** as the base, so the optimizer
   cannot mask a bug from another stage. The shipped `doOpt = true` binary is a
   **corollary** of base-correctness + `optimize-preserves-⟦⟧`.
3. Every per-stage fact is a **named postulate** in the instance until a proof
   discharges it. The shape can't be gamed; phases only ever *remove* postulates.

## Decomposition (per-stage links, chained by transitivity)

Only the **front-end** (parse+elaborate) is partial, so it carries
accept⇔valid; every later stage is total and carries only preservation:

| stage | obligation | discharged by |
|---|---|---|
| parse+elaborate | `accept src ⇔ valid src` ∧ meaning of accepted term | `VerifiedTypeChecker` (+ `faithful`) |
| optimize | `⟦ optimize ir ⟧ ≡ ⟦ ir ⟧` | `Optimize.Correct` (+ `Fusion`/`Escape`) |
| codegen → observable | `exec(codegen ir) ≈ ⟦ ir ⟧IR` | `IRObsCorrectFlat`/`cata-correct` (already wired) |
| machine refinement | flat ↔ target | `CompileCorrectFlat`/`FlatSim` (if a distinct stage) |
| assemble / emit / bytes | printer + `as` + loader | existing named postulates |

## Phases

- **Phase 0 — the statement (this plan's crux; review before editing).**
  - 0a (spec, `Once.Adequacy`): add `rejected`; restate `correct` unconditional
    (the one-way-ratchet edit). + a non-degeneracy `rejected-distinct`.
  - 0b (instance, `Once.Compiler`/`Adequacy.Compile`): give a **total, independent**
    `⟦_⟧` (invalid ↦ `rejected`); pin `doOpt=false`; prove the new `correct` from
    the existing `VC.correct` (valid/just case) + **named postulates** for the
    reject case, the front-end accept⇔valid, and `optimize-preserves-⟦⟧`.
  - Build green with postulates. Top now says the right thing.
- **Phase 1 — front-end link** ← `VerifiedTypeChecker` (fix `ErrorProofs`'s 3
  rotted `check-R*` lemmas) + `faithful`. Discharge accept⇔valid + meaning.
- **Phase 2 — optimizer link** ← `Optimize.Correct` (+ `Fusion`/`Escape`).
  Discharge `optimize-preserves-⟦⟧`; the `doOpt=true` corollary lands.
- **Phase 3 — machine link** ← `CompileCorrectFlat`/`FlatSim` (the recent island),
  if it is a distinct stage from the observable theorem.
- **Phase ∞ — delete.** Re-run reachability; whatever is *still* unreachable is
  now provably superseded (`DirectSimulation`, …) — delete that, only that.

## Discipline

Statement-first; discharge one link at a time; build green throughout; delete is
a mechanical leftover at the very end, never a judgment call mid-way.
