# Plan 0.128 — a result may share structure with its input (an optimization)

status: OPEN (written 2026-10-29, at the user's request). Not started. Future work: after plan 0.123's
B (reclamation under D6, choice A) is proved. No Spec change: the Spec's meaning does not see sharing.

relates: plan 0.123 B.1 D6 (static ownership) and D7 (two heaps), B.0 (`Once.Adequacy.NoLeak`), M4
(ownership classification), M7 (`heap-conservation`).

## 0. Where this starts

Plan 0.123 settles (user, 2026-10-29) that **a result never shares structure with a borrowed input**
(choice A). In `pair f g` on a heap value `x`, where `f` borrows `x`, a part of `x` that `f` returns
(`π₁`, a `case` branch's payload, a list's tail) is copied out, so `x` is freed whole after `g`, and
nothing the result holds points into `x`. An owned `x` is not copied: a projection moves its part out and
frees the rest. The cost of A is the copies: a large structure that a borrowing side only passes through
is copied in full.

## 1. The goal

Let a result point into an input the compiler knows outlives it, and skip the copy. Choice B: the
compiler tracks statically, for each result, which of its parts alias which inputs, and frees only the
parts nothing live still points to. Still no run-time information (D6): no counts, no flags.

## 2. What it needs

1. **An alias analysis** over the IR: for each output, the inputs (and paths into them) it may share. A
   static over-approximation is enough for soundness; precision buys fewer copies.
2. **Frees of parts.** A structure freed while a part of it lives on is freed by a walk that stops at the
   shared parts. The walk is generated from the type and the alias facts.
3. **The pop heap** (D7: the stack, under destination passing) frees by moving the stack pointer, so it
   frees everything above a point. A result that shares a pop-heap part of its input cannot outlive that
   input's frame: either such a part is copied (A, locally), or it moves to the cell heap.
4. **Linear values stay owned** (D6): sharing never makes a QTT-1 value aliased, so in-place update stays
   sound with no check.
5. **The proof**: NoLeak (B.0) is unchanged as a claim; `heap-conservation` (M7) gains the alias facts:
   a block is freed when the last value that may point into it is dead.

## 3. When

Only when copies show up as a cost in real programs (measure first: count the bytes copied per run on
the examples). Until then A stands.
