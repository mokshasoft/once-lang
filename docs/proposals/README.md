# Once Change Proposals (OCPs)

Proposals for significant changes to the Once language, compiler, or formal specification.

## When to Write an OCP

- Language syntax or semantics changes
- New generators or categorical structures
- Changes affecting formal verification
- Breaking changes to existing programs

For smaller decisions, use the [Decision Log](../compiler/decision-log.md) instead.

## Process

1. Copy `OCP-0000-template.md` to `OCP-NNNN-short-title.md`
2. Fill in the template
3. Submit for discussion
4. Update based on feedback
5. Accept/reject
