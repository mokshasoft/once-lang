## 2. Raw-M3c — CLOSED, and the file is retired

`SpikeErase.agda` — **`--safe`, zero postulates, zero holes, zero TERMINATING, 130
lines, 0.44 s** — proves `consistency : ∀ {t} → ε ⊢ t ∷ ⊥̇ → Empty` for the raw Church
calculus.

**Why it works.** `NbEPDirDTTCh`'s typing has six rules and **no conversion rule and no
𝕀 eliminator**, so a type never has to compute for a derivation to exist, and the
carrier can be read off the type SYNTAX alone: `⟦𝕀 t A B⟧T = ⟦A⟧T ⊎ ⟦B⟧T`, term-blind.
`wkTI`/`subTI` then become 4-case structural inductions with no environment, and
`MI ⊢app` needs no soundness invariant — so §4.2¹²'s `MI → MI-ty` back-edge does not
exist. Layer 2 (`⟨_⟩T`, a predicate over the fixed carrier) restores the honest
dependency and can never feed back into Layer 1.

**Two caveats, both in handoff §4.2¹³ — do not skip:**
1. Layer 1 ERASES the dependency: it proves consistency, not faithfulness.
2. The raw calculus **has no `bif`**, so its 𝕀 types are INERT — nothing can be
   introduced at an 𝕀 type except by assumption. Raw-M3c as written has no dependent
   content at term level to be faithful TO. **Adding `bif` to `_⊢_∷_` is what would make
   faithfulness non-trivial**; the `⊎` carrier and `⟨_⟩T` were written to accommodate it.

**Why `NbEPDirDTTChMF.agda` cannot be closed `--safe`:** `subTI` is postulated and
§4.2‴+§4.2⁹ show it is not closable in that architecture; the ~66 unsolved `--prop`

which only *reports* unsolved metas); `funext`/`funextP` remain axioms.

**⚠ THE ERASURE BOUNDARY — this is `SN⁺`'s obstruction from the other side.** Erasure

## 3. The linear core — where the real progress is

§1.3 of the plan resolved the long-open gating question as **a linear SMCC core with a
QTT `{𝟘,𝟙,ω}` layer in front** (Fox's comonoid layer = the `ω` fragment). Cheaper than
it looks: `formal/Once/Surface/Context.agda` already computes usage vectors that
elaboration currently discards, while `formal/Once/IR.agda` stays ungraded cartesian
with `AllocMode` on every intro. This is *stop throwing away information you already
have*, not *add a layer*.

### 3.1 linearization-6 — the exponential gap, CLOSED. The gate passes.

`PATHS.md` deferred `curry`/`apply` as "needing the comonoid on the argument". **They
need no comonoid at all.** `_*_` IS the tensor in this core, so
`lcurry : LTm (A * B) C → LTm A (B ⇒ C)` SPLITS the environment from the argument rather
than duplicating a shared source, and `leval : LTm ((A ⇒ B) * A) B` consumes each once.
Both dup-free (`df-lcurry`/`df-leval`), so **a pairing-free source WITH closures still
linearizes fully dup-free**. Fired concretely in `NbEPLinUse`: `closure-df`,
`closure-alloc-0`, `beta-alloc-1`, `beta-computes`.

Cost: `funext`, in **exactly one clause** — `curry`'s soundness equates two functions.
Threaded as a hypothesis, so everything stays `--safe` and postulate-free. `L-sound` and
`pipeline` gained a `FunExt` argument.

### 3.2 linearization-7 — dynamic cost, and operational linearity

`dupCount` is a STATIC count of `dup` generators. It is **neither an upper nor a lower
bound** on allocations, and closures are not the only cause — `case` already breaks it
in the first-order fragment. `NbEPLinDyn` settles it: an instrumented domain `⟦_⟧C`
(= `⟦_⟧T` except at `⇒`, where a function reports its own cost) and a cost semantics
`Lᶜ` (writer-monad reading of `Lⁱ`; building a closure is FREE, its body paid at
`leval` per call).

| where | direction | witness |
|---|---|---|
| `case` | **over**counts — static adds both branches, a run takes one | `case-over` |
| `lcurry` build | **over**counts — building is free whatever the body holds | `closure-build-free` |
| `lcurry` run | **under**counts — body dups fire once per application | `closure-per-app` |
| `lcata` | **under**counts — algebra runs once per node | `cata-under` |

**★ `dyn-linear`** — a `DupFree` morphism on `Free` inputs performs **zero allocations
at runtime**. Upgrades `dupfree-no-alloc` from syntax to execution, which is what "the
linear sublanguage allocates nothing" must mean for the memory dividend to hold. `Free`
is a real logical relation (at `⇒`: "applying it to any `Free` argument costs nothing")
— needed because `DupFree` cannot bound `leval`, whose input closure is an arbitrary
semantic value. **★ `pass-dyn`** — end to end: a pairing-free cartesian source compiles
to a program that allocates nothing at runtime.

⇒ **The honest payoff.** `pass-alloc` stays exactly true as the SYNTACTIC invariant
relating pass output to pass input. It is **not** an operational bound. Operationally:
pairing-free ⇒ provably zero; otherwise the figure depends on the RUN and cannot be read
off the syntax.

### 3.3 linearization-8 — ★ THE Lin↔QTT BRIDGE, BUILT (§1.3 gap 3 CLOSED)

`NbEPLinQTT` — **`--safe`, zero postulates, zero holes, 491 lines, ~1.9 s** — is the
first module to import both lines. `Γ ⊢[ρ] A` elaborates DIRECTLY into `LTm`, with the
usage vector indexing the context OBJECT (`⟪_⟫ᶜ`), not just the source judgment.

**The central move: context addition is TENSOR SPLITTING, not duplication.** `_+ᵘ_`
becomes `split`, which routes each slot to whichever side demands it. A `dup` appears
in exactly one clause — both sides demanding the same slot — and the semiring makes
that the `ω` clause, because `𝟙 +ᵐ 𝟙 = ω`. So "a `𝟙`-graded variable reaches the linear
core with no `dup`" is *forced by `Mult`'s addition*: `split-df`'s four both-demanded
clauses are absurd patterns.

- ★ `bridge-linear : LinD t → DupFree Lq⟦t⟧` — the `𝟙` half of §1.3's shape.
- ★ `Lq-sound` — semantics preserved (threaded funext, the two `lcurry` clauses).
- ★ `bridge-dyn` — via `dyn-linear`: **zero allocations at runtime**, now from a
  GRADED SOURCE rather than a hand-written linear term.
- `erase-K≡id` — `𝟘` erases on the nose: `Lq⟦K⟧ ≡ Lq⟦idₗ⟧ ≡ lcurry sndL`.
- `ω-alloc-1` / `ω-not-linear` — `ω` costs exactly one `dup`, and `LinD` refuses it.

**The payoff, measured** (same source, both routes, all `refl`):

| source | naive `⟦_⟧` then `L⟦_⟧` | bridge |
|---|---|---|
| `pair (var (vs vz)) (var vz)` | 1 alloc | **0** |
| `app (var (vs vz)) (var vz)` | 1 alloc | **0** |

**⚠ What it cost the core — a real finding.** `LTm` had **no associator and no
braiding**. The cartesian pass never needed them (`⟨_,_⟩L` buys any rearrangement for
one copy); splitting cannot pay that price. `lassoc`/`lassoc⁻`/`lswap` were added to
`NbEPLinRec` (dup-free, cost 0) plus the derived `mixL`, with clauses through
`Lⁱ`/`dupCount`/`frees`/`dupfree-no-alloc`/`Lᶜ`/`dyn-linear`. **The core is only now
genuinely symmetric monoidal.** Chain re-verified: 11 modules, all exit 0.

## 6. Tooling and method notes

- `./check-mf.sh <File.agda>` batch-checks any module here. Spikes and the whole `Lin`
  chain check in **≲1 s** (deps are `.agdai`-cached). `NbEPDirDTTChMF.agda` takes ~10 min
  and is the only slow one — and it is retired, so the compile ceiling no longer bites.
- **Exit 42 with `unsolved interaction metavariable` = deliberate holes**, not failure.
  For the spikes, the signal to read is the *termination* outcome, not the exit code.
- **Read the "Problematic calls" list, not the failing-function list.** The latter is the
  whole SCC, not a diagnosis.
- **Always include a deliberate non-terminating `bad` control** in a termination spike.
  All twelve spikes carry one; all twelve fire. Re-verified this session — every
  documented verdict reproduces.
- Agda does **not** termination-check `where`-bindings the body never uses; route
  recursive calls through `force`.
- Value bindings whose TYPE is a function type must be written **INLINE**, not
  `where`-bound — a where-bound value becomes an auxiliary definition and applying it
  counts as a call with no descent.
- `_×_` is `Σ` (a record, so η holds); `fst`/`snd` come from `open Σ`, not from the
  `Types` module's export list. `_,_`, `_+ℕ_` and `_≡_` are all level 20, so **parenthesise
  pairs whose components use them**.
