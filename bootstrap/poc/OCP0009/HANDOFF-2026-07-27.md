## 2. What this session ruled OUT — do not retry these

Seven prior spikes (§4.2⁗–§4.2⁸) had converged on "the `MI → wkTI` edge is the whole
problem". Today added three results.

**§4.2⁹ — "Option 1" (Acc + bound-free wrappers) is DEAD.** `SpikeAcc2.agda` implements
§4.2⁸'s recommendation in full (Acc on the WHOLE `CI/TI/MI/envO/wkTI/nat-TI` cycle). Agda
rejects it. Two independent causes:
1. the bound-free wrapper `TI wA ρ = TIa wA ρ (wfAcc _)` is itself a non-decreasing call
   *inside* the block, and cannot be lifted out (`CI`'s IR constructor mentions it);
2. `nat-TI`'s conclusion puts `TI (ren⊨ r wA)` and `envO …` **in a type** — no measure
   plumbing reaches a call in a signature.
Bonus finding: the live file's `--prop` bound-irrelevance is **load-bearing**. `Acc` must be
Set-valued (SplitInProp), so bridging needs `cong (TIa wA ρ) (accIrr …)` — a partial
application of a mutual-block function, i.e. yet another non-decreasing edge.
⇒ **`subTI` is not closable by re-plumbing the measure, in any form now tried.**

**§4.2¹⁰ V1 — "store the value at the weakened wf" is not a redesign that exists.** The slot
would need type `Êl (TI wR (ρ ∷ᴱ v))`: a constructor field mentioning the constructor's own
RESULT. Not induction-recursion — genuine self-reference. Storing the *equation* instead
fails identically.

**Also rejected (tested):** baking the well-formedness proof into `CI`. It makes `envO`'s
keep clause need `nat-TI`, resurrecting the exact edge §4.2¹⁰ removed.

## 3. What this session found that WORKS

**§4.2¹⁰/§4.2¹¹ — a type-agnostic `MI` breaks the blocking edge.** `MI : Δ ⊢ t ∷ A → CI Δ →
Val` with `Val = Σ Û Êl` (+ `⊤̂` for junk); MI's type never mentions `TI`.
`SpikeCIR.agda` / `SpikeCIRa.agda`, both ~1 s. Verified:

- `CI` becomes a **plain datatype** — no induction-recursion.
- `TI`'s 𝕀 clause reads the condition via `asBool : Val → 𝟚`, so **TI depends on no
  soundness invariant**.
- `MI ⊢vz`/`⊢vs` are **pure projections** — no `wkTI`. `⊢lam` is definitional.
- Therefore `envO (keep r wA) (δ ∷ᴱ x) = envO r δ ∷ᴱ x` — **no nat-TI coercion**. That is
  the edge that made the §4.2⁶ cycle close.
- `MI ⊢app` **closes with no hole** via a mutual `MI-ty : fst (MI td ρ w) ≡ TI wA ρ w`,
  with well-formedness carried SEPARATELY as `CIwf` (never baked into `CI`).

**§4.2¹² — Test B: the layering is ONE edge from stratified.** `SpikeCIRb.agda` puts the
real `wkTI`/`nat-TI`/`nat-MI`/`envO-wf` back. It fails termination (`TI, MI, MI-ty, wkTI`),
**but `envO-wf`, `nat-TI` and `nat-MI` are NOT in the failing set** — the naturality layer
orders on its own. The layering that emerges:

| layer | contents | status |
|---|---|---|
| 1 | `CI`, `envO` — pure, no proofs | ✅ verified |
| 2 | `CIwf`, `TI`, `MI` — ⊢vz/⊢vs projections | ✅ verified |
| 3 | `envO-wf`, `nat-TI`, `nat-MI`, `wkTI` | ✅ orders on its own |
| 4 | `MI-ty`, `subTI` | would be downstream |

**The only back-edge in the whole architecture is `MI ⊢app → MI-ty`** (Layer 2 reaching
into Layer 4). Remove it and everything stratifies into `.agdai`-cached modules with no
cycle and no measure anywhere — which would also retire the compile-ceiling problem.

⚠ Route (a) alone does **not** reach the theorem: its cycle needs a measure, and a measure
on `TI` reintroduces P1 (bounds in every statement mentioning TI) — exactly what §4.2⁹
failed to escape.

**(b) Untyped function space** — `π̂ : (a : Û) → (Val → Û) → Û`, `Êl (π̂ a b) = (v : Val) →
Êl (b v)`, making `⊢app` just `(b (MI tu ρ) , f (MI tu ρ))` with no coercion, hence no

## 6. Tooling facts (corrections to the older handoffs)

- **The 600 s harness cap is NOT a blocker.** Background execution (`run_in_background`)
  runs detached and notifies on completion. `HANDOFF-NbEPDirDTTChMF.md` §2's "you will not
  get feedback" is stale.
- **`NbEPDirDTTChMF.agda` interactive load takes ~26 min**, not the ~10 min §2 estimates.
  Batch is longer. Budget accordingly.
- `./check-mf.sh <File.agda>` batch-checks any module in this folder; spikes check in ~1 s
  because `NbEPDirDTTCh` is `.agdai`-cached.
- **Method trap 1:** value bindings whose TYPE is a function type must be written **INLINE**,
  not `where`-bound — a where-bound value becomes an auxiliary definition and applying it
  counts as a CALL with no descent. This alone failed a whole SCC today.
- **Method trap 2:** the "Termination checking failed for the following functions" list is
  the whole SCC, **not a diagnosis**. Read the "Problematic calls" list.
- **Method trap 3 (§4.2⁴, still true):** Agda does not termination-check `where`-bindings the
  body never uses. Route recursive calls through `force`, and always include a deliberate
  non-terminating CONTROL — every spike today did, and it caught nothing spurious.
