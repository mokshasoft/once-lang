## 1. THE MEASUREMENT THAT MATTERS

★ **Context depth is NOT what drives cost once the data are abstract.**

`ΓSS` is **8** slots under option C against **12** under option B. At
`SPIKE-COST`'s ~1.7× per slot that predicts option C should be ~8×
*cheaper* on this branch. It is instead **too big to finish**, both halves,
including a retry under `+RTS -c`.

★★ **What drives it is the `w`-tower depth on OPAQUE terms.** Under option
C the data are Agda-level terms, so every occurrence of the motive or a
measure is `renTm vs` iterated 11–14 times around `cP`/`μ₁`/`μ₂`, and every
conversion check walks that chain. Under `Γ₅` the same occurrences were
`var (vs^k vz)` — a variable, and cheap.

★★★ **And the transports scale with IH APPLICATION, not with branch size.**
What option C saves is roughly linear in slots removed. What it costs is
the naturality kit, and that grows with how deeply the IH is *applied*:
one reassociation of the IH's own type, plus **one fitting lemma per `⊢app`
argument**. Hence the exact ordering observed:

* (0,0) — `rec₁`/`rec₂` both vacuous, **no IH ever applied** → C wins big;
* (0,S) — inner IH, 3 arguments → C wins slightly;
* (S,0) — **outer** IH, 4 arguments (`n₂ := μ₂ y` comes first, so every
  later argument's expected type carries that substitution too) → C loses;
* (S,S) — both IHs live → C cannot finish.

⚠ **Do not "fix" (S,S) by splitting further.** Splitting helps when a
MODULE is too big. Here a SINGLE DERIVATION is: `⊢lexSSrec1` and
`⊢lexSSrec2` each exceed the cap alone, in their own modules, with nothing
else in them.

## 3. WHAT THE KIT GAINED (`LexC`, all green, all reusable)

* **`nrs-w`** — the THIRD weakening flavour. `⊢natrec`'s *step* motive is
  `subTy nrs M`, and `nrs` is neither a `single` nor an `extS`; on a
  weakened term it is just one more weakening. Needs
  renaming-as-substitution (`ren-sub`), which is `subTm-id` composed with
  `renTm-subTm` — `ρ ᵣ∘ₛ idₛ` **is** `λ x → var (ρ x)` by eta, the same
  move `sub-w`/`ren-w` make.
* **`lStepT-w²…⁶`, `auxBody-w²…⁷`** (in `LexC`) and **`auxMotB`,
  `auxMotB-w²…⁹`, `lStepT-w⁷…⁸`** (in `LexCMot`) — the `⊢wk` ladders. Each
  `⊢wk` leaves one more `renTy vs` OUTSIDE the combinator, which Agda
  pushes into the Π-chain instead of reassociating.
* **`auxMotB`** — the outer motive as a combinator. ⚠ Its μ₁-bound must be
  a **parameter**: `renTy vs` does not preserve the `var (vs vz)` that
  `lexAuxMot` writes inline, so a combinator with the bound written in
  cannot have a `-ren` lemma at all.
* `LexCMot` is split off so (0,S), which uses none of it, does not
  deserialise it. ⛔ No saving is claimed — see that module's header.

⚠ Branch (0,0) predates the ladders and inlines its own four-level chain.
It is green; it was left alone.
