## 4. W1h — `fund`. The next step.

### 4.0 ★ READ FIRST: syntactic validity is a DEAD END, and `⊢conv` needs no premise

The natural first move is `validity : ⊢ctx Γ → Γ ⊢ t ∷ A → Γ ⊢ty A`. **Do not
build it.** Its `⊢conv` case needs `⊢ty` closed under conversion, which is *not
provable*: the forward direction goes through (via `sr`), but the backward one
does not, because a `ty-Π` derivation does not record that its components were
`El`s. Closing that would force a `Γ ⊢ty B` premise on `⊢conv` — cascading into
all ~14 of `sr`'s `⊢conv` reconstructions, far beyond option A's two modules.

None of it is needed. State `fund` in **existential** form:

```agda
fund : ⊢ctx Γ → Γ ⊢ t ∷ A → ⊩ˢ Γ σ →
       Σ (⊩₁ (subTy σ A)) (λ R → R ⊩₁∋ subTm σ t)
```

Then `⊢conv` is discharged by `conv₁` + `sem-conv` — **the relation is already
closed under conversion, which is exactly what W1b bought.** No validity lemma,
no `⊢conv` premise, no `⊢ty`-closed-under-conversion. This is *why* option A's
cascade stayed at two modules, and it was found by trying to write `fund`.

### 4.1 The steps

1. **`⊩ˢ Γ σ`** — reducible substitutions: for each `Γ ∋ x ∷ A`, a
   `⊩₁ (subTy σ A)` together with a member at `subTm σ (var x)`. Plus the
   extension `⊩ˢ Γ σ → … → ⊩ˢ (Γ ▹ A) (σ,u)` used by `⊢lam`/`ty-Π`, and the
   variables-only instance used to start the induction.

2. **★ `⊩₁`-SHAPE INVERSION — the one genuinely new lemma.** `⊢app` recurses on
   the function to get some `R : ⊩₁ (Π A B)[σ]` and must read off its `Π`
   payload; a priori `R` could be any constructor. `⊩₁base`/`⊩₁U`/`⊩₁ne`/`⊩₁Σ`
   at a `Π`-shaped type are all refutable by `joinW` + `Π-reduct` — **the same
   refutations `irrel₁` already contains**, so extract them as `⊩₁-Π-inv` and
   `⊩₁-Σ-inv` (~30 lines each) rather than re-deriving.

3. **`fund-ty` / `fund`, mutual.** Every case has its lemma already:

   | rule | lemma |
   |---|---|
   | `⊢var` | `⊩var₁` (from `⊩ˢ`) |
   | `⊢lam` | `sem-lam`; its `⊢ty` premise feeds `fund-ty` |
   | `⊢app` | `⊩₁-Π-inv` + `sem-app` |
   | `⊢pair` | `sem-pair` |
   | `⊢fst` / `⊢snd` | `⊩₁-Σ-inv` + `sem-fst` / `sem-snd` |
   | `⊢⌜base⌝` / `⊢⌜Π⌝` / `⊢⌜Σ⌝` | `sem-⌜base⌝` / `sem-⌜Π⌝` / `sem-⌜Σ⌝` |
   | `⊢conv` | `conv₁` + `sem-conv` |
   | `ty-base` / `ty-U` / `ty-Π` / `ty-Σ` | `⊩₁base` / `⊩₁U` / `⊩₁Π` / `⊩₁Σ` at `doneᵀ` |
   | `ty-El` | `sem-El` + `emb` |

   For `ty-El`, `fund` returns an existential, so move it onto `⊩₁U doneᵀ` with
   `irrel₁ crflᵀ` first (`subTy σ U = U`, so both are derivations of the same
   type), then `sem-El`, then `emb`.

4. **`wnorm : ⊢ctx Γ → Γ ⊢ t ∷ A → WN t`** via `wn`, hence **`dec-conv`
   unconditional** and Phase 1 closed.

⚠ **The headline is WEAK normalization, not strong.** Nothing proves inductive-`SN`
equivalent to accessibility-`SN`; that stays open and is only worth doing if SN is
wanted for its own sake. Nothing downstream needs it — `dec-conv` consumes WN.
(If it is ever wanted: Once's optimizer rewrites the IR in arbitrary order, which

## 5. ★ NEGATIVE RESULTS — do not re-attempt

All found this session; three of them after the route had been recommended one
step earlier. Exact errors recorded so nobody pays twice.

**(a) Spine inversion for head expansion** (`SpikeSNX` §5). Not "bulky" —
unstateable. `_·_` is a function, so `app (lam s) u · sp` with `sp` a variable is
a STUCK term, and a stuck term can never be unified against a constructor
pattern:

```
SplitError.UnificationStuck
I'm not sure if there should be a case for the constructor β …
  app (lam t) u ≟ app (lam s) u₁ · (sp ▸ x)
```

Restructuring the inversion datatype does not help (its own proof needs the same
split), nor does cons-shaping `_·_`. Superseded by JM (`SpikeSNJ`).

**(b) An unstratified `U` clause carrying reducibility** (`SpikeSNK`):

```
NotStrictlyPositive
⊩_ is not strictly positive, because it occurs
  in the second argument of _×_ in the second clause
  in the definition of _⊩∋_, which occurs
  to the left of an arrow in the type of the constructor ⊩Π
```

`⊩Π`'s function field puts `⊩∋` negatively, so a `⊩` in `⊩∋`'s result makes `⊩`
occur negatively in its own definition. W1a's knot and this one are each fine
alone and not together. **Stratification by universe level is forced**, and it
stops at two levels only because the kernel's universe is predicative — codes are
`⌜base⌝`/`⌜Π⌝`/`⌜Σ⌝` with *no code for `U`*. Corollary for later: a hierarchy
`U₀ : U₁ : …` costs **one relation level per universe level**.

**(c) The Kripke action** (`SpikeSNX` §1). Struck, not built. `fund` is
substitution-based: its λ-case extends `σ : Sub Γ Δ` to `σ,u : Sub (Γ ∙) Δ`, so
the *target* context never grows and nothing is weakened. The one place Kripke is
classically forced is CR1 at `Π` — removed by carrying `SN t` as a conjunct in
the `Π` clause, a decision `SpikeSNU` took for an unrelated local reason.

**(d) Syntactic validity, and a `Γ ⊢ty B` premise on `⊢conv`.** See §4.0. `⊢ty`
is not closed under conversion (backward fails: `ty-Π` does not record that its
components were `El`s), and the existential `fund` makes the whole question moot.

**(e) Erasure as a shortcut to term SN** — refuted earlier (dHoTT-37, PLAN §5);
the erased simple type is not conversion-stable.

### 5.1 Two projections that were wrong, worth remembering

- **`SN` closed under reduction is a real lemma in the JM presentation** (its
  `sne-app` carries `SN` of the argument), so `SNe` cannot be used as the
  *type-level* neutrality payload — `El-ne-reduct` needs neutrality preserved
  under reduction. Nothing at type level uses the `SN` payload (it is only
  consumed by `joinW`-driven shape refutation), so `NbEPDirDBLR` carries a plain
  syntactic `Ne` with a forgetful `sne→ne`. The first draft papered over this
  with a nested `postulate`; the audit caught it.
- **`Σ'` was NOT the pure copy-paste W1f projected.** The eight cross cases per
  level were, but the real case was not: `Σ'` is the first former whose second
  component's *type* moves when the term does (expanding `t` changes `fst t`, so
  the codomain instance shifts from `G[fst t']` to `G[fst t]`). So `exp` at `Σ'`
  needs a genuine CONVERSION — `subTy-monoˢ` + `single-mono`, then `irrel` — where
  `exp` at `Π` needed only a congruence (`snr-app`). Same in `sem-pair`, since
  `fst (pair a b) ⟶ a`.
