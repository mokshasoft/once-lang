★ **Three things that are NOT the mechanism**, each of which was the
obvious guess and each of which cost time:

* **A huge type in the context is free.** Ablating `stp : LStepT` (which
  contains all of `REC1T`/`REC2T`) to plain `Nat` moves the number <6%.
* **Long `there` chains are nearly free.** Hoisting the `there⁹ here`
  lookups into `Def`s buys 13%, not the blow-up.
* ⛔ **Stating types in REDUCED form is WORSE, not better.** `SpikeCostS11`
  wrote `ΓZZ`'s slots and `REC1TZZ` as plain `Π`/`Hom`/`El` instead of
  `subTy`/`renTy` chains and **OOMs** where the chain version finishes in
  3.91 GB. `SpikeCostEq` proves they are definitionally equal, so this is a
  real cost inversion: Agda stores the small unreduced chain and normalises
  on demand. **KEEP THE CHAINS.**

### The three-way Ackermann comparison

| how | time | RSS |
|---|---|---|
| pure Agda, its own termination checker does the lex descent | 0.24 s | 0.07 GB |
| pure Agda, lexicographic `Acc` on ℕ×ℕ proved BY HAND | 0.33 s | 0.11 GB |
| object language, nested `natrec` (System T) | 0.61 s | 0.14 GB |
| object language via `⊢lexrec` | ≈120 s / 3.4 GB — *one branch of four* |

So hand-proving lexicographic well-foundedness costs **+40%**, and deriving
in the object language costs **~2.5×** pure Agda. Neither the descent nor
the kernel is the problem.

⚠ **`SpikeAckT` is a cost baseline, NOT a replacement for `⊢lexrec`.**
Ackermann is structurally recursive at higher type, so it never needed a
measure. It demonstrates that the combinator APPLIES; it is no evidence
that it is NECESSARY. `div`/`gcd`/quicksort are the cases that are.

## 5. WHAT'S NEXT — do these in order

### `#12` — the naturality lemma kit (BLOCKS EVERYTHING ELSE)

Option C makes the data Agda-level terms over an abstract `Δ`. `⊢natrec`
instantiates a motive, i.e. applies `subTy (single v)` to it. With `Γ₅`
that **computed** (the data were context VARIABLES, and `subTy` on a
variable is a lookup). With abstract terms it does not: the substitution
must push through `auxBody`'s own weakenings, and

    subTm (single v) (renTm vs a) ≡ a

is `wk-single` (`NbEPDirDBLR:3840`) — **propositional, not definitional**.

Write 3–4 lemmas of the shape

    subTm (extSᵏ (single v)) (renTm vsᵏ⁺¹ a) ≡ renTm vsᵏ a

each a `trans` of `subTm-renTm` / `subTm-subTm` / `subTm-id`. **The pattern
already exists**: `cancel2` in `LexAsm` is exactly this shape. Then
`⊢-cast` (`NbEPDirDBSubj:99`) at the ~7 motive boundaries: `⊢lexZZ`/
`⊢lexZS` against `M0lex`, `⊢lexSZ`/`⊢lexSS` against `M1lex`, `⊢lexZBr`/
`⊢lexSBr` against `lexAuxMot`, and `⊢lexAux`.

## 6. TOOLING AND TRAPS

**`renum.py`** (checked in, same directory) does the de Bruijn tower
renumbering. Read its docstring. It has two modes; option C's is
`OPTION_C[0] = True`. ⚠ It does not handle `--` comments — strip them
first, or they get flattened onto one line and swallow the rest of the
file. ⚠ `CARRIER_BINDER[0]` must be **False** for `LexAsm`, whose
`⊢lam ty-Nat`s are genuine `Nat` binders, not carrier binders.

**The probe technique** (still the goal display in batch mode): put a
deliberately wrong `⊢nzero` where a derivation goes; the `UnequalTerms`
error prints the EXPECTED type in full.

**Never run two Agda checks at once** — they OOM-kill each other. Exit 143
means contention/OOM; exit 42 is a real type error.

**`check.sh` defaults to `+RTS -A64m`**, and caps memory at 5.5 GB in a
systemd scope so agda dies before the harness does. Override with
`AGDA_RTS` / `AGDA_SAFE_MEM_MAX`.

⚠ `SZ` (5.16 GB) and `SS2` (5.05 GB) sit close to the cap. If they start
failing, the lever is the same one: context depth. `ΓSZ`/`ΓSS` are 10 and
12 deep against `ΓZZ`'s 8.
