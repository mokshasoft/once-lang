## 3. ★ NEXT TASK: `ordtr` — READ `ARCHITECTURE.md` FIRST

The design is DONE; only mechanization remains. The five rules:

    ordtr : RTm Γ → RTm Γ → RTm Γ → RTm Γ → RTm Γ → RTm Γ   -- a t u p q

    ⊢ordtr : Γ ⊢ a ∷ Nat → Γ ⊢ t ∷ Nat → Γ ⊢ u ∷ Nat →
             Γ ⊢ p ∷ Hom Nat a t → Γ ⊢ q ∷ Hom Nat t u →
             Γ ⊢ ordtr a t u p q ∷ Hom Nat a u

    ordtr nzero      t         u         p q ⟶ unit
    ordtr (nsuc a')  nzero     nzero     p q ⟶ p
    ordtr (nsuc a')  (nsuc t') nzero     p q ⟶ q
    ordtr (nsuc a')  nzero     (nsuc u') p q ⟶ absurd (⌜Hom⌝ ⌜Nat⌝ a' u') p
    ordtr (nsuc a')  (nsuc t') (nsuc u') p q ⟶ ordtr a' t' u' p q

SR is checked by hand for each in `ARCHITECTURE.md`. Rule 4 is stage
D's first real customer — the code works out exactly:
`absurd (⌜Hom⌝ ⌜Nat⌝ a' u') p : El (⌜Hom⌝ ⌜Nat⌝ a' u')`, which reduces
to `Hom Nat a' u'`, the result type.

**⚠ BUDGET: stage-D-sized or LARGER, not "stage-A-sized" as the old
record said.** Stage D was tractable because `absurd` has NO root rule
— every confluence row was pure congruence. `ordtr` has FIVE root rules
over THREE scrutinees, so Conf's `_⁺` must dispatch on three argument
shapes and the critical pairs are real.

## 4. AFTER `ordtr`: THE SHOWCASE

The crown jewel is strong induction without `Acc`:

    aux : (n : Nat) → (m : Nat) → m ≤ n → P m      -- by natrec on n

At `n = 0` the impossible branch is `Hom Nat (nsuc k) nzero`, which
COMPUTES to `base` — so `absurd` discharges it. Under a `natrec` motive
`λ m → Hom Nat m nzero → P m`, the successor branch's hypothesis has
exactly that type. **That half needs only stage D and already works.**
The step case needs `ordtr` (from `k < m` and `m ≤ suc n` conclude
`k ≤ n`), which is why `ordtr` is the gate.

Then, smallest first:
1. `div`/`mod` — the minimal end-to-end demo (needs only `m mod n < n`).
2. `gcd` — the crowd-pleaser; the textbook `Acc _<_` example.
3. One of THIS POC's own `sz`-bounded inductions (`prog`, `usplit`,
   `trS` in Canon all thread `(n : ℕ) → … → sz t ≤ n`). The most
   persuasive exhibit, because it is our own pain.
