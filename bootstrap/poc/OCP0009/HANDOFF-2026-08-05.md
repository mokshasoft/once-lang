## 3. THE tt-PATH FORK, AND HOW IT WAS CLOSED

`⊢tr` pins the motive to `⌜Hom⌝ c a (var vz)`, so the fibre over `x` is
`Hom (El c) a x` and transport along `p : Hom A t u` carries
`e : Hom (El c) a t` to `Hom (El c) a u`. **`tr` IS hom-composition**,
i.e. ≤-transitivity. At `A = Nat` the correct result depends on `t` and
`u`, and **`t`/`u` never occur in the term `tr d p e`** — only in the
typing derivation. No reduction rule can case on them, and every
endpoint-blind rule dies to the same counterexample that killed
`tr-J-Nat` (`⟶ e` would need `Hom Nat a t ≅ᵀ Hom Nat a u`; `⟶ unit`
would need `Hom Nat a u ≅ᵀ Unit`; neither holds open).

**DECISION (2026-08-05, with the user): restrict `⊢tr`.** It gains a
`NoNatC c` premise. This is not a stopgap and it does NOT get relaxed
later — `tr` is J-shaped, path-keyed and endpoint-blind, so an ordered
ambient is something it structurally cannot serve. The premise PAYS FOR
ITSELF: `trProgress`'s ⌜Nat⌝ case is refuted on it, and `tr-amb-nonat`
— whose `elNat⊥` proof stage C made FALSE — gets its `{A = Nat}` case
from it.

★★ **The mechanization then found a refinement**: a head-only premise is
NOT preserved by reduction, because `tr-pw` rewrites a `tr` at motive
code `c` into one at `pwBody c`, and `⌜Π⌝ γ ⌜Nat⌝` is non-⌜Nat⌝-headed
yet unfolds to a ⌜Nat⌝ motive. So `NoNatC` is **HEREDITARY along the
pw-spine** (`nnc-Π` recurses into the codomain, `nnc-Hom` into the
ambient), with `nonatc-pwBody` as the closure property `sr`'s `tr-pw`
case consumes. Same spine-recursive idiom as `pw?`/`stkC?`.

Order transport is deferred to its own axis item, `ordtr`, recorded in
`ARCHITECTURE.md` (ORDER TRANSPORT) with a worked three-endpoint case
tree and one trap: the two absurd branches must be left **STUCK**, NOT
given an ex-falso at `base` — `base` has only `ty-base`, no intro and no
elim, and that is what `consistency` rests on. It composes ON TOP of the
restriction; landing it undoes nothing.

Unchanged from the previous handoff, and worth keeping in view: the WF
axis exists to kill the highest-frequency everyday pain in
Agda/Idris/Coq — fuel, `Acc`-plumbing and `TERMINATING` boilerplate.
Once itself suffers it.

Two follow-ups the user has raised and wants kept alive:
1. **Dogfooding** — transcribe some of this POC's own Agda induction
   proofs into the kernel to test ergonomics. Free, and the strongest
   evidence for the axis: "this needed `Acc` plumbing in Agda and
   doesn't here."
2. **Bootstrap, not circularity** — depending on those transcribed
   proofs for the kernel's OWN consistency would be circular. The
   non-circular version is the standard bootstrap: the Agda proof stays
   as the frozen seed, and Once re-verifies independently once it has a
   checked kernel. Two mutually independent proofs beat one.
