### 2 — `ren-gcdStp` is `refl`

⭐ No lemma needed. What makes it compute is finer than "gcdStp is closed" —
closedness is not a judgement this syntax has. It is that **every variable in
`gcdStp` sits under strictly more binders than its own index**, so each
`extR` peels one `vs` and `ρ` is never reached.

⚠ It would NOT collapse for an abstract subterm: the `w (w a)` inside
`monusLtTm` needs `renTm` to fuse, which is propositional. gcd instantiates
it at a concrete variable, where it computes.

### 3 — `NbEPDirDBLibArithLe`, and why composing was never going to work

The 2026-08-15 handoff guessed "it may need composing the existing one-sided
lemmas". It does not, and the reason is worth keeping: **every monotonicity
in the tree is STRICT**, because strictness is what gcd's DESCENT needs. The
leaves need the opposite shape, and no composition of strict lemmas produces
it — the `nsuc` lands on the wrong side of `plusTm`, which recurses on its
FIRST argument.

```agda
⊢plus-le    x ≤ y  →  c+x ≤ c+y                 -- natrec on c
⊢plus-le-l  x ≤ y  →  x+c ≤ y+c                 -- via commutativity
⊢plus-le₂   x ≤ x' → y ≤ y' → x+y ≤ x'+y'       -- the one the leaf wants
```

★ **The witness is unchanged from the strict lemma.** `plusMonoTm p c` proves
both; only the type differs, because the ORDER is what reduces and `+`'s
monotonicity carries no computational content. `⊢plus-le-l` is even one
transport *cheaper* than `⊢plus-mono-l`: the strict version has to push its
`Id` under a `nsuc` with `congS`, and the non-strict endpoint is the sum
itself, which `⊢comm` already speaks about.

## ⚠⚠ THE OBSTRUCTION — `StepExt`'s pointwise premise is at `Θ`, the leaves are not

### What the premise says

```agda
StepExt Δ A cM m stp =
  {Θ : Ctx} {ρ : Ren ⌊ Δ ⌋ ⌊ Θ ⌋} → Ren⊢ Δ Θ ρ →
  (a ih₁ ih₂ : RTm ⌊ Θ ⌋) → … →
  ((y q : RTm ⌊ Θ ⌋) → … → Prv Θ (Id … (app (app ih₁ y) q) (app (app ih₂ y) q))) →
  Prv Θ (Id … (app (app (renTm ρ stp) a) ih₁) (app (app (renTm ρ stp) a) ih₂))
```

`Θ` is fixed by the time the premise is used: the provider of `StepExt`
receives it. **`y` and `q` must be terms of `⌊ Θ ⌋`.**

### Why gcd cannot satisfy that

The three splits are `natrec`s, and a `natrec` branch is typed in an
*extended* context. After split 3's zero branch the goal reduces to

```
Id (El ⌜Nat⌝) (app (app W₁ PAIRᶻ′) CERTᶻ′) (app (app W₂ PAIRᶻ′) CERTᶻ′)
```

in `Θ⁺ = Θ ▹ Nat ▹ M₁ ▹ Nat ▹ M₂ ▹ Nat ▹ M₃`, where `Wᵢ` is `ihᵢ` weakened
and `PAIRᶻ′ = pair (nsuc k′) (monusTm (nsuc n′) (nsuc k′))`. **`k′` and `n′`
are variables bound by the splits.** So the instance needed is at
`y : RTm ⌊ Θ⁺ ⌋`, and there is no function `RTm ⌊ Θ⁺ ⌋ → RTm ⌊ Θ ⌋`.

⚠ This is not a difficulty, it is a type error, and no amount of caller-side
cleverness removes it:

- **Splitting is forced.** At a neutral `a` all three scrutinees are stuck,
  and there is no funext in this kernel — the 2026-08-15 analysis of that is
  correct and unchanged.
- **Binders are forced by splitting.** `⊢natrec`'s successor branch is typed
  in `(Γ ▹ Nat) ▹ M`. Nothing avoids that.
- **Internalising the premise first does not help.** Building a term
  `Θ ⊢ hTm ∷ Π A (Π (Hom …) (Id …))` from the meta-level premise needs the
  premise at `Θ ▹ A ▹ Hom …` — the same context extension. Circular.
- **Re-expressing the recursive call over `a` does not help.** Even if
  `PAIRᶻ` were rewritten as `pair (fst a) (monusTm (snd a) (fst a))`, a
  `Θ`-term, the *certificate* still is not: it exists only in the branch,
  because only the branch knows `fst a` and `snd a` are successors.

### THE FIX — make the premise context-polymorphic, exactly like the rest of `StepExt`

```agda
  ({Θ′ : Ctx} {ρ′ : Ren ⌊ Θ ⌋ ⌊ Θ′ ⌋} → Ren⊢ Θ Θ′ ρ′ →
   (y q : RTm ⌊ Θ′ ⌋) → … →
   Prv Θ′ (Id … (app (app (renTm ρ′ ih₁) y) q)
                (app (app (renTm ρ′ ih₂) y) q)))
```

Two forms were weighed. **The renaming-indexed meta form wins**, and it is
also the form the rest of the module already uses (`auxAt ρ`, `irrT θ`,
`ihS-atR ρ`) — see `pointwise-beats-tower-lemmas`.

- ✅ **renaming-indexed meta** — the consumer's goal already contains
  `renTm ρ′ ihᵢ` (its `ihᵢ` are opaque and its weakening *is* a `vs`-tower),
  so the leaf matches with NO extra naturality on the caller's side.
- ❌ **internal `Π` (`pwT` as an `RTy`)** — rejected. The consumer would need
  a `pwT-ren` lemma and two `⊢app` peels, and the provider would need the
  same `ihS-atR` naturality *plus* two `⊢lam`s. Strictly more work on both
  sides. (This is the form `LibAmrec`'s header considered and rejected in
  2026-08-14, for a different but compatible reason.)

### What the provider side costs — ONE new lemma, not two

`ext` is applied in `aux-irr`, whose callers are `aux-irr-z`, `irr-zz`,
`irr-zs`, `irr-sz` (all supply `pwZ`) and `irr-ss` (supplies `pw`).

- **`pwZ` generalises for free.** It is EX FALSO from `μ y < μ a ≤ 0`; it
  never inspects `ih₁`/`ih₂`, which are already abstract in its statement.
  Only `dc`/`da` need `ren-lemma`.
- **`irr-ss`'s `pw` needs exactly one new naturality lemma:**

  ```agda
  ihS-atR-renʳ : {Γ′ Γ″ : Cx} {ϑ : Ren Γ′ Γ″}
                 (θ : Ren ⌊ Δ ⌋ Γ′) (θ′ : Ren ⌊ Δ ⌋ Γ″) →
                 (∀ v → ϑ (θ v) ≡ θ′ v) → (x : RTm ⌊ Δ ⌋) (a k p : RTm Γ′) →
                 renTm ϑ (ihS-atR θ x a k p)
               ≡ ihS-atR θ′ x (renTm ϑ a) (renTm ϑ k) (renTm ϑ p)
  ```

  Five peels through `ihS-atR`'s five layers, in the style of the existing
  `auxAt-renʳ` (which is a three-liner because `subren`/`renren`/`extcond`
  do the work). ⭐ **Reach for the pointwise calculus, not a tower lemma.**

- ⭐ **`descS-atR` does NOT need one**, and this is the saving that makes the
  fix cheap. Once `renTm ρ′ (ihS-atR ρ …)` has been rewritten to
  `ihS-atR (ρ′∘ρ) …`, the reduction `ih-appR` is instantiated *fresh* at
  `Θ′`, so it produces `descS-atR (ρ′∘ρ) …` directly. `descS-peel` is
  already generic in `ρ`, so `dD` generalises verbatim. Do not start by
  writing a 7-layer naturality lemma for `descS-atR` — it is not needed.
- `dihAt` moves to `Θ′` by `ren-lemma` + the existing `irrT-ren`.

## THEN — the four leaves, unchanged from the 2026-08-15 design

Everything the previous handoff designed still stands, including the wrinkle
and its fix (split motives 1 and 2 carry an order hypothesis, instantiated at

calls for is now available: `⊢plus-le₂` composed with `⊢CERTᶻ`/`⊢CERTˢ` under
`⊢ordtr`.

Recommended shape: **one top-level lemma per split, each in an arbitrary
context**, so that each motive mentions only its own scrutinee and everything
else is a parameter. L1 splits `snd a` and calls L2; L2 splits `fst a` and
calls L3; L3 splits the comparison and is the only one with a constant
motive. The two base leaves reduce both sides to the same term and finish
with `⊢idrefl` after a `wk-single` cast (the discarded `ih` is why the cast
is needed — `subTm (single ihᵢ) (w t) = t` is propositional).

## Standing lessons (carried forward, plus new)

- ⭐ **A design derived by reading types can still miss a context.** The
  2026-08-15 plan was right about every reduction and every certificate and
  wrong about *where* the pointwise hypothesis lives. Both wrinkles found on
  this route — the missing scrutinee equation, and now this — are about the
  CONTEXT a fact is available in, not about the fact. When a plan says "and
  then instantiate the hypothesis", check which context the instantiation
  needs it in **before** budgeting the leaves.
- **Meta-level hypotheses do not cross binders.** A hypothesis stated as an
  Agda function at `Θ` is unusable in any proof that eliminates into an
  extended context. If the consumer will case-split — and any non-trivial
  step function will — the hypothesis must be renaming-indexed from the
  start. This is the cost the 2026-08-14 "meta-level, not an `RTy`" decision
  deferred; it comes due at the first real caller.
- **Agda cannot invert `subTm`.** Anything occurring only under a
  substitution must be **named**, never left as `_`.
- **Green ≠ meaningful.** `StepExt` is still undischarged by anything in the
  tree, so `irr-ind`/`amrec-unfold-Id` remain machinery with a real
  statement.
- **Prefer the pointwise bridge to another tower lemma.**
