the `Π`-passenger encoding is what you get free once you have chosen
that. **Nobody chose the passengers.**

`tmp/AmbientMot` (fails) · `tmp/AmbientMotC` (control, rc=0) ·

ambient Γ-term IS usable in a method body. The true restriction is

because `⟨i⟩` is method-bound.

⇒ **`IPayTyMot:16`'s "a free variable of `Γ` cannot be used" is FALSE as
stated**, and `PayTy:11`'s "it could equally be a free variable of the

## 5. ✅ WHAT SURVIVED — `opaque` ON THE TYPE FORMER

Four probes, IDENTICAL harness (`imethsTyFrom-wf` over all 53 rows), only
the motive changes:

| motive | cost |
|---|---|
| `Nat` — mentions nothing | **0.98 s** |
| `K (pair sTm nzero)` — closed, 3 nodes | 62.28 s |
| `K (pair sTm (var …))` — ambient variable | 60.99 s |
| `K (pair sTm (snd ⟨i⟩))` — index-reading | 61.38 s |

`K x = IMu KnotD IPair x`. Every slow motive carries the **53-row
description**; `Nat` carries nothing. ⇒ **the cost is the elaborated term
size**, and `renTy` does NOT walk the description (`renTy ρ (IMu D I i) =
IMu D I (renTm ρ i)`) — it is that the UNFOLDED form, containing `KnotD`
inline, is what gets stored, compared and serialised.

**`tmp/ProbeOpaque`** seals the TYPE FORMER, not the description, with its
⊢ty proof sealed alongside so callers never look inside:

```agda
opaque
  Kop i = IMu KnotD IPair i
  ty-Kop di = ty-IMu KnotWf di
```

| | wall | peak RSS |
|---|---|---|
| `K` transparent | 62.28 s | 2.15 GB |
| **`K` sealed** | **31.60 s** | **0.69 GB** |

⇒ **2× time, 3.1× memory, rc=0, LOCAL change, no kernel surface.**
★ `KnotD` stays transparent, so `ilookupD`/`ipayTy`/`iihTy` still compute.
**Seal where the description is an inert index; leave it open where it is
eliminated.**

⚠ It is 2×, not 63×: sealing stops the EXPANSION, not the ACCUMULATION of
stuck transports. The rest needs a sealed
`ren-Kop : renTy ρ (Kop i) ≡ Kop (renTm ρ i)` threaded — untested.
