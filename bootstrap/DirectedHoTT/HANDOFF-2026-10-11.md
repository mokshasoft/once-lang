### The regression it fixes

These timings come from deleting only the module's own `.agdai`, with the
dependencies already built:

| module | before PLAN-REF (cold, `sweep-cold.log`) | at `ea5ba8987` |
|---|---|---|
| `Examples.Gcd.LeEq` | 4 s | **1057 s** / 1.0 GB |
| `Examples.Gcd.LeMid` | 61 s | **113 s** / **4.96 GB** (the 5.5 GB cap explains the sweep's 143 kill) |

**Profile** (`tools/agda-profile.sh`, report in
`~/.cache/once-lang5-profile/reports/LeEq.*`):
- 850 of 1050 s are `extS`/`renTm`/`subTm` unfoldings in `Eq4.⊢transport`,
  `Eq4!.step`/`eq4`, `⊢MIDnr` and `⊢S3s`.
- The conversion heads include `Lib0.Inst.Spec-Typing.single`,
  `Lib.ArithComm._.⌊_⌋` and `Spec.Typing._.Base.⌊_⌋`: copies of
  definitions from the signature-free `Spec.Base`.

**Cause.** `Spec.Reduction` had `open import Spec.Base public`. A module
application copies the module's whole exported scope, re-exports included.
So every `Spec.Typing 𝒮 n` instance minted its own `single`, `⌊_⌋`, `nrs`
and so on. With two heads for one function, Agda can't match them by name
and decides `subTm (single x) F ≡ subTm (single′ x) F` by evaluating the
substitution. This is the same family as the 2026-10-09 SD fix, and it is
open problem 4 of the 10-08 handoff.

### The fix (uncommitted)

- `Spec/Reduction.agda`: `open import DirectedHoTT.Spec.Base` without
  `public`, with a comment explaining why.
- New `tools/base_unshare.py`. It strips the Base names from every
  Typing/Reduction `using`/`hiding` list (including `Lib0.Spec-*` and
  `as`-aliases) and opens them once from `Spec.Base`, before the module
  header. It is idempotent.
- `tools/planref.py`: `convert_all` runs `base_unshare.convert_text` last,
  so `gen-knot.py`/`gen-judge.py` emit the same thing. Regenerating
  reproduces the tree byte for byte.
- 247 `.agda` files rewritten. Hand fix: `Examples/Knot/Core.agda` now uses
  `B.DescF` (`import Spec.Base as B`) instead of `T.DescF`.
- `lint-imports.py`: 0 errors, 395 warnings, the same as before.
- **Type-checked so far:**
  - checked alone: Spec/Typing, Spec/TypingA, Metatheory/SubjectReduction;
  - the sweep (`bootstrap/sweep-unshare.log`) passed **165 modules with no

## Rule learned

A parameterised module must never `public`-re-export a non-parameterised
one. When a regression follows a parameterisation, look in the profile's
conversion and unfolding heads for `M._.name` / `Inst.…name` copies of
signature-free definitions.
