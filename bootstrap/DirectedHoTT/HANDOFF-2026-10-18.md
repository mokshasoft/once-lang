### 2. Sweep resume cache (`tools/sweep.sh`)

- Each mem-guard restart re-walked all 298 modules. Now an ok module writes
  a stamp, `_build/sweep-ok/<tag>`, containing its key.
- key = sha256(salt + source + the keys of its deps). The salt covers:
  - every normalizer/formal `.agda` file;
  - the `.agda-lib` files and `check.sh`;
  - the agda binary;
  - the stdlib path.
- A module whose stamp matches its key prints `cached` and is skipped. The
  last line is `ALL GREEN (N modules, k of them cached)`.
- `SWEEP_NO_CACHE=1` forces a cold sweep. Timing comparisons need it; see
  memory "agda-timing-needs-a-cold-interface".
- It has only been partly exercised: one restart wrote 163 stamps, and 202
  are on disk now. A full run that reuses the stamps has not been seen yet.
- ⚠ The stamps assume `_build` interfaces stay valid. If you wipe
  `_build/*.agdai`, also wipe `_build/sweep-ok`.

### JudgeConGen: why the sweep kept stopping at 257

  1848 lines) takes **117–155 s cold every sweep**: sweep-tbl 119 s,
  sweep-reexp2 127 s, sweep-p6 155 s. That is the box's longest single
  check after the core segments. It was also the module running when the

  there. The user: "This is not a coincidence."
- The plan is to profile it and fix the cost in the `gen_con` template, not
  to work around it.
- **The profile has not run yet.** `agda-profile.sh` must first rebuild the
  Knot chain under profiling flags in its staged copy (stale since
  PwCore/Preds changed), and that stage peaks at about 3.7 GB. Claude Code's
  low-memory reaper killed it while a foreign
  `make agda MODULE=EverythingFiltered.agda` was running.
- From `bootstrap/`, with the box to itself:
  ```bash
  TIMEOUT=3000 DirectedHoTT/tools/agda-profile.sh \
    DirectedHoTT/Examples/Knot/JudgeConGen.agda > prof-jcg.log 2>&1
  ```
- Suspects from reading the template (each matches a known bad pattern;
  confirm with the profile's unfoldings and conversions before changing
  anything; memory "profile-call-counts-first"):
  1. `dp = ⊢payK …` and `dc = ⊢cTy …` are where-bound with no type
     signature ("levitated: name every piece").
  2. R₀/R₁'s types read `fst c`, `fst p` and `fst (snd p)` through
     where-bound pairs, so every constructor carries projection redexes
     into a conversion. Using the variables (`g f0 f1`) directly would apply
     "a variable is the cheapest position".
  3. `okB = okT…I {_} {j} …` leaves the first implicit unpinned ("unsolved
     meta = missing pin" / "pin implicits on defined Set types").
  - An existing comment in `gen_con` records that unpinned p/c implicits
    once cost 3.4 s per constructor. At 91 constructors, ~1.3 s each is
    the whole 117 s.
- A/B each fix as a single cold check with the sweep's RTS (`-A64m -c`), one
  agda process at a time.

## Rules learned this stretch

- A module that stalls the sweep repeatedly at the same position is the
  sweep's longest check, not bad luck. The collision lands there because
  that is where the time is. Profile it.
- Every mem-guard restart used to cost the whole prefix of the sweep. The
  stamp cache makes restarts cheap, but timing claims still need
  `SWEEP_NO_CACHE=1` on a cold `_build`.
