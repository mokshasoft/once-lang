## Decisions taken this session (all recorded in PLAN-REF §6)

1. **The typing family's parameter is `⌜TSig⌝ = Σ ⌜QSig⌝ Nat`** — the
   signature AND the bound, mirroring `Spec/Typing (𝒮)(n)`. Its
   conversion premise is at `sigT q` (a redex; bridged by
   `Lib/SynFam.DF-⟶*`/`KF-⟶ᵀ*`: the family at a reducing parameter
   reduces).
2. **The core is a hypothesis on the ambient signature.** `Knot/PwCore`
   cites core entries, and a reference projects from the AMBIENT
   signature, so it (and the 33 modules above it) take
   `core : PwCore.Kc ⊑ᴰ 𝒮` (`Spec/SigExtend`). Core ≅ Knot is decided
   once at the core by NbE and carried by `Metatheory/SigExt.ext≅`.
   Rejected: a Knot not citing the core (reverts P4 and R4).
3. **δ / ⊢ref as side conditions on the computing order:**
   `n < sizeQ q ⇒ kref n ⟶ εwkK 1 j (bodiesQ q n)`;
   `n < boundT q ⇒ kref n : εwkK 0 j (typesQ (sigT q) n)` — no premise.
   Rows as a tail after the side condition (`TδT`, `T⊢refT`).
4. **Library arguments have ONE global spelling**
   (`Entries.okᵂ 𝒮 wf`, `Entries.refsᵂ 𝒮 wf`, `Defs.size 𝒮`), never
   per-module private abbreviations (instances of one library must be
   syntactically identical). Did NOT fix the regression below.
