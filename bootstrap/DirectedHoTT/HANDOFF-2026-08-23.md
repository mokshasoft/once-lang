## 3. TRAPS FOUND THIS SESSION — do not re-learn these

* **`rc=0` can mean NOTHING WAS CHECKED.** A cached `.agdai` gives exit 0 with
  no `Checking` line. **A green is a claim about module M only if
  `Checking …M` is in the log.** I committed an unverified module this way.
* **A catch-all is SILENT and can be WRONG.** `spine?`/`stablecd?` had explicit
  `con`/`elim` rows and inherited `_ = false` for `icon`/`ielim` — three wrong
  answers, coverage-checker happy. check-formers check 3 lists these; CONFIRM
  each default rather than inherit it.
* **A datatype missing a constructor is invisible to Agda.** `icon`/`ielim`/
  `⌜IMu⌝` had no SN-layer home; only check-formers check 1 caught it. I had
  read the check's exit status wrong and committed "CLOSED" while it exited 1.
* **`snr-ielimⁱ` MUST NOT EXIST.** I added an index-ξ to weak-head reduction by
  analogy with `_⟶_`; it makes `snr-det` FALSE (for `ielim D i ms (icon k p)`
  both ι and the index-ξ apply). `_⟶_` is full reduction and tolerates overlap;
  `SNRed` must be deterministic. The index is CARRIED, like `elim`'s methods.
* **Agda's missing-case list describes ITS SPLITTING, not your definition.**
  72 cases → 3 clauses (`trstk?-red-d`); 226 → 15 (`_⁺ᵀ`). Read the analogous
  existing clause, not the list.
* **Code motion:** slice on MARKERS, assert occurrence counts IN THE TARGET
  REGION, insert in REVERSE order, and remember a `with` head owns the `...`
  lines below it. Four self-inflicted corruptions came from ignoring this.
* **Dedup up to PATTERN-VARIABLE RENAMING** — `(ι-ielim D iˣ …)` and
  `(ι-ielim D i …)` are the same clause; Agda takes the first and only warns.
