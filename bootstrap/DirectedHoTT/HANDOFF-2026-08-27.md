## The results worth carrying forward

### 1. ★★★ A GREEN BUILD REFUTED THE DESIGN

`PLAN-JUDGEMENT` step 2 needs object-level weakening over the knot, at
the uniform motive `WkTm` and `WkFin` both use. As sort 7, `◇`'s method
holds `snd ⟨i⟩ ≡ nzero` and would have to prove `nsuc (snd ⟨i⟩) ≡ nzero`
to rebuild itself — but `K (sCtx, 1)` is INHABITED, so a different
constructor closes the goal. **It compiled**, `--safe`, trust surface
empty, computing

    ⋄  ↦  ◇ ▹ Nat            -- a type that was never there

and nothing downstream would have noticed, because there is no
`Ctx`-weakening spec for it to violate.
⇒ `verification-that-covers-less-than-it-claims`, reached from a new
direction: **the hazard was a GREEN build, not a red one**, which is why
it had to be built rather than argued.

### 2. ★★ THE PRINCIPLE IT SETTLED — A STRATUM IS NOT A MEMBER

The seven families in `KnotD` are one mutual recursion in `Spec/Syntax`.
`_▹_` carries an `RTy ⌊ Γ ⌋`, so `Ctx` depends on the syntax and the
syntax never depends back. **One-directional dependency ⇒ stratum, not
member.**

★ And the index had been meaning two things: `KnotD`'s second component
is the AMBIENT SCOPE a term lives in — a parameter — while a context's
depth is its OWN LENGTH, a measure of the datum. Sharing one slot is what
forced `Knot/Map` to grow a third signature shape for `⊢enCtx`. That got
written down as an oddity; it was a symptom.

⇒ ★★★ **AND SPLITTING MADE `wk`'s TYPE TRUE, rather than restricting
it.** With `Ctx` out, `wkK : K (s,d) → K (s, suc d)` is honest at all 53
sorts — closed sorts' depth is degenerate, `ICon` is genuinely scoped,
and no row invents anything.

### 3. ★ THE UNTESTED JOINT WENT THROUGH FIRST TRY

`_▹_`'s `RTy` field has its TYPE in another family, so it is a κ field
carrying a `⌜IMu⌝` code (`icw-imu`) **at an index mentioning a BOUND
field** — three separately-built things (`Scoped.varC`, `DepIx.islamC`,
`DepIx`'s ford naming `var vz`) never before combined. ⚠ Fording could
not do this job: it turns a computed INDEX into a constraint, never a
field's TYPE into a family. Both mechanisms are in `_▹_`, three lines
apart.

And the split is cheaper per row, not dearer:

| | as sort 7 | as `CtxD` |
|---|---|---|
| fords per row | 2 (tag + depth) | **1** (depth) |
| index | `Σ' Nat Nat` | `El ⌜Nat⌝` |
| `_▹_`'s `num-ren`/`num-sub` chains | 14 | **9** |
| `⊢ixP` on the ambient, `fordFst`, `βfst` | throughout | **absent** |

### 4. ⚠ THE COVERAGE GUARD MOVED, AND IT IS NOT WEAKER

`gen-knot.py`'s `verify()` is back to one file and no longer mentions
`Ctx`. `Ctx` is not thereby unchecked: `enCtx`'s clauses check it, because
**Agda's coverage checker checks FUNCTIONS**. A hand-written table with a
hand-written map is guarded already; a GENERATED table with a GENERATED
map is not, which is the entire reason `verify()` exists.
**Controlled**: deleting `enCtx`'s `_▹_` clause gives `Incomplete pattern
matching for enCtx`.

### 5. ★ WHAT A PAIR-INDEXED TRANSPORT COSTS — TWO `jsub`s, FLAT

One per index component, where `WkFin`'s `fsuc` moved along one. ⚠ And
the `wk-single` one expects does NOT appear: the outer transport's family
mentions the inner component, weakened past the transport's own binder
and then substituted — PROPOSITIONAL in general, DEFINITIONAL here,
because that component is `snd` of a VARIABLE and both actions COMPUTE on
variables (`Knot/Build`'s finding (c)). **Measured after a wrong guess**:
replacing either `wk-single` with `refl` type-checks, so both casts came
out.

★ ⇒ **`_∋_∷_`'s THREE-component telescope should cost three `jsub`s,
flat** — the first quantitative thing anyone knows about step 1. ⚠ Its
telescope now mixes two families (`CtxK` and `K`); `DepIx` already builds
one mixing `El ⌜Nat⌝` with an `IMu`, so that is the same mechanism at one
more component.

## NEXT — and the gate is now NAMED AND PRICED, not just named

### A. ⬜ OBJECT-LEVEL WEAKENING **OVER THE KNOT** — the whole gate
###    (the MOTIVE half is settled; the PER-FIELD RULE is not)

`PLAN-JUDGEMENT` step 1 (`_∋_∷_`) reads *"needs only the weakening
already in hand"*. ⚠ **THAT IS TRUE OF THE MECHANISM AND FALSE OF THE
CODE.** `Examples/WkTm` weakens a **3-constructor toy**; `_∋_∷_`'s index
mentions `renTy vs A`, which must be an `ielim` over the **53-row knot**
returning a knot element.

★★ **AND IT CANNOT BE 53 ENUMERATED METHODS.** That is precisely the
147s-vs-5s mistake of 2026-08-26 (`half-generalization-is-worst`), with a
SYNTAX codomain instead of `Nat`. It has to be `Lib/IFold`-shaped: method
computed from the `ICon`, tuple from the `IDesc`.

⚠⚠ **BUT `Lib/IFold`'s SHAPE DOES NOT REACH IT, AND HERE IS WHY.** A fold
into a constant motive takes the IH at every `iρ`. A weakening does not:

* `dκ`'s `RTy ε` field is pinned at the LITERAL index `pair sTy nzero`.
  Under the motive `M(i,t) = K (pair (fst ⟨i⟩) (suc (snd ⟨i⟩)))` its IH
  lands at depth `1` — but the rebuilt row needs it back at depth `0`.
  ⇒ that field must take the **original field**, not the IH.
* the two depth-Forded rows (`vz`, `vs`) constrain `snd ⟨i⟩`, so the
  shifted index needs the ford witness **re-proved at a bumped `m`** —
  `WkFin`'s `⊢jsub` transport, twice. ✅ `◇`/`_▹_` are no longer among
  them, which is (A′).
* `_◂_`'s `ICon (ε ∙)` field is pinned at the LITERAL index `pair sICon
  1`, so it is a second instance of the first bullet — the rule has two
  customers in the table, not one.

⇒ **the per-field choice — IH or original — is a function of whether that
field's index expression MENTIONS THE AMBIENT.** That is decidable on
`ICon`'s raw `RTm Δ` indices, so a generic `Lib/IWk` is plausible; it is
not established, and it is **the one thing left to spike before
building**. ⚠ The MOTIVE half of this entry is now settled — see (A′) —
so this is the remaining content of step 2, not a fork.

★ **SPIKE IT AT THREE ROWS, NOT 53.** `cTy-Nat` (ford-only), `cTm-lam`
(the binder, index `suc ⟨d⟩`), `cDCon-kap` (a LITERAL-pinned field beside
a riding one) bracket every case in the table, and `cVar-vs` adds the
transport. Done when the per-field rule types, or the obstruction is
named. Everything in `PLAN-JUDGEMENT` §3 steps 1–4 is downstream of it.
